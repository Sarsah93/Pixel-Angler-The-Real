# UI 패널 작성·검수 규칙

## 패널 골격 (DraggablePanel 상속)

- 모든 팝업은 `ui/DraggablePanel.ts` 상속 — 헤더 드래그·X 닫기·dim(모달)·`contentTop` 제공.
- **닫기는 우측 상단 ✕ 하나로 통일**(122차 사용자 지시) — 전체 화면 씬(도감·출처)도 하단/엣지 버튼 없이 우상단 ✕ + ESC. 푸터 텍스트는 뷰포트 계산(`maxScroll`)에 포함.
- **씬에서 `scene.add.existing(panel)` + popupStack 등록** (ESC LIFO 편입). 하네스에서도 add.existing 필수.
- **자식 추가/재구성 후 `this.applyFix()`(= applyScreenFixed) 필수** — 카메라 스크롤 씬에서 자식 scrollFactor 1이면 히트 판정이 카메라 이동량만큼 어긋난다.

## z-order 밴드 (76차 확립 — 위반 금지)

- **일반 팝업 [800, 899)**: 인벤/장비/상점/쿨러/상세보기 — 정적 depth는 "초기 서열"일 뿐, **클릭하면 depth 동적 최상단**(bringSelfToTop이 밴드 내 max+1 setDepth). 일반 팝업은 모달 밴드 침범 불가.
- **모달 [900~)**: 손질 900 / 회썰기 910 / 확인·수량 다이얼로그 950 — dim이 아래 입력 흡수.
- ⚠ `scene.children.bringToTop()`은 depth가 다르면 **무력** — z 조정은 반드시 setDepth로.
- 자식 팝업(컨텍스트 메뉴·툴팁)은 패널의 자식으로 넣으면 패널 depth를 따라 자동 해결.
- **새 팝업은 여는 순간 밴드 최상단**(122차 — `RegionFieldScene.openPopup` → `DraggablePanel.raiseToTop()`). 정적 depth는 밴드 안 초기값일 뿐 —
  큰 패널(스킬 892) 위에 작은 정적 depth(일지 891)를 열면 통째로 가려지고 ESC 순서가 어긋났다.
- 밴드 밖 특수값: HUD 200 / 드래그 고스트 1500 / 일시정지·최상위 확인 1200.

## 타이틀바(캡션바) 규칙 (119차 확립 — 위반 금지)

패널에 제목 밴드나 조절 버튼이 있으면 **그 밴드는 컨텐츠가 침범하지 않는 전용 영역**이다.

- **밴드 높이 상수 하나로 관리**한다 — `DraggablePanel.HEADER_H = 32` / HUD 계열은 `RegionHud.HUD_HEADER_H = 20`.
  컨텐츠 y는 `패널상단 + HEADER_H` 를 기준(`SP_CONTENT_Y` 같은 파생 상수)으로 잡고, **패널 높이에도 밴드를 더한다**.
- **조절 버튼(◱ 크기 / ◐ 투명 / ✕ 닫기)은 밴드 안에만** 둔다. 버튼이 16px이면 밴드는 최소 20px —
  축소 단계에서 밴드를 배율로 줄이면 버튼이 아래 컨텐츠를 덮는다. `Math.max(HUD_HEADER_H, round(h * k))` 로 하한을 건다.
- 실측 위반 사례(119차): 상태 패널 ◱◐ 버튼(y 16~32)이 HP 바(y 28~38)와 4px 겹쳐 있었다.
  지역 채널은 축소 단계(k=0.5)에서 밴드가 11px로 줄어 버튼이 로그 뷰포트를 침범했다.
- 신규 패널 검수 항목: **밴드 하단 y ≤ 첫 컨텐츠 상단 y** 를 실측으로 확인할 것.

## 고정 y 배치 금지 — 흐름 배치 (119차 확립)

`wordWrap`이 걸린 텍스트는 **줄 수가 데이터에 따라 변한다**. 그 아래 요소를 고정 y나 고정 피치로 배치하면
언젠가 반드시 겹친다(한국어에서 안 겹쳐도 영어 번역이 길어지면 겹친다).

- 아래 요소의 y는 `앞 요소.y + 앞 요소.height + gap` 으로 **실측 흐름 배치**한다.
- 카드/패널 높이를 미리 알아야 하면 **텍스트를 먼저 만들어 `height`를 재고** 그 합으로 높이를 산출한 뒤
  배경을 그리고 위치를 다시 잡는다(119차 월드맵 구역 확인 카드가 이 방식).
- 실측 위반 사례(119차): 구역 확인 카드가 상세 줄을 `줄 수 × 21px` 로 가정 → 한 줄만 wrap돼도 버튼 침범.
  스팟 툴팁의 유형 라인이 고정 y=76 → 본문 3줄이면 4px, 4줄이면 21px 겹침.

## 마스크·스크롤 — 두 방식의 선택 기준

| 콘텐츠 | 방식 | 이유 |
|---|---|---|
| **인터랙티브 목록/그리드** (클릭 가능한 행·셀) | **윈도우드 렌더** (보이는 행만 생성 + 휠 + 스크롤바 + `n–m / N행` 표기) | Phaser 마스크는 **입력을 클립하지 않는다** — 스크롤아웃된 셀의 팬텀 히트 발생 (54차 ShopPanel) |
| 비인터랙티브 본문 (텍스트·이미지) | GeometryMask + 휠 | 단 **마스크 Graphics에 `setScrollFactor(0)` 필수** (33차 — 없으면 카메라 이동량만큼 클립 어긋남), 패널 이동 시 마스크 위치 동기화, destroy 정리 |

- 휠 리스너는 `containsPointer` 게이트 — 동시에 열린 다른 패널 휠을 가로채지 않게.
- ⚠ **중첩 Container 안에 GeometryMask 자식 + 인터랙티브 자식을 같이 두지 말 것** — 포인터 이동 시 렌더러 탭이 통째로
  크래시한다(117차 실측 — HUD 채널을 스케일용 래퍼로 감쌌을 때). 축소/확대가 필요하면 **패널을 그 크기로 재생성**(로그·상태 보존).
  마스크 본문은 패널 직속 자식으로 두고, 패널 이동은 `postupdate`에서 마스크 지오메트리를 다시 그린다(HelpLibraryPanel 패턴).

## 드래그 앤 드랍

- **네이티브 `setInteractive({draggable})` 금지** — scrollFactor 0 + 스크롤 카메라 조합에서 drag/dragend가 죽는다 (41차 실측).
- 표준 = **커스텀 포인터 방식**: 요소 `pointerdown` → 씬 레벨 `pointermove/pointerup` 추적, 6px 임계 초과 시 고스트 생성, 이동 없으면 클릭으로 처리. 패널 간 전달은 씬 이벤트(`inventory-drop` 패턴 — 수신자 없으면 조용히 무시).

## 텍스트 오버플로 3원칙 (전 텍스트 컴포넌트)

가변 문자열은 반드시 다음 중 하나로 방어:
1. `wordWrap: { width: 안쪽폭 }` — 줄바꿈 (세로 여유 확인, 필요 시 `fitTextHeight(t, maxH)` 안전망)
2. `setOrigin(1, …)` 우측 정렬 — 우측 열/버튼 침범 방지
3. `clampTextWidth(t, maxW)` (ui/TextFit.ts — 이진 탐색 말줄임) — **한 줄 고정 행** 전용
- 위험 1순위 패턴: 좁은 열 + 좌측정렬(origin 0) + wordWrap 없음 + 가변 내용.
- 제목이 2줄이 될 수 있으면 **아래 요소를 고정 y가 아니라 실측 높이 흐름 배치**(hShift — 66차 상세보기 재발 사례).

## 마지막 방어선 · i18n

- 패널 render 마지막에 **`enforceTextBounds(container, PANEL_W − 20, '패널명')`**(ui/TextFit.ts) — 배치 실수가 있어도 창 밖으로는 못 나간다.
  dev 콘솔 `[TextOverflow]` 경고가 뜨면 근본 배치를 고친다(119차).
- **Text 원문을 한국어 리터럴과 비교하지 말 것** — i18n 훅(`i18n/I18n.ts`)이 `setText`를 가로채 EN으로 바꾼다. 상태는 필드로 들고,
  새 UI 문구는 `i18n/en.ts`에 원문 = 키로 추가한다.
- 컨테이너에 **자기 자신을 add 금지**(`c.add(c)` — 조용히 사라짐) · 재생성형 위젯은 구 파츠·마스크·씬 핸들러 **파괴 먼저**.
- **정적/동적 2층 패널은 레이아웃 키로 정적 층을 지킨다**(154차 `CookingPanel`) — 버튼 클릭에서만 `renderAll`을 부르면 스토어가
  다른 경로(동기화 틱·다른 씬·하네스)로 바뀔 때 새 동적 층이 옛 정적 층 위에 겹쳐 그려진다. 틱마다 `키(모드|대상 id|status)`를
  비교해 달라지면 `renderAll`, 같으면 `renderDynamic`.
- **HUD/패널 축소는 `setScale`이 아니라 단계별 레이아웃 재생성** — scale은 글씨까지 줄여 가독성을 깬다. 줄이면서 뺀 정보는
  **호버 툴팁**(커서 우측 하단)으로 돌려준다.
- **버튼이 팝업을 열고/닫거나 자기 자신을 재생성한 직후 `restoreHandCursor(scene)`** — Phaser는 `useHandCursor` 객체가
  파괴되면 캔버스 커서를 기본값으로 되돌린다(포인터가 그 위였는지 무관). 안 부르면 "클릭 후 손 커서가 풀리는" 버그.

## 인게임 표현 규칙 (150차 — 사용자 지시 · 상세는 AGENTS §4 「인게임 표현 규칙」 R1~R10)

새 화면·새 문구를 만들 때 **매번** 확인한다. 기능이 맞아도 여기서 틀리면 "AI가 텍스트로 때려 넣은 UI"가 된다.

- **개발 용어·내부 id를 라벨로 쓰지 않는다**(R1) — `자격 사다리`·`서브 아크`·`트랙`·`N04`·`M1-06`.
  구조 명칭은 주석에만. 화면에는 사람이 쓰는 말(`자격 취득`·`이야기`·이야기 제목).
- **진행하지 않은 것은 목록에 올리지 않는다**(R2) — 회색 비활성으로 보여줘도 스포일러다.
  완료분은 토글로 선택 열람(기본 가림).
- **대사는 타이핑 + 스크롤 + ▼**(R3) — 한 화면에 쏟지 않는다. 본문 20px 이상.
  표준 선택지 3종(도와줄 일 / 물건 보기(거래하는 사람만) / 나가기). NPC 클릭 즉시 의뢰서 펼치기 금지.
- **설명문은 나레이션으로**(R4) — 정의문 요약 금지. NPC의 말 + 내 생각·느낌.
  길면 **그 박스만** 스크롤(패널 전체 스크롤 아님).
- **초상은 얼굴 확대**(R5) — `ensureFacePortrait`. 전신 축소 금지.
- **세로 경계 준수**(R6) — 하단 고정 요소는 패널 안쪽으로, 사유 줄은 버튼 **위**.
  `DraggablePanel.auditBottom()`(= `auditTextBottom`)으로 확인. 가로와 달리 **세로는 자동 교정이 없다**.
- **텍스트 입력은 `ui/TextInput.ts`**(R7) — Phaser `keydown` 글자 수집은 한글을 못 받는다.

## 검수 체크리스트 (신규·수정 시마다)

1. **오버플로**: 어떤 요소도 패널 경계 밖 금지. 총높이 초과 가능하면 높이 캡 + 화면 안 위치 클램프.
2. **겹침**: 새 요소가 인접 요소(같은 행 버튼·라벨·값)와 좌표 충돌하는지 확인.
3. **스크롤/클립**: 무한 증가 콘텐츠는 위 표의 방식 필수. 조용한 잘림 금지(개수 표기).
4. **가장 긴/많은 콘텐츠로 실렌더** (최장 어종명·특대 수치·꽉 찬 목록) — verify-render 스킬로 스크린샷 확인. 측정은 origin 보정(`x + width*(1-originX)`).
5. **금지 = 이모지 + 텍스트 장식 / 권장 = 픽셀 아이콘**(2026-09-10 · **128차 정정**).
   막는 것은 ① 이모지·장식용 특수문자 ② `[아이콘] [타이틀]`식 텍스트 꾸밈 — **시각 아이콘은 오히려 정답**이다.
   아이콘은 ① **16x16 손그림 픽셀 아이콘**(`tools/gen_pixel_icons.py` → `data/PixelIconArt.ts` →
   `ui/PixelIcon.ts`의 `addPixelIcon`) ② 절차 생성 픽셀 그래픽 ③ 스프라이트 텍스처.
   **텍스트 약어 배지(`식`/`FP`)는 쓰지 않는다** — 유저가 해석해야 하고 로케일마다 폭이 달라진다.
   상태·경고 표식도 `✅⚠❌` 대신 아이콘·색 칩·`[경고]` 말머리. 예외는 확립된 조작 글리프 `✕`·`◀▶`·`◱◐`.
   신규 데이터의 `icon` 필드에 이모지 문자열 금지 — **픽셀 아이콘 키** 또는 텍스처 키.
   ⚠ 아이콘은 **실사이즈(16px) 스크린샷으로 육안 확인**할 것 — 확대 미리보기에서만 예쁜 도트가 흔하다(128차).
6. **호버 팝업은 앵커 확장 + 실시간 갱신**(128차) — 커서 추종 금지(대상 위에서 흔들린다).
   대상 rect를 앵커로 **여유 공간이 큰 쪽**으로 펼치고(`RegionHud.anchorTip` 전례), 앵커는
   **형제 항목을 덮지 않는 범위**로 잡는다(칩 하나가 아니라 스트립 전체 박스).
   시간이 흐르는 값(남은 시간·게이지)을 띄우면 **갱신 훅**을 걸어 매초 다시 그린다.
