# Pixel Angler The Real — Pixel-Perfect Korean Sea Fishing Simulator

> **2D 픽셀 퍼펙트 한국 해양 낚시 시뮬레이터 + 생활 경영 RPG**
> PC (Tauri v2 데스크톱 앱) · 추후 Steam 출시 목표

OpenStreetMap 실지형, Sentinel-2 위성 피복, 실측 연안 수심, 물때(1~15물), 공공 OpenAPI(기상청·해양기상·
바다낚시지수·경락 시세·어획량 통계)를 게임 물리에 직접 연동하는 **리얼리즘 낚시 시뮬레이터**입니다.

### 낚시 파이프라인 (1인칭)

```
탑다운 조준 캐스팅 ─→ 착수 ─→ 1인칭 낚시 뷰 ─→ 입질 시퀀스 ─→ 챔질 ─→ 파이팅 ─→ 랜딩 ─→ 보관/방생
  마우스 각도+파워      실측 수심   침강·조류 존·정렬도   초릿대 3단계     우클릭    물리 텐션+3D 운동  쿨러/인벤토리
  3D 탄도+바람/비       여 밭 판정  뒷줄견제(H)·밑밥(C)   구부러짐 읽기            거리=랜딩 진행도   선택 팝업
```

| 모듈 (`@tra/core`) | 역할 |
|---|---|
| `CastingPhysicsEngine` + `CastWeather` | 완력×파워×조준 3D 탄도 · **풍속 3m/s 초과부터 맞바람 비거리 감소**(9m/s ×0.73) · 옆바람 산포·착수점 밀림 · **비 = 유속 ×1.27·밑걸림 ×1.33** · 400ms 홀드 = 필요 파워 눈금 역산 |
| `UnderwaterSinkPhysics` | 라인각 모델 침강 — `tanθ = k·유속 / W^n`, 무게가 조류를 못 뚫으면 표층 쓸림(swept) |
| `TidalCurrentEngine` | 조수·반탄류·**조경지대**(입질 1.6배 Hit Zone)·횡조류·본류 — 존별 유불리 |
| `LineTensionPhysics` | 뒷줄견제 = 그 지점 홀드, 목줄 정렬도 A(0~1), 조류 하류 스트리밍 |
| `ChumPhysics` | 밑밥 파슬 3D 확산·조류 감쇠 침강·지형 코팅 → **3차원 동조율**(수심 창 × 수평 근접 × 신선도) |
| `BiteSequenceEngine` | 입질 → **초릿대 구부러짐 3단계**(20°/35°/50°) → 챔질 성공률 5%/20%/100% + **입질 유도**(릴링/견제 → 70% 3단계 승격) |
| `BiteProbabilityEngine` | P = P_base × M_지형 × (1+k·A) × M_리액션 × M_밑밥 × 피딩활성 + 밑걸림(지역 위험도 연동) |
| `FeedingTimeCalculator` | **피딩타임** — 계절 시간창 × 조류(만조 전 피크) × 날씨(저기압·냉수대) → 0.2~1.5 활성 배율 |
| `FishSpawningOracle` | **어종 마스터 56종** — 서식지/수심층/미끼 선호/성전환/금어기·금지체장/물때 활성도/주야간 + **체장-체중 관계(LWR)** |
| `SizeTierRules` | **크기 등급(소/중/대)** — 루어 무게↑=대물 가중, 청물 야간=소형만, 급심 게이트, 농어 포말대 예외 |
| `SeabedProfile` | 유저↔착수 지점 **연속 해저 지형**(암초 융기·수초·모래) — 침강 한계·여밭 판정·수심 모식도의 단일 기준 |
| `LuresCatalogDB` + `LureRig` | **루어 8종 17변종**(웜/저크베이트/미노우/스푼/스피너/에기/메탈지그/타이라바) — 침강 타입·C_d·대상 어종 가중을 데이터로만 표현 |
| `RigRecommender` + `SinkerDatabase` | 지역/지형/물때/대상어종 → 조법·찌·**무게추 봉돌 종류·호수**·미끼 추천 (U창·상점 '추천' 마크) |
| `FightingPhase` + `FightPhysics2D` | **물리 텐션** = 체중 × (정적하중 + 어종군 버스트 × 패턴 × 대응) ÷ 라인 강도 · **거리 = 랜딩 진행도 / 제압도는 별도 축** · 도주는 언제나 플레이어 반대쪽 · 드랙은 감는 중에도 미끄러진다 |

#### 어종별 무게와 체형 (133차)

- **체장-체중 관계(LWR)** — `W = a·L^b`(FishBase 표준형)로 56종 전수 보정.
  지수 3 고정 모델은 체형을 못 담아 **갈치 1m = 10kg**(실제 ≈ 0.7kg)이었다.
  감성돔은 실측표 회귀 `a 0.0179 · b 2.95` → 40cm **953g** / 50cm 1.84kg / 60cm 3.15kg.
- **비만도** — 겨울 +7% · 산란기 +9% · 산란 직후 −8% · 개체차 ±5% → 상세보기에 `115% · 아주 통통함`.
- **체형 7종 파이트 배수** — 어종군 버스트(힘의 **크기**)와 **직교**하는 힘의 **성질**:
  장어·리본형(갈치·붕장어·갯장어) = 정적하중 ×0.55 · **1.2Hz 요동** · 바늘빠짐 ×1.45 /
  납작형(광어·가자미·양태) = 정적하중 **×1.9**(판자 저항) / 방추형 = 거리 저항 ×1.15.

- **조작**: 우클릭 = 챔질 · 좌클릭 홀드 = 릴링 · ←/→ = 채비 횡 이동 / 파이트 로드 스티어 ·
  H = 뒷줄견제 · ↑ = 리프트 / 버티기 · 탭 = 호핑 · 더블탭 = 트위칭 · C = 밑밥 · I = 인벤토리
- **낚싯대**: 5절 로드 + 스피닝릴 렌더, 하중 방향으로 초릿대 벤딩(축 재교차 금지·전방 말림). 설정에서 **로드 위치·릴 핸들 좌/우** 선택
- **조법**: 반유동 / 전유동 / 잠길찌 / **원투**(무게추 봉돌·초릿대 끝 입질 · T자 천평·카드 채비 다관점 히트) /
  **루어 모드**(에기 = 두족류 전용 스폰 바인딩 · 타이라바 = 참돔)
- 실패 시 유형별 **채비 손실**(미끼 털림/목줄 터짐/찌 터짐/밑걸림) — 루어는 목줄째 터질 때만 손실

- **장비창 = 인체 배치형** — 머리/어깨/상·하의/장갑/손(좌·우)/반지/신발 … 착용품은 **인벤토리 그리드에서 이탈**, RPG식 드래그 장착 + 우클릭 해제
- 활용(U) 창: 채비하기 · 요리하기(도마 드래그 + 손질/회썰기) · 밑밥 품질 · **제작**
- 어획물은 개체별 실측치(어종/길이/무게/성별)를 보존 → 어종·등급·길이·상태 기반 정식 판매가 산정

## 시작하기

```bash
# 요구사항: Node ≥ 20, pnpm ≥ 9
npx pnpm install

# 개발 서버 (dev에서는 vite 프록시로 전 API 실데이터)
npx pnpm --filter @tra/client-pc run dev   # → http://localhost:5173

# 전체 빌드 / 타입 체크
npx pnpm run build                                  # 3/3 패키지
npx pnpm --filter @tra/client-pc run typecheck
```

> ⚠ **`--filter @tra/client-pc run build`만 단독으로 돌리지 말 것.**
> client의 `tsc`는 `@tra/core`를 소스가 아니라 **`packages/core/dist`** 로 해석하므로,
> core를 빌드하지 않으면 신규 export가 전부 *"has no exported member"* 로 뜬다.
> 루트 `npx pnpm run build`를 쓰면 turbo가 core → client 순으로 빌드한다.
>
> core를 재빌드한 뒤 dev 서버를 쓸 때는 vite 사전번들 캐시도 지워야 한다
> (안 그러면 인게임이 **조용히 옛 core를 본다**):
> `Remove-Item -Recurse -Force packages\client-pc\node_modules\.vite`
