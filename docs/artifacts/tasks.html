멀티 서버 권위 · NAT · 패키징

공유 원장이 생길 때 서버 권위와 아이템 서명(플리마켓의 선행 조건) → NAT 통과(릴레이 또는 Steam 네트워킹) → Phase 9 Tauri · Steam.

착수 전 확정할 3가지

1. E2 수조의 성격 — 판매용 활어 보관(신선도 정지)만인가, 키우는 양식까지인가.   2. E5 경영의 첫 형태 — 식당 납품 계약부터인가, 직접 가게 운영부터인가.   3. 배 출조의 방식 — 선상 낚시 장면(드리프트)을 새로 만드는가, 이동 컷씬 + 새 지역 필드로 가는가.
