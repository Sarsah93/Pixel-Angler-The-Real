# 배경음 후보 초안 (253차 · Lyria)

- 생성기: `tools/gemini_bgm.cjs` — 장면 9곳 표(`TRACKS`) + 공통 꼬리(보컬 없음 · 반복 재생 · 큰 클라이맥스 없음).
- 모델: `lyria-3-pro-preview`(응답 기록상 `lyria-3.5`) — 곡마다 약 2분 14초 ~ 2분 58초, 44.1kHz 스테레오 192kbps MP3.
- `_log.jsonl` = 곡마다 모델 · 걸린 시간 · 길이 · 구간 표시 · 한국어 설명 · 영어 프롬프트(다시 뽑을 때 그대로 쓴다). 1판 9곡 + 2판 7곡(파일 이름 `.v2`).

## 사용자 의견과 2판(253차)

| 곡 | 1판 의견 | 2판 |
|---|---|---|
| menu | 괜찮아 보임 | 그대로 |
| field_day | 비트가 빨라 신나 보임 → 산뜻하되 절제 | 손가락 기타 · 목관 · 타악 거의 없음(측정 템포 96 → 83) |
| field_day_chip | 괜찮아 보임 | 그대로 |
| field_night | 괜찮아 보임 | 그대로 |
| fishing_wait | 더 느린 곡 | 박자 없는 패드 · 띄엄띄엄 피아노(76 → 60) |
| home | 카페 노래 같음 → 주인공 집 설정 | 두 판 — (가) 아버지가 남긴 옛집 · 업라이트 피아노 · 오르골 / (나) 기타 · 풍금 · 클라리넷 · 둘 다 드럼 · 재즈 화성 없음 |
| farm | 조금 더 느긋하게 | 76BPM(89 → 76) |
| market | 중국풍 · 신남 → 절제 | 두 판 — (가) 아코디언 · 기타 · 서양 포크 화성(103 → 89) / (나) 부드러운 칩튠 + 기타(86) |
| rain | 필요 없음 — 빗소리는 효과음으로 | 뺐다 → 날씨 환경음(효과음) |

- **MP3 파일은 저장소에 넣지 않았다**(9곡 약 34MB). 253차 대화에서 사용자에게 보냈고, 고른 곡만 반복 이음매 · 음량을 맞춰
  `packages/client-pc/public/audio/`로 넣는다(백로그 BZ).

다시 뽑기:

```bash
NODE_USE_ENV_PROXY=1 node tools/gemini_bgm.cjs --out <폴더> --only menu,rain --tag v2
```
