## 3. 동작 구조
```
필드 오브젝트 = 초기(HOMETOWN_OBJECTS) − removed + moved + placed   → effectiveObjects()
설치: 인벤 '설치하기' → placement-request → 그리드 오버레이
      footprint 프리뷰(초록 가능 / 빨강 불가) → 클릭 설치(아이템 1 소모)
      [E] 회수 = 아이템 반환 (이동 = 회수 후 재설치)
저장: locationTag 'hometown_interior' 에서만 canSaveHere() → 침대 [저장하고 쉬기]
교통: 출조 = ₩10,000 차감 / 귀가 = 무료
텃밭(235): 개간 키트 설치(마당 풀밭 4×3) → [F] 텃밭 창 → 호미로 갈기 → (퇴비) → 심기(씨앗 · 모종 · 종구) → 물
      → FarmSim이 한 시간 단위로 굴림(꺼 둔 동안도 · 최대 400일) → 다 익으면 거두기(등급 꼬리 _sp/_nm)
      실내: 콩나물 시루 · 수경 재배기(가구) → 집 안 [F] 기르기 선반(4칸)
      판매: 식자재마트 · 식당만 산다(그날 시세 × 신선도 × 0.7) · 요리: 가게 채소면 5번째 별 막힘
```

## 5. 잔여·차기 — 농장 경영 로드맵 (E1~E5, 099 조사 기반)

**실상(2026-08-14 전수 조사)**: 동작하는 것은 **칸 단위 설치/회수뿐**. 농사·수조·하우스Tier·
벌목/채굴/채집/보트는 전부 타입·"추후" 안내 스텁이다(`till` 핸들러는 코드에 아예 없음 ·
`HOUSE_TIERS`는 어디서도 소비 안 됨 · `AquariumState.fish`는 `unknown[]`).

**선행 결정 — 시간 모델**: 게임 시계는 실시간(`getCurrentGameMinute` = wall-clock).
압축 달력을 새로 만들지 말고 **쿨러·냉장고의 "오프라인 경과" 패턴 재사용**
(작물 = `plantedAt` 절대 시각 기준 lazy 성장, 계절 = 실제 월) — 정체성 일치·재작업 최소.

- **E2 수조 (먼저 — 소~중)**: 190차에 **관상 수조는 실내 가구로 먼저 열었다**(`HomeStore.tanks`). 남은 것은 상업용 활어 수조 —
  `AquariumState` 실타입화(InvItem[]) + 세이브 직렬화 +
  `freshnessMult`(0.1) 소비(활어 신선도 정지 = 경제 직결) + 패널 UI(쿨러 패널 재사용) +
  실내(interior) 배치 개방(현재 exterior만 — `aquarium_display`는 설치 불가 상태).

### 농사 — 235차 확정 · 구현 (234차 추천안 2번)

실제 시간 · 실제 계절은 그대로, 매일 할 거리는 원래 빠른 작물 · 중간 수확 · 시설로 만든다(집 전체 고정 배율 없음).

- 빠른 작물: 콩나물 · 숙주 · 새싹채소 · 느타리 · 노루궁뎅이 · 목이(실내) · 상추 · 깻잎 잎 따기 · 부추 · 쪽파 베기.
- 중간 수확: 솎음 배추 · 무 · 고구마순 · 마늘종 · 고춧잎 · 호박잎 · 고추냉이 잎(`interim`).
- 모종 = 육묘 3~6주를 건너뜀 · 씨앗은 싸고 느림(섬 = 1 − (1 − 발아율)^2.5 · 발아율 50~92%, 실험실 기준 이하).

## 6. 함정·불변조건
1. **초기 오브젝트는 core TS 데이터**(JSON 아님) — 타입 안전 + 파이프라인 재생성 없이 조정 가능. 타 지역으로 확산되면 JSON 스키마 이관 검토.
2. **저장은 집 침대뿐** — 새 씬을 만들 때 `locationTag`를 설정하지 않으면 저장 불가가 기본값(의도).
3. Phaser `Container.body`는 예약 프로퍼티 — 필드명 충돌 주의(`gridC` 사용).
4. 실내 캐릭터도 `PLAYER_FOOT_SINK` 접지 보정을 적용한다(스프라이트 하단 여백).
5. **실내 [F]는 할 수 있는 일이 있는 가구에만** 뜬다(189 — 사용자 지시). 첫 입장 혼잣말(`LOOK_TEXT`)을 [F]로 되풀이하지 않는다.
   새 가구에 기능이 없으면 `FURN_DEFS.action`을 비워 둔다. 닿는 거리는 발밑 ↔ footprint 가장자리 26px(옆 칸에 서야 닿는다).

18. **`maxPerPurchase`는 한 번에 사는 수지 총량 상한이 아니다**(236) — 235차까지 텃밭 구획 상한이 없어 풀밭 927칸에 70구획 남짓이 들어갔다.
