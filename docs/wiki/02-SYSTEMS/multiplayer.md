# S24 — 싱글/멀티플레이

> 상태 🔶 **부분** (143차 신설 · 145차 세션 세계) — 로비·세션·이름 유일성·같은 지역 이름표에 더해
> **설치 통발 공유 · 공용 시드 · 외형/활동 · 피어 밀어내기 · 지역 채팅 · 이어하기 · 유저 간 거래(146차)**까지.
> 진행도(퀘스트·우호도·인벤·재화·어획)는 **설계상 계속 각자의 것**이다. 남은 것은 서버 권위.

## 1. 목적·범위

**책임진다**

- 플레이 방식 선택(혼자 / 여럿이)과 그 진입 순서
- 세션(= 한 세계) 열기·참가
- **세션 안 캐릭터 이름 유일성**
- 같은 지역에 있는 사람의 위치·이름표

- **세션이 공유하는 세계** — 공용 난수 시드 · 설치된 통발 · 지역 채널 채팅
- 접속이 끊겨도 자리를 기억하는 **이어하기**
- **유저 간 거래**(146차) — 서버는 공증인. 인벤토리는 각자 로컬, 도장 찍힌 기록만 서버가 든다
- **정보 보기**(146차) — 레벨·장비·면허·최대어·출조만

**책임지지 않는다** (설계상 — 145차 사용자 결정)

- **진행도 동기화**(퀘스트·우호도·인벤·재화·어획) — 서로 진행도와 분기가 다르므로 각자의 것이다
- 플리마켓·유저 경매 **원장**(계약 `MarketListing`만 있다 — 서버 서명 뒤)
- 서버 권위 판정(치트 방지) — 공유할 원장이 생기는 시점의 과제

## 3. 동작 구조

```
메인 메뉴 ─ 게임 시작 ─┬─ 혼자 하기 ─────────────→ 슬롯(새로/이어) ─→ (새로면) 캐릭터 만들기
                       └─ 여럿이 하기 ─ 로비 ─ 방 열기/코드 참가 ─→ 슬롯 3칸 ─→ 캐릭터 만들기
```

캐릭터 만들기 `[이대로 생성하기]`

| 단계 | 화면 문구 | 하는 일 |
|---|---|---|
| 1 | `중복 여부 확인중` | `POST /mp/session/:code/name-check` |
| 2a | `중복 여부 통과` | 통과 |
| 2b | **빨간 글씨** `캐릭터 이름이 중복되어 생성할 수 없습니다! 이름을 변경하세요.` | 중단(재시도 가능) |
| 3 | `생성 중 로딩` | `POST /mp/session/:code/join` (이름 선점) |
| 4 | `접속중` | 필드 진입 · 위치 폴링 시작 |

싱글이면 3단계만 짧게 지나간다.

**REST 목록**

| 메서드 | 경로 | 하는 일 |
|---|---|---|
| POST | `/mp/session` | 방 열기 → 6자리 코드 |
| GET | `/mp/session/:code` | 방 조회(인원·이름 목록) |
| POST | `/mp/session/:code/name-check` | 이름 형식 + 중복 |
| POST | `/mp/session/:code/join` | 이름 선점 + playerId 발급 |
| POST | `/mp/presence` | 내 위치 올리고 남의 위치 받기 (1초) |
| POST | `/mp/leave` | 나가기 (**자리는 남긴다** — 이어하기) |
| POST | `/mp/trap/place` | 통발 설치 알림 (같은 칸 중복 거절) |
| POST | `/mp/trap/remove` | 통발 회수 알림 (남의 것 거절) |
| POST | `/mp/trade/propose` | 거래 제안 (거리·바쁨·거래 중 검사) |
| POST | `/mp/trade/respond` | 수락/거절 |
| POST | `/mp/trade/offer` | 내 제안 갱신 (**양쪽 잠금 해제**) |
| POST | `/mp/trade/lock` | 잠금(1단계) / 확정(2단계 — 양쪽이면 committed) |
| POST | `/mp/trade/cancel` | 취소 (committed는 거절) |
| POST | `/mp/trade/applied` | 내 인벤에 적용했다 |

`/mp/presence`는 **편승 채널**이다 — 위치와 함께 `activity`·`look`·`say`(채팅)를 올리고,
같은 응답으로 `peers`·`traps`·`chat`을 받는다. 왕복을 늘리지 않는다.

## 5. 잔여·차기

- **서버 권위**는 공유 원장(공유 경제·랭킹·거래)이 생기는 시점의 과제다. 지금은 공유할 원장이 없다.
- **NAT 통과** — 브라우저가 남의 공유기 뒤 IP에 평문 HTTP로 붙지 못한다.
  경로는 ① LAN·포트포워딩(지금) ② 얇은 릴레이 ③ Phase 9 Steam 네트워킹.
- **홈타운 설치물**(텃밭·울타리·수조) 공유 — 통발과 같은 방식으로 확장 가능하나,
  홈타운은 각자의 집이라 공유할 이유가 약하다. 사용자 판단 대기.
- **로비 '이어서 들어가기' 버튼** — 지금은 불러오기 슬롯을 고르면 자동으로 재접속한다.
- **플리마켓·유저 경매** — 등록 = 서버 소유 이전(에스크로) · 구매 = 서버 안 소유권 이동 · 수령으로 반입.
  ⚠ 로컬 세이브가 수정 가능하므로 **서버가 아이템에 서명**하기 전에는 열지 않는다. 타르코프식 카테고리 트리 UI는
  `paintHudPanel` 문법 안에서 나중에.

### 배포 모델 (145차 결정)

**호스트-클라이언트 P2P.** 호스트가 같은 `@tra/server`를 자기 PC에서 돌린다 —
코드 경로는 같고 배포·NAT 이야기만 달라진다. 전용 서버는 **다른 코드가 아니라 배포 선택지**다.

저장 소유권: **호스트 = 세계(설치물·시드·시간) / 각자 = 자기 캐릭터**.
세션 파일은 `MP_SESSION_DIR`(기본 `.mp-sessions/`)에 세션당 JSON 한 장.

## 6. 함정·불변조건

- **`types/Multiplayer.ts`는 양쪽이 같이 읽는 계약**이다. 여기 모양을 바꾸면 서버와 클라이언트를
  같이 고쳐야 한다 — 한쪽만 고치면 조용히 어긋난다(응답 필드가 `undefined`가 될 뿐 에러가 안 난다).
- **이름 유일성은 세션 범위**다. 세션이 다르면 같은 이름이 있을 수 있다.
  `characterNameKey`는 공백·대소문자만 접는다.
- **서버가 없어도 게임이 멈추면 안 된다** — `MultiplayerClient`의 모든 요청은 실패 시 `null`을
  돌려주고 `offline` 플래그만 세운다. 새 호출을 추가할 때 이 규칙을 깨지 말 것.
- **`reportPosition`은 `RegionFieldScene.update`에서만 부른다.** 1인칭 낚시·상점은 필드를
  `pause`하므로 그 사람은 마지막 자리에 서 있는 것으로 보인다(사라지지 않는다) — 의도된 동작이다.
- **피어에게 물리 바디를 달지 말 것** (145차 결정). 좌표가 1초 폴링이라 정지 바디를 달면
  순간이동한 유령에 내가 끼인다. 밀어내기는 **내 바디만** 민다(`applyPeerPush`) —
  양쪽이 각자 자기를 미므로 결과가 대칭이다. 막힌 칸 방향으로는 밀지 않는다.
- **분리 벡터가 0이 되는 경우**를 반드시 다룰 것. 두 사람이 정확히 같은 좌표면 `(dx,dy)=(0,0)`이라
  밀어내기가 영영 동작하지 않는다 → `playerId` 비교로 서로 반대 방향을 고른다.
- **Phaser는 `stopPropagation`으로 막히지 않는다.** 같은 DOM 이벤트로 `keydown-B` 같은 조합 이벤트를
  따로 emit한다(실측: 채팅에 `b`를 치면 쿨러가 열렸다) → 채팅 입력 중에는
  `input.keyboard.enabled = false`로 플러그인을 끄고 window에서 직접 받는다.
  **씬을 떠날 때 반드시 되켤 것**(`shutdown`에 `endCompose`).
- **공용 시드는 위치 기준까지 바꿔야 의미가 있다.** 구 보일링은 발생 지점을 **플레이어 ±26타일**에서
  골랐다 — 시드를 공유해도 기준점이 다르면 다른 자리가 나온다. 이벤트는 **맵 격자 칸의 성질**이어야 한다.
- ⚠ **퀘스트 게이트 규칙.** 진행도가 조건에 끼어드는 무작위는 `MpSharedRngKind`(닫힌 유니온)에
  넣지 않는다 — 아직 그 단계가 아닌 사람 화면에 뜨거나, 같은 단계라도 한 사람이 먼저 가져가면
  다른 사람의 목표가 사라진다. 유니온에 손을 대야만 늘어나는 것이 그 자체로 관문이다.
- **차량은 초기 편성만 같다.** 걸음이 프레임 dt로 밀리므로 시간이 지나면 위치가 갈린다.
  배경 차량에 좌표 복제 대역폭을 쓰지 않는다(게임플레이 영향 0).
- **이름은 7일간 잠긴다.** 접속을 끊어도 자리를 남기므로 그 이름을 다른 `userId`가 쓸 수 없다.
- ⚠ **`userId`는 브라우저 localStorage에 있다.** 브라우저를 바꾸거나 저장소를 지우면 **다른 사람**이 된다.
- **멀티 동기화는 `uiBlocked` 가드 앞에서 돈다**(146차). 뒤에 두면 팝업을 여는 순간 남이 얼고 확정 거래가 적용되지 않는다.
- **"보냈다" 판정은 플래그가 아니라 실은 객체로**(146차). 요청이 나는 사이에 `setProfile/setLook`이 불리면 플래그만 보고는 영영 안 올라간다.
- **거래로 받은 개체는 새 id**(`_t<시각><순번>`) — 내 순번만 붙이면 dev 시드와 겹쳐 한 스택으로 합쳐진다.
- **`addCoins(…, quiet)`는 거래 경로 전용** — 다른 데서 쓰면 `earn` 목표가 조용히 죽는다.
- **영속 검증 함정**: 서버를 "재시작"할 때 옛 프로세스가 살아 있으면 새 인스턴스가 `EADDRINUSE`로 죽고
  **옛 메모리가 응답**한다. `[mp] 저장된 세션 N개 복원` 로그만 보고 통과시키면 영속을 검증한 것이 아니다.
- **헤드리스 검증 함정**: 두 번째 탭은 소프트웨어 WebGL로 떨어져 ≈5fps다. Phaser `delayedCall`은
  게임 루프 델타로 진행하므로 대기 시간이 실시간 몇 배로 늘어난다. 하네스 대기를 넉넉히 잡을 것.
