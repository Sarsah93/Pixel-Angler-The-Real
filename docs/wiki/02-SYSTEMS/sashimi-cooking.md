# S4. 회썰기 · 플레이팅 · 요리

> 상태 **🟢 운영**(회·접시) / **⬜ 미착수**(불요리·스시).
> 관련 차수 65·66·68·69·73·74·75

---

## 1. 목적·범위
손질 산출물(순수 필렛·엔가와)을 **회 조각 → 접시 완성품**으로 만들고 값을 매긴다. 불을 쓰는 조리는 미착수.

## 2. 구성
| 계층 | 파일 | 역할 |
|---|---|---|
| core | `db-schema/SashimiSlicing.ts` | 모드 2종(일반 14컷 세로 / 고급 16컷 사선) · 크기 등급 · `buildSashimiCutPaths` · 엔가와 2컷 |
| core | `MIXED_SASHIMI_PRICING` / `SINGLE_SASHIMI_PRICING` (`types/Economy.ts` 계열) | 모듬 고정표 / 단품 = kg시세 × 필요원물 ÷ 실수율 × 인분마진 |
| client | `ui/SashimiPanel.ts` | 썰기 모달 — 뷰 분기(탑/측면/엔가와 스트립) · 컷 분리 팬아웃 |
| client | `ui/UtilizationPanel.ts` | 도마 스테이징 · 접시 플레이팅 · [사시미 만들기]/[불요리(비활성)] |
| client | `data/SashimiFilletProfiles.ts` | 실루엣 프로필(자동 생성 — 수동 편집 금지) |
| tools | `gen_sashimi_fillet.cjs` | 필렛 3뷰(탑·측면·조각) 생성 |

## 3. 동작 구조
```
순수 필렛 ─드래그→ 도마 ─[일반/고급 회뜨기]→ SashimiPanel(모달)
   컷 = 머리쪽(우) → 왼쪽 순서 · 성공 시 조각 분리 팬아웃
   → 회 조각 N개(inv_sashimi_cut_…) : 원물 가치 승계
도마 조각 스테이징 ─한 점씩 드래그→ 접시(소/중/대/특대)
   4방위 × 방위당 4~7점 · [접시 돌리기]로 방위 전환 · 만석 시 안내
   → [사시미 완성] : 2종 이상 = 모듬(고정가+g 하한) / 1종 = 단품(kg시세식)
```
- **가치 규칙**: 조각·필렛 체인은 **원가 승계**, 부가가치는 **접시 완성 시점**에만 실현.
- 완성 접시는 **0.6 매입 할인 미적용**(책정가 그대로 판매).

## 4. 세부과제 현황
| 과제 | 상태 | 차수 |
|---|---|---|
| 회썰기 미니게임(2모드) | ✅ | 65 |
| 뷰 매핑 정정(일반=탑뷰 / 고급=완만 슬랩 측면) | ✅ | 65 후속 |
| 접시 플레이팅(4방위·회전·완성) | ✅ | 66 |
| 가격 체계(원가 승계 + 접시 실현) | ✅ | 66·68 |
| 접시 회전 렌더 실버그 수정 | ✅ | 73 |
| 도마 조각 스테이징 → 접시 드래그 | ✅ | 69 |
| 광어 3뷰 실사 + 엔가와 회썰기(2컷 3조각) | ✅ | 74·75 |
| **스시**(고급 조각 '요리하기') | ⬜ | 스텁만 존재 |
| **불요리**(화구·용기) | ⬜ | 버튼 비활성 상태 |
| 두족류 슬라이싱(`whole` 모드·어슷썰기) | ⬜ | 두족류 트리 ⑧단계 |
| 접시 배치 상태 세이브 | ⬜ | 현재 세션 메모리(닫으면 반환) |

## 5. 잔여·차기
불요리 시스템(화구·용기 아이템 → CookScene 실조리)이 스시·구이·탕의 공통 선행. 두족류 트리 완료 후 착수 예정.

## 6. 함정·불변조건
1. **접시/조각은 패널 파괴 시 전량 반환** — 아이템 유실 금지 규칙(61차 이후 공통).
2. 조각 배치는 **세션 메모리** — 세이브에 없다. 저장 대상으로 바꾸려면 스키마 추가 필요.
3. `SashimiFilletProfiles.ts`는 생성기 산출물 — 손으로 고치면 다음 재생성에 사라진다.
4. 도마 필렛 방향 규칙 = **꼬리 왼쪽·머리 오른쪽**(`MIRROR_KEYS`로 원본 반전).
