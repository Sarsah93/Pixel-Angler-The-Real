# S1. 낚시 루프 (캐스팅 → 입질 → 파이트 → 어획)

> 상태 **🟢 운영** — 핵심 루프 완성, 확장(어탐)만 남음.
> 관련 차수 9·11·12·15~19·24·25·28~30·32~37

---

## 1. 목적·범위

탑다운 필드에서 **캐스팅 착수** → 1인칭 전환 → 물속 시뮬레이션 → 어획까지. 손질/판매는 다른 시스템.

## 3. 동작 구조

```
[탑다운] 좌클릭 유지 → 차지 → 릴리즈 → 탄도 비행
        └ 게이트: 손 착용 낚싯대 · 착수점=바다 · 릴링 경로에 육지 없음 · 자전거 미탑승
[착수] → pause+launch → 1인칭
   ① 드리프트   침강(라인각) · 조류 5존 · ←→ 채비 횡이동 · H 홀드 · C 밑밥
   ② 입질       BiteSequenceEngine 3단계(찌 잠김 α 연동) — 확률 = P_base
                 × 지형 × 정렬도 × 액션(루어) × 밑밥동조 × 피딩타임 × 낚시지수
   ③ 챔질       우클릭 — 1단계 5% / 2단계 20% / 3단계 100% (릴리즈 후 실패)
   ④ 파이트     텐션 30~80 유지 · ↑버티기 · ←→ 로드 스티어 · 피로 SPENT → dragIn
   ⑤ 회수·랜딩  거리→크기/투명도 수렴(70% 지점 2배) · 발앞 3m 랜딩
   ⑥ 결정       [쿨러] / [인벤토리] / [방생]
[회수] 릴링으로 0.5m 도달 = 채비 회수 → 탑다운 복귀
```

## 5. 잔여·차기
- **대물 텐션 밸런스(F8)** — 132차 시뮬 실측: 3kg 참돔/5kg 라인 줄터짐 **약 48%**,
  1.2kg 감성돔/2.7kg 목줄은 **패턴 중 릴링 시 85% 파단 / 정석 펌핑 시 85% 랜딩**.
  체급이 오르면 "패턴 중에는 감지 않는다"가 요구되는 구조(안내문에 반영)지만 수치는 조율 대상.
- **파이트 타이밍 미세 조정** — 복섬 10m 실렌더 6~7초(목표 10초). 손잡이는 `fightDist.reelBaseMps`·`resistFrac`.
- 어탐 레이더(D1 구조는 준비됨) · 사운드 · 삽화 교체(`help_fp_fight` 실캡처) · `fightPhys`·`castWeather` F8 확정.
- 파고(`waveHeightM`)는 아직 채집 차단에만 쓰인다 — 캐스팅·조류 연동은 미착수(127차 잔여).
- 홈타운은 기상청 격자가 없어 풍속 0 — 지역 필드에서만 바람이 실제로 분다(127차).
- 신규 해양 API 5종(어초·해수유동·수치조류도·수심·조석예보) 연동 — `IMPLEMENTATION_PLAN` Q5.

## 6. 함정·불변조건
1. **1인칭은 `pause + launch` / 복귀는 `stop + resume`** — `scene.start` 금지.
2. **조류 드리프트 거리 하한**(0.3m)이 회수 판정(0.5m)보다 커지면 영원히 회수 불가 — 19차 실버그.
3. 입질 확률 배율은 **곱 체인**이다. 새 요소를 넣을 때 기존 배율을 대체하지 말 것(중복 확률식 금지).
4. `FightingPhase`는 프레임레이트 정규화(`1−exp(−rate·dt)`)를 지킨다.
5b. **`result` 상태는 시뮬을 멈춰야 한다**(119차) — `update()`가 상태와 무관하게 조류를 적용해
    어획 후에도 `distM`이 반탄류로 **늘어났다**(= 물고기가 뒤로 가는 연출). 결과 상태에서는
    `lastTidal`을 고정하고 tide를 0으로 두며, 남은 거리는 `LANDED_PULL_MPS`로 발앞(0.3m)까지 당긴다.
    좌클릭 릴링도 `fpState === 'result'`에서 차단한다(배경 클릭으로 릴링 연출이 진행됐다).
5. FP 씬 ESC는 popupStack이 아니라 **하드코딩 순서**(인벤→쿨러→종료) — 강제 방생 `lockedOpen`이 얽혀 있다.
6. **물리 텐션에서 드랙 상한은 "릴을 안 감을 때" 전부**에 건다(117차) — 홀드에만 걸면 대물이 버티기 중에 터지고,
   전부 빼면 소형이 안전 밴드 아래로 떨어져 바늘이 빠진다(`reelLoadKg`로 보정). 정석 = 달려 보내며 피로 대기 → 감기.
7. 튜토리얼 플래그(`guideSeen.<cat>`)는 **[다시 표시하지 않기] 체크 시에만** 기록 — 열기 전에 기록하면 재표시 경로가 없다.
8. 필드 씬 `pointerdown`은 `over`(인터랙티브 오브젝트 목록)를 먼저 본다 — HUD·버튼·팝업 위 클릭은 맵 클릭이 아니다(118차).
9. **캐스팅 날씨 계수(127차)**: 비거리는 `speedMult`(수평 속도 전체), 밀림은 `crossWind`(비행 중 가속) —
    **둘을 한쪽에 몰아 넣으면 이중 계산**이다. 완력에 배율을 곱하는 방식은 효과가 7%뿐이라 폐기(실측).
11. **랜딩 진행도는 거리다**(132차) — 진행도를 별도 시계로 굴리면 거리와 어긋나 "발앞인데 진행도가
    뒤쳐지는" 증상이 난다. `landProgress()` 하나를 상단 진행 바·수심 패널 거리축이 함께 쓰고,
    `FightingPhase.progress`는 그 주입값의 미러다. 클래스 내부의 "굴복" 축은 `subdue`로 분리돼 있다.
12. **무대 좌표(f2dPos)는 물리에서 파생된다**(132차) — 구 구현은 무대에서 추진·견인을 따로 적분해
    거리·수심과 따로 놀았다. **이중 시뮬 금지**: `updateFight2DSim`은 heading만 계산한다.
13. **릴링 중 거리는 절대 늘지 않는다**(132차 · 사용자 요구) — `reelHoldCap`이 도주 전진을 회수 속도
    아래로 묶는다. 손을 놓으면 상한이 사라져 줄이 나간다. 저항의 세기는 **회수 속도 대비 비율**
    (`resistFrac`)로 표현하므로 체급이 달라도 "영영 못 감기 / 저항 없이 끌려오기"가 생기지 않는다.
14. **슬랙 바늘빠짐은 체급 게이트가 필요하다**(132차) — 최대 요구 장력이 게이지 임계의 1.5배를 못 넘는
    소형어는 "느슨하게 줬다"가 성립하지 않는다. 게이트가 없으면 24g 복섬은 바늘털이에 **정대응할수록**
    바늘이 빠진다(시뮬 67%).
15. **헤드리스로 파이트 시간을 벽시계로 재지 말 것**(132차) — 헤드리스 rAF는 초당 2회 수준이고
    `dt`가 0.05로 클램프돼 10m 파이트가 **110초**로 측정된다. `fp.update(now, 16.67)` 수동 스텝 +
    `fightElapsedSec`(게임 시간)으로 잰다.
10. **강수는 조류·밑걸림을 함께 올린다**(127차) — `castWx.currentMult`는 `tideBase`와 `tideStrength`
    양쪽에 곱해야 표시 조류와 실제 드리프트가 어긋나지 않는다. 밑걸림은 `snagMult` 2곳(지형 생성·타이머).
