# 2. 시스템별 세부과제 · 잔여과제

각 페이지는 **동일한 6절 구조**로 쓴다(스킬 `work-log` §2 참조).

```
1. 목적·범위        이 시스템이 책임지는 것 / 책임지지 않는 것
2. 구성             core / client 파일 표 + 역할
3. 동작 구조        상태·흐름·핵심 규칙 (한 눈에 보이는 도식 우선)
4. 세부과제 현황    과제 단위 표 (상태 · 차수 · 근거 링크)
5. 잔여·차기        무엇이 · 왜 남았나 · 착수 조건(선행)
6. 함정·불변조건    건드리면 깨지는 것 (재발 방지 지식)
```
