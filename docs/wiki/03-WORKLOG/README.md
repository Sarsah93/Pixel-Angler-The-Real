# 3. 작업 기록 (WORKLOG)

> **원칙**: 새 작업의 **본문 기록은 여기 1건**에 쓴다. `AGENTS.md` §9와 `IMPLEMENTATION_PLAN.md`에는
> **요약 3~5줄 + 이 파일 링크**만 남긴다. (같은 내용을 세 군데 길게 쓰던 것이 "난잡한 누적"의 원인이었다.)

- 파일명: `YYYY-MM-DD-NNN-슬러그.md` (예: `2026-08-06-080-board-rotation.md`)
- 양식: [`_TEMPLATE.md`](_TEMPLATE.md) — 8절 고정
- 절차: 스킬 **`work-log`** (작업 완료 시 반드시 실행)
