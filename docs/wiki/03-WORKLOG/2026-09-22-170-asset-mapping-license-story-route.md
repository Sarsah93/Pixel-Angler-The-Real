## 1. 배경

사용자 실플레이 준비 중 두 갈래 요청이 왔다.

**① 테스트 경로가 없다.**

> "근데 dev 서버 안열려. 구글 브라우저로 주소창에 'http://localhost:5173/' 쳐서 들어가니까 …
> ERR_CONNECTION_REFUSED 이렇게 뜨고 있어."

**② 에셋 매핑이 어긋났다.** (원문 그대로 — 회귀 판정 기준)

> "두족류 분류에서 '문어'는 없애고, 해루질 가능한 문어는 돌문어야."
> "용치놀래기는 'male'도 이미지가 따로 있는데, 반영이 안되어 있어."
> "돌돔도 30cm 이상 체장에서 수컷 이미지가 따로 있는데, 반영이 안되어 있어."
> "일반 볼락은 제거하고, 열기(불볼락)와 조피볼락 사진은 별도 첨부."
> "쏨뱅이는 'spotbelly_greenling' 이 사진이 되어야 해."
> "적용중인 놀래미는 'spotbelly_rockfish'이 사진이 되어야 하고. (놀래미에 쏨뱅이 사진을 쓰고 있었음)"
> "'통생선 매운탕'과 '서더리 매운탕' 에셋 이미지를 첨부해줄게."

**③ 자격 해금 범위 확정.**

> "너 추천대로 주의할 사항 네 가지 지키는 쪽으로 가고, **자격 부분만 스토리로 얻는 경로를 고민해보자.
> 다른 건 자유도를 해칠 것 같네.**"

## 2. 원인

### 2-1. dev 서버가 사용자 브라우저에 안 닿는 이유 — 확정

서버는 살아 있었다. 컨테이너 안에서 `curl http://localhost:5173/` = **200**이고
`vite.config.ts`에 **`host: true`가 이미 설정**돼 있다(모든 인터페이스 바인딩).

문제는 바인딩이 아니라 **위치**다. 이 세션은 원격 컨테이너에서 돌고, 사용자의 크롬은 사용자 PC에서 돈다.
사용자 PC의 `localhost:5173`에는 아무것도 없다 — 포트 포워딩 경로가 없기 때문이다.
**dev 서버로는 원리적으로 테스트가 불가능**하다.

→ 실제 테스트 경로는 **gh-pages 재배포**다. 직전 배포는 11차(2026-09-18 · 151~153차)라
**154~169차가 통째로 미배포** 상태였다(불요리·요리 개체화·컷씬·NPC 체계·장면 게이트 전부).

### 2-2. 놀래미 ↔ 쏨뱅이 — 파일 중복이 원인

`spotbelly_greenling.png`와 `spotbelly_rockfish.png`는 **md5 동일한 중복 파일**이다.

```
c57b0987764c6aaf0683101997ca952d  spotbelly_greenling.png
c57b0987764c6aaf0683101997ca952d  spotbelly_rockfish.png
```

내용은 둘 다 **쏨뱅이**(얼룩무늬 볼락류 — 육안 확인). 즉 원래 놀래미 사진이 들어 있어야 할 파일이
언젠가 쏨뱅이 사진으로 덮여 쓰였고, 그 파일을 놀래미(`greenling`)가 쓰고 있었다.
**놀래미 전용 실사는 레포에 존재하지 않는다.**

### 2-3. 암수 변형은 인게임에는 있었고 위키에만 없었다

`resolveFishTexture`는 돌돔·용치놀래기 암수를 이미 분기하고 있었다.
어긋난 곳은 **위키 생성기** — `FISH_TEX` 정규식이 `FISH_TEXTURE` 맵만 읽는데 두 어종은 맵에 없어
`fish_<id>_female` 폴백 한 장만 실렸다. 돌돔 임계는 코드가 **40cm**, 사용자 지정은 **30cm**였다.

### 2-4. 매운탕 2종이 같은 그림이었다

`stew_red`(서더리)와 `stew_red_whole`(통생선)은 **`family`가 둘 다 `stew_red`**라
`px:it_dish_${r.family}` 한 줄이 같은 픽셀 아이콘을 물렸다. 재료 구성이 다른데 그림이 같았다.

### 2-5. 「일반 볼락 제거」 해석 — 명시

앞뒤 문장이 전부 **사진↔어종 매핑** 이야기라 **이미지 회수**로 읽었다.
`dark_banded_rockfish`(볼락) **어종 자체는 지우지 않았다** — 퀘스트 2편(M·N)의 목표,
레시피·스팟·지역·조행록 장이 참조하고 있어 삭제하면 **진행 중 세이브가 목표를 잃는다**.
실제로 회수한 것은 청볼락에 잘못 걸려 있던 **일반 볼락 사진**(`dark-banded_rockfish.png`)이다.

## 4. 구조상 위치

```
시스템 S23 캐릭터·에셋      → 어종 실사 매핑        → 이 작업(렌더 층 — 판정 무영향)

시스템 S21 성장·진행       → 자격 취득 경로        → 이 작업(데이터 + 판정 층)
```

- 어종·요리 매핑은 **렌더 층**이다. 스폰·입질·수율·가격은 한 줄도 건드리지 않았다.
- 자격 경로는 **데이터 + 판정 층**이다. `LicenseDef`·`checkUnlockRequirements`는 불변이고,
  면제는 그 앞에 얹는 순수 함수 하나(`applyLicenseWaiver`)다.
- 돌돔 30cm는 `isStripelessMale` **단일 정의**를 고쳤다 — 어획 팝업·인벤·손질 도마가 이 한 줄을 공유한다.

## 5. 자격 이야기 경로 — 설계와 실측

사용자가 승인한 **네 가지 주의사항**을 그대로 강제 장치로 옮겼다.

| 원칙 | 강제 방법 |
|---|---|
| 1. 가산만 | 면허사무소 경로 무수정. 면제는 `applyLicenseWaiver`가 **덮어쓰는 값**일 뿐 |
| 2. 영구 소멸 금지 | 검증기가 `once`·`event` 정책 퀘스트 연결을 거부 — 8건 모두 `standard` |
| 3. 스포일러 금지(R2) | `storyTerms()`가 **진행 중이거나 끝낸 할 일**일 때만 안내 줄을 낸다 |
| 4. 사다리 보존 | `KEEP_ALWAYS = {license_held, quest_completed}` — 구조 게이트는 면제 불가 |

⚖ **레시피·조법은 대상에서 뺐다**(사용자 지시) — 그쪽을 퀘스트 뒤에 두면 "이야기를 안 하면 못 하는 것"이 생긴다.

⚖ **검증기 「메인 전용」 제약은 손대지 않았다.** 면제는 `QuestRewards`가 아니라 **별도 테이블**이라
`skillUnlocks`/`shopUnlocks`의 메인 전용 규칙과 아예 만나지 않는다. 서브 퀘스트 3건도 그대로 경로가 된다.

⚠ **배포본 라이브 검증은 이 컨테이너에서 불가**(`sarsah93.github.io` 접속이 egress 정책에 막혀 `000`).
검증은 **push 직전 배포 번들을 로컬 정적 서버로 실행**해 대신했다(위 표의 「텍스처」·「게임 기동」 행 —
배포에 올라간 것과 **바이트 동일한 산출물**). Pages 빌드 완료 후 라이브 확인은 사용자 몫이다.

⚠ **검증 하네스 함정 (신규)** — `python3 -m http.server`는 charset 헤더를 안 준다.
아티팩트 HTML은 charset meta를 **발행 시점에 스켈레톤이 주입**하므로, 원본 파일을 그대로 정적 서빙하면
브라우저가 latin-1로 읽어 **한글이 모지바케가 되고 `:has-text("두족류")` 선택자가 전부 실패**한다.
로컬 검증 사본에만 `<meta charset="utf-8">`를 앞에 붙이고, 선택자는 `[data-g="..."]` 같은 **속성 기준**을 쓴다.

## 7. 잔여

- **놀래미(`greenling`) 전용 실사** — 레포의 두 파일이 바이트 동일한 중복(§2-2)이라 지금은 그림이 없다.
  사용자가 실제 노래미 사진을 주면 `fish/` 배치 + `FISH_TEXTURE` 한 줄로 끝난다.
- **청볼락(`blue_rockfish`) 전용 실사** — 일반 볼락 사진을 회수해 현재 그림 없음.
- **볼락(`dark_banded_rockfish`) 어종 삭제 여부** — §2-5 해석대로 이미지만 회수했다.
  어종 자체를 지우려면 퀘스트 2편 목표·레시피·스팟·조행록을 함께 옮겨야 하므로 별도 차수.
- 과증식 4종 **필드 렌더**는 여전히 core `NuisanceArt` 절차 도트다(사용자 제공 타일맵 시트와 동일 형태).
  실사는 슬롯·상세·위키에만 쓴다.

## 8. 위험·부작용

- **구세이브 과증식 아이템 아이콘이 강제로 바뀐다**(`inv_nuisance_*` 백필). 개체·가치·수량은 불변.
- **돌돔 30cm 임계 하향** — 30~40cm 수컷 개체의 어획 팝업·인벤·도마 그림이 암컷 → 수컷으로 바뀐다.
  판정·가격·수율은 무영향(그림만).
- **돌문어 이름 변경** — 구세이브 인벤에 이미 들어간 어획물은 **저장된 이름 문자열을 유지**한다
  (`참문어 (32cm)` 그대로). 신규 어획부터 `돌문어`.
- 자격 경로는 전부 **추가 면제**라 기존 세이브의 면허 보유·조건 판정에 회귀가 없다.
- ⚠ **면제는 실적 요건을 통째로 건너뛴다** — 수협 조합원증(150,000원 · 출조 요건)이
  N03-4 하나로 열리므로 ch7 후반 재화 곡선이 소폭 완화된다(의도).
