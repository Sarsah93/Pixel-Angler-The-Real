## 1. 배경·판단

93차의 "한 드래그 안에서 라이브 프레임 전환" 방식을 사용자가 **단계 분할**로 재정의했다 —
연출 프레임 연결이 아니라, 짧은 당김마다 다음 사진이 나오는 구조. 절차 합성 플랩은 어색해서
목업 그대로 재현하도록 변경.

## 2. 변경

### A. 에셋 (`pixelize_butchery.cjs`)

| 구분 | 키 | 내용 |
|---|---|---|
| 베이크 교체 | `squid_skin_lift` | **목업 0-1을 직접 베이크**(cw) — 구 절차 합성 플랩 폐기. 파생 정리 4단: 도마색 보더 플러드(색근접+**따뜻함 r−b≥40** — 거리 단독이면 몸통 회색까지 먹음) → 검은 띠(좌 5% 열·L<70) → 프린지 침식 → 최대 연결요소 |
| 미러 추가 | `squid_fin1` | 좌우반전(95차) — 94차 상하반전과 **병행**(cw+미러+상하) |

⚠ **신규 함정 2건**: ① `ERASE_POLY`를 불투명 배경 캡처에 쓰면 투명 비율이 3%를 넘어
**알파 경로로 오판** → 배경 제거가 통째로 꺼진다(직접 재현). 캡처 정리는 파생 단계에서 할 것.
② 목업 캡처 PNG는 투명 여백이 있어 애초에 알파 경로 — 도마색이 남으므로 보더 플러드 필수.

### B. core

| 구분 | 위치 | 내용 |

### C. client

| 구분 | 내용 |
|---|---|
| **peel 당김 품질 = 스윕 길이 비례** | 구 절대거리(`along×1.5`)는 분할로 스윕이 짧아지자(1/4 = 0.158) **가이드를 끝까지 따라도 임계 0.25 미달(0.237)** — `along/swLen` 정규화로 교체 (peel은 두족류 전용 — 어류 무영향) |
| 프레임 단순화 | `CEPH_DRAG_FRAMES`에서 껍질·날개살 제거(라이브 전환 폐기 — **finskin만 잔존**). 각 peel 단계 = 시작 사진 고정 + 완료 연출(`CEPH_ANIM_FRAMES`) = 다음 사진(peel1→…→4.1, 뜯기 ② = **4.2**) |
| 날개살 | fin_off_1/2 = fin0/fin0_m 고정 + **드래그 후** 완료 연출로 5.1/5.2 표시 |
