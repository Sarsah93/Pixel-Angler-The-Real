# 168차 — 장면 생성기 재작성 · 채집 스팟 거대 사진 수정 · 전체 위키 아티팩트 (2026-09-22)

## 1. 배경

167차 §9 감사 결과를 본 사용자 지시 3건.

- *"'이름없는꾼' 멘트와 '혼잣말' 멘트가 겹치는 부분 때문에 이질감이 있네."* + N19-1 각본 지정
  (*정옥선이 … "탁 영감이 주던가?" 라고 말하고, 이름없는꾼(나)이 "...모르겠어요." 라고 대화가 종료되어야 한다*).
- M4-11 · N18-1 · M6-05의 대사 연결성 질문 + *"전체적으로 스토리를 한 번 봐야겠네. 하나씩 다 지정해줘야 하는 거야?"*
  + *"조행록 퀘스트 일지만 아티팩트로 할 게 아니라, wiki처럼 … 전체 내용이 구현해야 한다고 이전에 언급했었는데"*.
- *"마지막 캡처 화면(사진 속 천막)에 이상한 게 보이는데? '상태창'과 '맵이름 타이틀' 사이 … 이상한 픽셀 객체 …
  캐릭터가 특정 위치에 서 있을 때, 버그처럼 랜더링되는 부분들이 있던 것 같아. 이런 부분 없도록 전수 조사해서 수정해줘."*

## 2. 원인

**렌더 이물질** — 디스플레이 리스트 열거로 확정: `Image:forage_hemigrapsus_sanguineus` **1881×1881px** · depth 6.5 · 월드 좌표.
166차가 채집물 사진 5장(1254px)을 아이템 아이콘 키 `forage_<id>`로 실었는데, `ForageSystem.ensureTextures()`가
**같은 키**로 16×14 절차 도트를 만들다 `textures.exists`에 걸려 건너뛰었고, `renderSpots()`의 `setScale(1.5)`가
사진을 그대로 키웠다. 해안 근처에서 그 5종 스팟이 반경 안에 들면 화면을 덮는다 — "특정 위치에서만" 보이는 이유.

**장면 이질감** — 167차 생성기 규칙 6가지(§9 표) 중 A~D. 핵심은 플레이어가 나레이션 문장을 입으로 말하고,
발주자가 재촉문(`progress`)을 말하는 것.

## 6. 잔여

- 실내 무대 없음 — 병실(M6-05·M7-04)·교육장·부산 다리 밑은 지금 서 있는 필드에서 재생된다. 자막은 실제 장소로 바꿨다.
- 비발주자 상대(N19-1류 심부름 보고)는 데이터에 대사가 없어 침묵한다. 필요한 편만 손글(`QUEST_SCENE_OVERRIDES`).
- 위키 카드 탭은 목록 수준 — 요리 상세(별점·변형)·어종 서식은 157차 컨텍스트대로 후속.
- `quest_scenes.json`은 dev 서버가 있어야 다시 굽는다(코드가 바뀌면 재실행).

## 7. 위험·부작용

- 채집물 아이템 아이콘(인벤·쿨러)은 사진 키 그대로 — 회귀 없음. 필드 스팟은 항상 절차 도트.
- 장면 규칙 변경으로 100편 대사가 전부 바뀐다 — 세이브 무관(목표 스키마 불변).
