## 1. 배경 — 왜 했나

- 인게임 콘텐츠가 많아져 "무엇을 어떻게 하는지"를 한 곳에서 찾을 수단이 없었다(가이드 허브는 4주제뿐).
- 외부 테스터(URL 테스트) 피드백 7건 — 랜딩 연출이 너무 빠르다 / 챔질 타이밍 설명이 챔질 뒤에 뜬다 /
  패턴에 맞게 대응해도 텐션이 오른다 / 채비·어종·크기별 난이도가 없다(20cm 광어 = 25cm 감성돔 < 15cm 잿방어) /
  희귀도 색 표시 / 지그헤드가 봉돌 없이는 안 던져진다 / 미끼·루어 채비 소켓이 분리돼 있지 않다.

## 2. 원인 — 무엇이 문제였나

- **파이팅 텐션 모델**이 물리량이 아니었다 — `reeling +16`, `holding +10` 같은 상수라 **버티기 자체가 텐션을
  올렸고**, 체중·줄 강도가 개입할 자리가 없어 어종·크기·채비 난이도가 성립하지 않았다.
- **줄·바늘을 다시 살 수 없었다** — 줄터짐·밑걸림으로 잃는 소모품인데 상점 카탈로그에 없어, 목줄을 잃은
  테스터가 "미끼 채비에서 목줄을 선택할 수 없다"고 보고한 것이 실체.
- 루어 모드가 미끼 채비의 `_rig.mainLine/leader`를 **공유**해 모드 전환이 서로를 오염시켰다.
- 바늘 소켓에 루어(자중)가 있어도 원투 판정이 **무게추 봉돌을 강제**했다.
- 튜토리얼 플래그를 **열기 전에** 기록해 "다시 표시" 선택지가 없었고, 챔질 설명은 첫 파이팅(=챔질 후)에 떴다.
- 조작 힌트 바는 정보량이 적고 고정 — 사용자가 둥근 사각 버튼 + 라이브러리로 대체 요청.

## 4. 구조상 위치 — 어느 계층의 무엇인가

- core: `simulation/FishRarity.ts`(어종군·희귀도·줄 강도 — 낚시 루프 S1이 소비) · `FightingPhase` 물리 모드(구 상수 모드 호환).
- client: 도움말은 `data/HelpContent.ts`(데이터) + `ui/HelpLibraryPanel.ts`(뷰) — 가이드 허브와 분리(허브 = 상황 튜토리얼, 라이브러리 = 사전).
- 튜토리얼 흐름: FP 씬 `openTutorial(cat)` → `GuidePanel(tutorial)` → `onTutorialDone(dontShowAgain)` → `guideSeen.<cat>`.

## 6. 잔여 — 이번에 안 한 것

- **파이팅 실캡처**(`help_fp_fight` 플레이스홀더) — 하네스로 입질을 강제할 수 없어 사용자 플레이 캡처로 교체.
- 튜토리얼 페이지 삽화는 기존 SVG 삽화 재사용 — 상황별 실캡처+표시 가이드는 캡처가 쌓이면 교체.
- 물리 튜닝 수치는 시뮬 기준 mockup — 실플레이 후 F8 스냅샷으로 확정.
- 준비 중 콘텐츠 토픽(해루질·농사·광질 등)은 예고문만.

## 7. 위험·부작용

- ⚠ **중첩 컨테이너 + GeometryMask + 인터랙티브 자식 = 포인터 이동 시 렌더러 탭 크래시**(실측 — 지역 채널을
  래퍼로 감쌌을 때). 채팅은 재생성 방식으로 우회. 다른 HUD에 같은 구조 금지(함정 기록).
- 텐션 모델 변경으로 기존 체감이 달라진다 — 특히 라이트 채비로 대물은 이제 **터진다**(의도).
- 구세이브: 루어 소켓 null → 첫 전환 시 미끼 채비 줄로 시드(손실 없음).
