## 1. 배경

92차의 껍질 구간은 프레임이 스테이지당 2장뿐이었고, 사용자가 detail 폴더로
**뜯김의 중간 사진 3장 + 완료본 + 날개 시작본**을 시퀀스 번호로 준비해 재구성을 지시했다:

- 벗기기 0(현 상태 캡처) → 0-1(클릭 시 껍질이 살짝 들려 **손잡이**가 되는 연출) →
  1(우→좌 **곡선 가이드** 목업) → 1-2·2·3(신규 — 딸려오는 중/절반/절반+) →
  4(기존 4.1 = 70%+) → 5(기존 4.2 — **상→하 마무리 당김**) → 6(신규 — 다 벗겨진 순살).
- 날개 0(신규 — 껍질 속 날개살이 온전한 분리 직후 덩어리)을 **가장 먼저** 렌더하고,
  우→좌 드래그 시 들려지는 것이 **실시간으로** 반영되어 날개 1(기존 5.1)이 된다.

## 2. 판단·정정

- **탭 좌표 해석 정정** — 캡처 「벗기기 0」이 조준 링을 **회전 뷰 화면 우상단**에 표시 →
  92차의 "주어진 좌표 = 로컬" 해석이 오독(링이 좌상에 갔다)임을 확정. 로컬 = `[1−v, u]` 역변환으로
  정정 (`CEPH_SKIN_LIFT_TAP` = (0.770, 0.777) — 화면 (0.777, 0.230)에 표시).
- **껍질 섹션 = 회전 뷰(270) 유지** — detail 사진 전부가 그 방향으로 촬영됨. 92차의
  "뜯기 ① 무회전·뜯기 ② 우 90°" 구성 폐기, 4스테이지 전부 `rotationRequired: 270`.
- **베이크 규칙** — 신규 사진은 전부 **cw 베이크**: 표시 회전 270(ccw)이 되돌려
  **촬영 방향 그대로** 보인다. 4.1(`squid_skin_grip`)도 cw 재배향(이 뷰에 편입).
- 목업 0-1(조준 링이 그려져 있음)·1(가이드 선)·0/4/5/날개 1(기존 에셋 캡처)은 굽지 않는다 —
  0-1은 **파생**(skin_on + 절차적 플랩), 1은 **좌표 추출**(스윕 곡선)로 반영.
