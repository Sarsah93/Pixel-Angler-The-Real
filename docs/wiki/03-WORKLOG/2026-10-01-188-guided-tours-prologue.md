## 1. 배경 — 왜 했나

사용자 지시 7건(요지 — 원문 표현 유지).

1. **모든 기능 팝업은 처음 열 때 단계별 USE CASE 가이드**를 준다(단축키 창 K·S·M 등).
   패널 좌·우 말풍선이 각 구성 요소를 가리키고, 텍스트는 타이핑 + [다음], 대상은 하이라이트,
   진행 중에는 다른 행동을 막고, **실제 행동을 직접 해 보게** 한다.
   예시(인벤토리): 「게임 내 획득하는 아이템들이 저장되는 공간이다」 → 「모든 아이템은 카테고리 별로 분류되어 저장된다」 →
   「모든 아이템은 1개의 슬롯을 차지하며, 드래그&드랍하여 움직일 수 있다」 → 「우클릭 시 '상세보기', '먹기', '착용하기' …」.
   > "'우클릭:아이템 액션/드래그: 위치 이동'과 같이 기능을 텍스트로 표시하는 것은 현재와 앞으로의 작업에서 금지 규칙으로 만들 것."
   > 도움말 라이브러리는 첫 가이드 뒤에 다시 읽는 곳.
2. 새 캐릭터는 기본 상·하의 외에 **지급품 없음**(사용자 선택 「대·릴만」 — 상점 방문·구매·판매 기초 가이드를 넣기 위해,
   "기초 장비를 하나씩 사보게 하는 것으로").
3. 오프닝은 **집 안에서 시작** → 기본 상호작용·단축키를 익히며 자연스럽게 속초(영금정 M1-01)로.
   사용자 선택 = 시나리오 A 「떠나는 날 아침」.
4. 슬롯 이름표가 읽을 수 없게 작아진다 → **약어**로(예 'AMSTRONG 합사 원줄 1호·150m' → 'AMS·합사·1호·150m').
5. **스킬 창 재설계** — 정사각 슬롯 + 픽셀 아이콘 + 이름, 설명은 실시간 호버 팝업, 하단 「다음 레벨: …」·최대.
6. 타일 **격자무늬** 전수조사·수정.
7. 백로그 **AG** 항목 이어서 수정.

## 2. 원인 — 확정된 기전 (버그성 항목)

- **격자** — 표면 아틀라스 셀 경계·물 버킷 경계·해시 없는 암초/해구 패턴이 32px 주기로 반복되고,
  농지 이랑이 도로보다 늦게 칠해져 선이 드러났다(`SurfaceArt`·`SeamlessChunks` — [world-field §6](../02-SYSTEMS/world-field.md)).
  집 실내 마루는 가로 이음매가 IT×2마다 방 전체를 가로질러 격자로 보였다.
- **영어 혼잣말이 한국어로 타이핑** — `MonologuePanel`이 원문을 한 글자씩 쳤고, 부분 문자열은 사전에 없어
  다 칠 때까지 한국어가 흘렀다(150차 오프닝부터).
- **할 일 달성 토스트 반쪽 번역** — HUD가 「[할 일] 」 말머리를 떼고 띄워 규칙이 안 맞았다(제목만 영어).
- **자전거를 얻을 길이 없음** — `inv_bike`는 dev 시드에만 있었다. 빈손 시작 뒤 M1-10 「자전거에 탑승한다」가 닫히지 않는다.
