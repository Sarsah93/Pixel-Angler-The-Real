## 1. 배경 — 왜 했나

183차에 속초 방파제 성분 16개 목록을 드리고 "위성 확대 캡처를 주면 OSM 좌표와 대조해 반영"하기로 했다.
사용자가 네이버 위성 캡처 8장을 보냈다(원문 요지, 2026-09-29):

- 1·2번 = 영랑호 호숫가(속초의료원 인근 · 서쪽 끝) — 설명 없이 캡처만.
- 3번 = 영금정 — "빨간색으로 표시한 부분은 테트라포드야."
- 4번 = 동명항 안쪽 활어센터 앞 — "연석 같은 돌바닥으로만 이루어진 방파제 … 주변 자갈이나 테트라포드,
  바위 덩어리 등이 없고, 딱 연석만 바다 위에 쌓은 느낌."
- 5번 = 청초호 갯배 선착장 인근 — "빨간색 부분은 평지 도로가 아닌, **다리 도로; 대교(2~3레이어층 높은 고도의
  highway 같은)**야. 인게임 내 잘 반영해 주면 좋겠고 … 인근 물 지형과 육지 경계는 … 딱 연석으로만 이루어진
  **직벽**(곧바로 물과 연결됨)."
- 6번 = 청초호 남서쪽 — "한 줄짜리 짧은 테트라포드 … 요트 혹은 작은 배들에 대한 선착장이 보이니,
  **돌아다닐 수 있는 길처럼** 구현하는 것도 필요."
- 7번 = 속초항 남쪽 해안 — "빨간색으로 표시한 부분만 테트라포드."
- 8번 = 13번 바로 남쪽 — "빨간색 = 테트라포드, 파란색 = 돌덩어리·갯바위."

## 2. 원인 — 무엇이 문제였나 (대조 결과)

- **좌표 대조는 OSM 이름 지물로 기준점을 잡았다.** 캡처는 축척이 제각각이라 OSM의 등대·교량·잔교 좌표로 맞췄다.
  - 영금정: `속초등대`(OSM 567,85) ↔ 캡처 (500,715)px → **14px/타일**로 일관.
    ⚠ 처음엔 등대를 캡처 (505,390)으로 잘못 읽어 가로·세로 축척이 3배 어긋났다.
  - 금강대교: OSM `bridge=yes` 4구간(`168876667` · `178808335` · `753395815` · `178808348`) — 수로 폭 19타일 ↔ 캡처 400px.
  - 조양동 잔교: OSM `man_made=pier` 면(348~356 × 535~558) ↔ 캡처 13px/타일.
- **청초호가 바다와 끊겨 있었다.** 금강대교 밑 수로(y 354~370)가 103차 방파제 추론 `'b'`와 도로 래스터 `'r'`로
  칠해져 **다리 밑이 둑**이었다. 같은 추론이 호수 안에 가짜 대각선 호안 33타일(183차 목록 11번)도 만들었다.
- **13번과 14번은 한 방파제였다.** 13번 = 청호동 해수욕장 북단 섬 방파제의 팔, 14번 = 머리. OSM에는 두꺼운 `'b'` 덩어리지만
  캡처는 **가는 연결 다리 + 테트라포드 섬**이다.
- **캡처 7은 제가 말한 "속초항 남쪽 해안"과 다른 곳이었다.** 핀(청호동)은 13번 좌표 그대로였고, 긴 빨간 호안은
  그보다 북쪽 **청호동 동쪽 해안**(y 438~552), 왼쪽 위 L자는 **10번 청호동방파제**였다(이미 테트라포드 — 일치).
- **캡처 8(외옹치·대포항)은 현재 속초 맵 밖이다.** 맵 남쪽 경계 = 위도 38.1886(행 642). 외옹치·대포항은 그 남쪽.
- **캡처 3의 핀 자리(영랑동 1-17)는 바위 선반**이었다 — 183차 목록 4번·2번 소형 성분(사석 판정)은 틀렸다.

## 4. 구조상 위치

- `필드 → 지형 데이터 → 위성 대조 반영` — **데이터 층**(patch) + 피복 판정 1건(**판정 층** — `quay`·문턱 우회).
- `필드 → 고도 → 고가 상판` — 183차 타일 층(`Elevation`)과 **별개인 두 번째 층**. 타일 하나에 층 하나라 다리 밑 길·물길을
  표현하지 못해서, 상판은 폴리라인으로 두고 플레이어 상태(`deckId`)로 층을 가른다.
  - 계약 = core `RegionOverpass` · 판정 = core 순수 함수 · 렌더·충돌 전환 = client `OverpassSystem`.
  - 상판 위에서는 지면 충돌(청크 벽·POI 벽·경사로 둑)을 끄고 난간은 횡거리 클램프로 막는다.

## 6. 잔여

- **캡처 8(외옹치·대포항)은 맵 밖** — 속초 bbox 남쪽 확장 때 반영한다. 기록: 외옹치 곶 = 갯바위·돌덩이(파란 표시),
  대포항 = 북쪽 소형 방파제 · 동방파제(길다) · 남서 소형 방파제가 전부 테트라포드(빨간 표시).
- **호수 안 테트라포드 판정 3곳 미확인** — 183 목록 1번(영랑호 CC 북 75타일) · 3번(영랑호 378타일) ·
  12번(청초호 씨크루즈호텔 앞 526타일). 호숫가에 테트라포드는 드물다 — 캡처 대조 필요.
- **동명항 성분(2,010타일)** — 캡처 4의 동명항 외곽 테트라포드(동쪽)는 일치. 남쪽 속초항 구간(y 200~317)은 미대조.
- 영금정 북쪽 테트라포드 띠는 **캡처 프레임 안(x 534~548)만** — 서쪽 영랑해안길 호안(x 480~532)은 OSM 그대로(안벽).
- 고가 = 금강대교 1곳. 다른 OSM `bridge=yes`(하천 소교량 11곳)는 평지로 둔다 — 짧고 낮다.
- 편집기에 고가 도구 없음(작성기로만 편집) · 미니맵에 상판 표시 없음 · 상판 위 보행 NPC 없음.
- 섬 방파제 연결 다리는 타일 계단형(대각 2칸) — 매끈한 대각 데크는 렌더 층 작업.

## 7. 위험·부작용

- **피복 지정이 규모 문턱을 건너뛴다** — 이제 `patch.armor` 한 줄이 작은 `'b'` 선도 방파제로 만든다. 지정은 캡처 대조로만.
- **작성기는 좌표 덮어쓰기**다 — 범위를 줄이면 예전 좌표가 patch에 남는다(이번에 x 531~533을 수동 정리).
- **청초호가 바다와 이어졌다** — 수역 연결을 보는 판정(항만·외해 마스크·통발 설치 거리)이 청초호에서 바뀔 수 있다.
- **도로 클립** — 상판과 30° 이내로 나란한 지면 도로 구간만 뺀다. 가로지르는 길은 남는다.
- 상판 위에서 순간이동으로 3타일 넘게 벗어나면 지면으로 내려진다(난간 클램프가 끌어오지 않게).
