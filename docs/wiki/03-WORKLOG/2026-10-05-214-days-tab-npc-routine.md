## 1. 배경 — 왜 했나

사용자 원문(요지):

> "일지 「나날」 탭이랑 NPC 일과부터 진행해줘."
>
> "'이야기 N일째'로 하면 일 수와 실제 일 수와의 혼동이 생기므로 … '이야기 N번째'가 더 좋지 않을까?"
>
> "나머지 2~5 설계 제안은 그대로 해도 될 것 같아." (옷 가게 · 음식점 탑다운 방 캡처 2장 — 참고용)
>
> "도움말 전체 내용은 위 요구사항 반영 후에 업데이트할 것." · "맡긴 물건 목록을 보거나 찾아오는 기능도 추가해줘."

213차 §6 제안 중 **나날 탭**과 **NPC 일과**를 먼저 구현하고, 213차 잔여(맡긴 물건 목록)와 도움말 전체 갱신을 함께 끝냈다.
농사 · 실내 공간은 설계 확정만 받았다(§6).

## 2. 원인 — 조사에서 확정한 것

| 항목 | 조사 결과 |
|---|---|
| 이야기 날짜 표기 | `StoryStore.storyDay`(0부터)는 **다 잔 잠 횟수** — 실제 날짜와 1:1이 아니다(하루 두 번 자면 +2). 「N일째」는 오해를 부른다 → 「이야기 N번째」 |
| 장부 ↔ 이야기 날짜 | 결산 장(`DayLedgerPage`)에 이야기 날짜가 없었다 → 「지난 하루」 줄에 몇 번째인지 못 보였다 |
| **장부 수지 ±0 버그** | 장이 첫 기록 때 열리는데, 그 첫 기록이 **돈 변동**이면 시작 잔액이 이미 바뀐 값이었다(그날 수지 ±0). 211차부터 있던 결함 — 하네스 「지난 하루」 5장 중 4장이 ±0원으로 드러남 |
| NPC 상주 | 스토리 NPC 9명이 24시간 같은 자리에 서 있었다(실시간 시계와 어긋남) |
| 시각 의존 위험(R12) | 인물이 집에 들어가 버리면 그 사람에게 걸린 할 일(대화 · 보고)이 시각에 막힌다 → **문 두드리기로 같은 대화**를 열어 R12를 지킨다 |
| 집 자리 | 속초 지형에 주거 POI가 없다 → 탐색 하네스로 「건물 2칸 아래 보도 · 거래 문 3칸 밖」 칸을 뽑고, 스크린샷으로 건물에 붙어 보이는 칸만 골랐다(첫 후보 중 항구의 붉은 담장 띠는 탈락) |

## 4. 구조상 위치

- **월드 → 인물 → 일과**: 계약(core `NpcRoutine` 타입) · 데이터(core `NpcRoutines` 시간표 · client `StoryNpcs.home` 좌표) · 판정(core `npcWhereabouts`) · 렌더(필드 문 · 페이드 · 안내).
  일과는 **어디서 만나는가**만 바꾸고 **만날 수 있는가**는 바꾸지 않는다(R12) — 대화 메뉴는 문 앞에서도 같다.
- **스토리 → 일지 → 나날**: 데이터(장부 `storyDay` · `upkeepItems` · `ConsignQueue`) · 렌더(일지 3번째 탭).
- **경제 → 위판 → 맡긴 물건**: 데이터(큐 `take`) · 판정(창구에서만 찾아오기) · 렌더(목록 창).

## 6. 잔여 · 설계 확정 (사용자 확인 완료)

- **농사**: 이야기 날짜로 자람 · 실제 계절 · 실제 비 = 물 주기 · 비닐하우스. 착수 조건 = 로드맵(요리 개체화 2단계 뒤 농장).
- **실내 공간**: 집 실내 엔진을 데이터 구동 `InteriorScene`으로 일반화 → 1단계 가게 · 보건소 · 위판장, 2단계 주요 인물 집, 3단계 아파트 템플릿.
  사용자 참고 캡처(옷 가게 · 음식점) — 매대 · 진열장 · 카운터 앞 점원 · 테이블 배치의 밀도를 참고한다(그대로 베끼지 않는다).
  인물 집이 생기면 「문 두드리기」 → 「들어가기」로 바뀌고 일과의 `home`이 실내 좌표가 된다.
- 다른 지역 인물(부산 · 포항 등)은 무대가 열릴 때 시간표와 집을 정한다(지금은 24시간 기본).
- 일과 시각은 실플레이로 조율할 여지(특히 탁새벽 08~19 · 배누리 09~21).

## 7. 위험 · 부작용

- 인물이 집에 있으면 일터 칸에 없다 — 할 일 화살표 · 미니맵은 `n.x/n.y`(문 앞)를 따라가므로 길 안내는 이어진다.
  필드 장면(컷씬)이 집에 있는 인물을 부르면 문 앞으로 나와 서고, 장면 뒤 5초 안에 다시 들어간다.
- 같은 공방에 문이 둘(탁만수 · 탁새벽) — 64px 간격이라 안내는 문 위 한 줄씩만 뜬다.
- 장부 시작 잔액 정정은 **새로 여는 장부터** 적용 — 이미 닫힌 옛 장의 ±0은 그대로다.
- 행인 수는 씬에 들어올 때 정한다(같은 맵에 머무는 동안은 바뀌지 않는다).
