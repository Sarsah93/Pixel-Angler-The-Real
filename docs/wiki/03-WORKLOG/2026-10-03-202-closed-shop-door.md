## 1. 배경 — 왜 했나

사용자 원문:

> "문 닫은 시간엔 거래 막고 문 앞 대사도 넣어줘."

같은 메시지에서 **히든 타이틀 업적 시스템**(방생 누적 n회 → 「구원자」 · S 창에서 확인·장착 · 머리 위 또는 멀티 이름 앞 표시)을
제안받았다 — 사용자가 의견을 물어 이번 차수는 **설계안 보고**만 하고 구현은 확인 뒤로 둔다(백로그 AR).

## 2. 원인 — 무엇이 문제였나

기능 추가. 201차까지 영업시간은 지도 카드 표시뿐이라 밤 11시에도 마트 거래가 열렸다.

## 3. 변경 — 어디를 어떻게

| 구분 | 위치 | 내용 |

| 수정 | [`RegionFieldScene.promptTrade`](../../../packages/client-pc/src/scenes/RegionFieldScene.ts) | 거래 확인 창 전에 `BUILDING_HOURS` + 지금 KST 판정 — 닫힘이면 거래 대신 문 앞 혼잣말 · 상점 방문 퀘스트 이벤트도 열렸을 때만 |
| 신설 | `RegionFieldScene.showClosedDoor` | `MonologuePanel`(타이핑 · ▼ — R3) 2단락: ① 가게 모습(먹는 곳/물건 파는 곳 × 열기 전/닫은 뒤 4종) ② 문 안내문 「영업시간 10:00 ~ 22:00」 + 언제 다시 올지 · 지역 채널 한 줄 |

## 4. 구조상 위치 — 어느 계층의 무엇인가

- `경제 → 가게 → 거래 진입` — **판정 층**(거래 진입 한 곳 `promptTrade`만 지난다 — `openShop` 호출처는 여기 하나).
- 이야기 인물의 「물건을 볼 수 있을까요?」(사람이 파는 것)는 영업시간을 따르지 않는다(가게가 아니다).

## 5. 검증 — 무엇으로 확인했나

| 대상 | 방법 | 결과 |
|---|---|---|
| 닫힌 마트(23:52 KST) | 하네스(`r202a.cjs`) `promptTrade('mart')` | 혼잣말 「셔터가 내려가 있다…」 → 「…내일 10:00에 다시 와야겠다」 · 상점 창 없음 · 끝나면 팝업 0 |
| 열기 전 음식점 | `showClosedDoor('restaurant', …, true)` | 「아직 문을 열기 전이다. 안쪽 주방에서…」 → 「10:00에 연다…」 |
| 직판장(24시간) | `promptTrade('market')` | 평소대로 거래 확인 창 |
| EN | 같은 하네스 `en` | 「The shutter is down…」 · 「A notice on the door: "Open 10:00 – 22:00." …」 |
| 오류·빌드 | 하네스 · 빌드 · typecheck | pageerror 0 · 3/3 · 0 오류 |

## 6. 잔여 — 이번에 안 한 것

- **타이틀 업적 시스템** — 사용자 확인 대기(설계안은 채팅 보고 · 백로그 AR).
- 문 닫은 가게 건물 그림(불 꺼진 창 · 내린 셔터)은 없다 — 지금은 들어가 봐야 안다. 필요하면 건물 그림에 밤 상태를 더한다.

## 7. 위험·부작용

- 밤에만 플레이하는 사람은 마트·생활용품점·약국을 못 쓴다(의도 — 직판장·편의점은 24시간). 각얼음은 편의점에서 살 수 있다.
- 퀘스트가 「상점 열기」를 요구하는 단계에서 밤이면 직판장·편의점으로 가야 한다.
