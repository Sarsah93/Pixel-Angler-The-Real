# 246차 — 그림 없던 어종 4종(Gemini) · 어종 그림 카드 방식(부팅 텍스처 194MB → 12MB) (2026-10-14)

> 시스템: 실사 도트 · 낚시(어획 그림) · 발견 도감 · 위키
> 계층: 에셋(원본 4 · 카드 57 · 아이콘 57 · 원본 폴더 이동) + 렌더(크기별 판 고르기 `fitFishTexture`) + 도구(`gemini_fish_art.cjs` · `fish_cards.cjs` · 생성기 경로)

## 1. 배경 — 왜 했나

사용자: 「해당 작업이 끝나면, 어종 그림 53장도 카드 방식으로 줄일 수 있으면 줄여보자. 단, 이미지가 없는 어종 그림부터 우선 작업해주면 좋을 것 같네.」

- 244차 실측: 어종 원본 53장(긴 변 511~2,172px)을 부팅 때 전부 싣는다 — 텍스처 약 181MB(백로그 C 「어종 그림 부팅 로드」).
  작물은 244차에 같은 문제를 카드 방식으로 풀었다(59MB → 3.9MB).
- 그림 없는 어종 = 어종 DB 56종 중 **4종**(개서대 · 눈퉁멸 · 도루묵 · 말쥐치). 도감 카드가 「이미지 없음」이고, 어획 팝업 · 가방은 그림 없이 떴다.

## 2. 판단 — 무엇을 어떻게 정했나

**그림 없는 4종 먼저 — Gemini로 그린다**(244 작물 도구를 어종용으로 옮긴 `tools/gemini_fish_art.cjs`).

- 생김새 설명(`LOOKS`) + 화풍 참고 = 기존 어종 원본 3장. 체형이 가까운 것을 고른다.
  - 개서대 = 넙치 · 양태 · 붕장어 / 눈퉁멸 = 방어 · 숭어 · 보리멸 / 도루묵 = 쥐노래미 · 보리멸 · 방어 / 말쥐치 = 방어 · 청볼락 · 망상어.
- 조건: 순백 배경 · 한 마리 · **머리 왼쪽**(어획 팝업 · 도마 규약 — 개서대는 눈 있는 쪽을 위에서) · 물 · 그림자 · 글자 없음. 비율 21:9(말쥐치 16:9).
- 이웃 종과 헷갈리는 점을 적었다(쥐치 ↔ 말쥐치 · 정어리 ↔ 눈퉁멸).
- 8장 생성(Nano Banana 2.1 · 평균 23초 · 출력 토큰 18,507 · 추정 0.3달러).
  - 개서대는 v1~v3이 넙치처럼 둥근 타원이었다 → 「몸 폭 ≤ 길이의 4분의 1 · 창끝 꼬리 · 가슴 · 배지느러미 없음」을 적은 v4 채택.
  - 눈퉁멸 v1은 몸이 높았다(정어리) → 「몸높이 = 길이의 6분의 1 · 원통형」 v2 채택. 도루묵 · 말쥐치는 첫 장.

**원본 = 생성 해상도 그대로**(1,305~1,566px). 기존 원본도 511~2,172px로 제각각이라 한 기준에 맞출 이유가 없다.

- 192셀(셀 6px)로 다시 맞추면 윤곽선이 흐려졌다 — Gemini 도트 격자가 고르지 않다(셀 추정 5~23px). 비교 시트에서 원본 해상도 쪽이 선명했다.
- 배경 벗기기는 작물 `cutout`(테두리 BFS · 갇힌 흰 섬)을 쓰되 **그림자 걷기는 끈다** — 은빛 배 가장자리를 지웠다(눈퉁멸 887px · 도루묵 1,186px).
- 갇힌 흰 섬 11곳(19~96px)은 지느러미와 몸 사이 V자 틈에 갇힌 진짜 배경이다(4배 확대로 확인) — 그대로 뺀다.
- **번짐 벗기기**(`peelFringe`): 응답이 JPEG라 진한 윤곽선 바깥에 1px 회색 띠와 계단 모서리 흰 삼각형이 남았다(어두운 창에서 흰 테).
  - 투명과 8방향으로 닿은 무채색(채도 < 0.3 · 밝기 > 70) 중 안쪽 이웃보다 40 넘게 밝은 픽셀을 3회 걷는다 — 진한 윤곽선에서 멈춘다.
  - 떨어져 나간 부스러기(4방향 덩어리 40px 미만)도 지운다. 장마다 번짐 4,469~5,949px · 부스러기 432~660px.
- 타이트 크롭 + 투명 여백 2px → `food assets/fish/<파일>`.

**카드 방식** — 작물 카드(244)와 같은 생각이다. 화면은 고정 1280×720이라 그리는 칸보다 큰 텍스처는 버려진다.

- 원본 53장은 `public/fish/` → **`food assets/fish/`**(git mv · 바이트 동일). 새 4장도 여기. 게임은 원본을 싣지 않는다.
- **카드** = 가장 크게 그리는 칸 410×166(손질 도마 미리보기 = 도마 480×240 − 70 · 74)에 비율대로 맞춘 면적 평균.
  어획 결과 창(최대 360×146) · 상세(300×120) · 도감(84×66)은 카드를 줄여 그린다.
  비율이 원본 그대로라(여백 포함) 화면마다 그려지는 크기가 같다.
- **아이콘** = 긴 변 64px. 그릴 긴 변이 72px 이하면 아이콘(`fishicon_*`) — 가방 칸 · 쿨러 교체 칸 · 수조 · 세로로 긴 어종(문어)의 도감 칸.
- 표 하나(`FISH_IMAGE_FILES` — 텍스처 키 → 파일)가 BootScene 로드 · 카드 굽기 · 위키 그림을 함께 맡는다. BootScene 53줄 → 반복문 하나.
- 크기별 판 고르기 = `fitFishTexture(tex, key, boxW, boxH)`. 카드로 맞춘 긴 변이 72 이하면 아이콘으로 바꿔 다시 맞춘다.
  어종 키가 아니면 받은 키 그대로라 다른 텍스처가 지나가도 안전하다(가방 아이콘 경로 · 도마 미리보기 공용).

**곁 효과 — 알파 정리**: 면적 평균이 알파를 문턱(0.3 · 0.85)으로 굳힌다.

- 어종 원본 10장의 전면 알파 252~253(「반투명 100%」)과 유령 픽셀(알파 1~7 · 장당 500~58,000개)이 카드에서 사라졌다(반투명은 가장자리 2~6%만).
- 241차 잔여 「어종 알파 정규화」의 게임 쪽 효과는 이것으로 끝났다. 원본은 그대로다(위키는 원본을 360px로 줄여 쓴다).

**도마 스냅숏 생성기는 경로만** — `gen_species_sprites.cjs` · `gen_flatfish_sprites.cjs`가 `public/fish/`를 읽었다.

- 이 컨테이너 크로뮴으로 다시 구우면 사용자 PC 크롬과 캔버스 축소가 달라 픽셀이 바뀐다(벵에돔 64줄 · 감성돔 · 돌돔 몇 줄).
- 그래서 그림 데이터는 그대로 두고 생성물 머리 주석 「소스:」 한 줄만 고쳤다(광어 생성기는 여기서도 바이트 동일 — 머리 주석만 달랐다).

**검증 중 발견해 고친 것**

- 위키 어종 상세의 「선호 미끼」가 `sandworm, prawn` 같은 미끼 종류 키를 그대로 찍고 있었다(56종 전부 · R1 위반) →
  `gen_game_wiki_data.mjs`에 표시 이름 표(`BAIT_CATEGORY_KO` — 갯지렁이 · 새우 · 냉동 크릴 …)를 두고 바꿔 찍는다.

## 4. 구조상 위치 — 어느 계층의 무엇인가

실사 도트 → 어종 그림 → **에셋 · 렌더 층**. 계약(어종 id · 텍스처 키 `fish_*`)은 그대로라 세이브의 `iconTexture`(카드 키)가 그대로 맞는다.
판정 · 경제 · 손질은 건드리지 않았다. 새 4종은 core 어종 DB에 이미 있었고 텍스처만 없었다(도마 손질 편입은 별도 단계).

## 6. 잔여 — 이번에 안 한 것

- **원본 품질 결정(사용자)** — 셀 2px 7장 · 셀 ≥ 12px 3장 재굽기 · `So-iuy_mullet.png` 소문자화. 카드는 축소본이라 차이가 덜 보인다. 알파는 카드에서 해결.
- **새 4종의 손질(도마)** — 그림만 들어갔다. `BUTCHERY_IMPLEMENTED_SPECIES` · 프로필은 손질 트랙에서.
- **도마 스냅숏 재생성**은 사용자 PC 크롬에서 하면 된다(경로만 바뀌었고 데이터는 같다). 이 컨테이너에서 돌리면 픽셀이 달라진다.
- gh-pages 배포는 하지 않았다(사용자 요청 없음).

## 7. 위험·부작용

- **원본 경로 이동** — 레포 안에서 `public/fish/`를 읽던 도구는 셋(생성기 2 · 위키 그림 1)이고 모두 고쳤다. 레포 밖 개인 스크립트는 알 수 없다.
- **새 어종 그림을 넣고 `fish_cards.cjs`를 안 돌리면 404**다(카드가 없다) — `--check`가 잡는다. 스킬 `add-species` · `asset-pipeline`에 절차를 적었다.
- **어종 그림 칸을 410×166보다 키우면 카드가 확대된다** — `fish_cards.cjs`의 `CARD_W` · `CARD_H`를 같이 바꾸고 다시 굽는다.
- 64px 아이콘을 72px까지 1.125배 확대하는 칸이 있을 수 있다 — 작물과 같은 문턱이고 눈에 띄지 않았다.
- 세이브 영향 없음 — 키는 그대로다.
