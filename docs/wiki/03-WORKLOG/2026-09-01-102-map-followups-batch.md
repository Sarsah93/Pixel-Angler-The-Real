## 1. 배경 — 왜 했나

사용자 로드맵 지시(2026-09-01):

> "현재 추진 일정은, 맵 후속 잔여 → 확정되면 OSM 타 지역 확장 → 두족류 마무리 → 해루질 통발 관련 시작.
> 우선, '지역마다 terrain 육안 대조' 및 '섬'으로 분류될 지역간 구분도 필요해 보여.
> (어차피 도보권으로는 도달이 안되므로, 추후 출조; 배 타고 흘림 낚시나 다운샷 등, 갯바위 출조 등
> 관련 업데이트 시, 고려될 섬이므로, 따로 분리해야 할 것 같음)"

이에 따라 ① 섬 지역 분류(확장 선결)를 먼저 반영하고, ② 101차 잔여 목록을
소형→대형 순서로 전부 소화했다(진행 순서는 사용자 선택 — "소형→대형 전체 소화").

101차 잔여 원문: 사고 후 정체 해소(추월 없음) · 회전교차로 분리섬 · 편집기 새 도로 그리기 ·
지면 오토타일 코너/엣지(Kenney 행 19/23·열 0/2) · 물 타일셋 · 지붕 Kenney 타일링 ·
대각 건물 지붕 코너 셀 · 신호등·대각선 횡단보도.

## 2. 원인 — 무엇이 문제였나

버그 수정이 아니라 잔여 기능 구현이지만, 구현 중 확정한 사실 4건:

- **분리섬 1차 구현이 0건 렌더** — 수복탑 링 접점 접근로가 **전원 `oneway`**(진입로·진출로가
  갈라진 OSM 이중도로)라 "양방향 접근로" 전제 필터에서 전멸(인페이지 진단 실측 —
  링 248 접근로 10개 전부 `oneway: true`). 물리적 분리섬은 그 **쌍 사이 쐐기 공간**이 정답.
- **잔디 이너코너 노치 셀은 못 쓴다** — 흙 블롭의 바깥 모서리 셀이라 반타일 흙 사각형이
  계단 경계 안쪽마다 "갈색 블롭"으로 찍혔다(실렌더 확인 → 폐기, 셀 추출물만 예비 보존).
- **지붕 2×2 패널 셀 그룹 오독** — 행 2~3의 열 0~3을 2×2로 묶으면 세로 1×2 패널·와이드
  패널의 파편 합성이 되어 지붕에 "05" 헬리패드 숫자처럼 찍혔다(실렌더 확인).
  정합 2×2 블록은 **열 4~5·열 6~7**뿐(10배 줌 서베이로 확정).
- **Kenney 팩에 바다 셀 없음** — 파랑 우세 셀 전수 탐색 결과 수영장 시안(행 4~6)뿐.
  물 타일셋은 DEPTH_RAMP 톤 절차 베이크로 결정.

## 4. 구조상 위치 — 어느 계층의 무엇인가

`S2/S7 필드 → 심리스 v2 후속` — 전부 **렌더·엔티티 층**(교통·청크 베이킹·dev 편집기).
core 계약 변경 없음(`RegionRoad` 등 기존 타입 소비만). 파이프라인은 추출 표(데이터)만 확장.
`regions_config.access`는 **파이프라인 데이터 층**(소비처 없음 — 확장 목록 분류 전용, 게임 무영향).

## 6. 잔여 — 이번에 안 한 것

- **차량 신호 준수 없음** — 신호등은 시각 전용(신호 위상·정지 로직 없음). 현행 교차 양보
  (선진입 우선)가 충돌은 막고 있어 체감 우선순위 낮음. 착수 조건: 사용자 요청 시.
- **OSM `traffic_signals` 노드 미보존** — 파이프라인이 빌드 산출물만 저장해 휴리스틱(폭 기준)
  검출로 대체. 원본 노드 태그 보존은 파이프라인 확장 후보(재fetch 필요 — terrain 재굽기 동반).
- **수심 버킷 경계 디더 없음** — 물 타일 밴드 경계가 타일 단위 스텝(기존과 동일). 체감 시 후속.
- 사용자 육안 확인 대기: **주간 시각 확인 · 정지선 방향(우측통행 진입 차로)** — 101차부터 이월.

## 7. 위험·부작용

- **추월 중 대향차 시각 겹침** — 틈 판정(5타일)을 뚫고 들어온 대향차와 좌차로에서 겹칠 수 있다
  (엔티티 교통이라 충돌 없음 — 앰비언스 수준 허용).
- **신호 교차로 90곳은 휴리스틱** — 실제 신호 위치와 다를 수 있다(w≥4 × 2 기준).
  타 지역 확장 시 지역별 밀도 확인 필요.
- **`kn/` 재추출은 바이트 churn** — Pillow 버전이 다르면 기존 PNG가 픽셀 동일·바이트 상이로
  전부 M 뜬다. **픽셀 diff 0 확인 후 `git restore`**가 절차(이번 47파일 원복).
- 오토타일 엣지 셀은 **불투명 전체 덮어쓰기** — 잔디 흙 림은 흙 톤 고정(베이스가 모래든 포장이든
  갈색 림). 의도된 표현이나 사용자 시각 확인 대상.
