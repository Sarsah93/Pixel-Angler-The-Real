# 169차 — 전체 위키 도감: 분류 버튼 · 상세 · 그림 (2026-09-22)

## 1. 배경

168차에 전체 위키를 탭 6개로 발행했으나 요리·어종·아이템 탭은 **목록 수준**이었다.
사용자 지시(원문):

- 요리 — *"카테고리 별로 눌러서 모아서 볼 수 있게 버튼 추가 / 요리 상세설명 추가 — 설명, 조리법, 가치(1x 기준),
  완성도에 따른 benefits 등 인게임 내 구현된 모든 정보 / 사진 이미지도 추가"*
- 어종 — *"어류, 패류, 갑각류, 두족류, 기타 수산동물류로 분류할 것. 기타 수산동물을 추후에는 극피동물,
  피낭동물/척삭동물, 자포동물, 연체동물 등으로 분류할 수 있어"* + 설명·특징·가치(1x 기준) + 이미지
- 제작 — *"우선은 미구현이므로 배제"*
- 아이템 — 카테고리 분류 + 설명 + 이미지

동시에 *"퀘스트 반영 내역 테스트해보게 localhost 하나 열어줘"* — dev 서버 기동(`http://localhost:5173/`).

## 2. 원인

버그가 아니라 **데이터가 위키에 안 실려 있었다**. 168차 생성기는

- 아이템을 **정규식으로 `id`·`name`만** 긁어 카테고리·가격·설명·판매처가 통째로 빠졌다(145건).
- 요리는 `descKo`·주재료·용기 4필드만 실었다. `RECIPE_LORE`·`RECIPE_EFFECTS`·`DISH_VARIANT_LORE`·
  단계·재료 범위·별점 산식은 core에 다 있는데 아티팩트가 읽지 않았다.
- 어종은 `FISH_DATABASE` 57종만 실었다. 채집 생물 18종(`SHORE_CREATURE_DATABASE`)과
  과증식 4종(`MARINE_NUISANCES`)은 아예 없었고, 분류 축도 없었다.
- **그림이 한 장도 없었다** — 게임 텍스처는 `public/**` PNG인데 아티팩트로 옮기는 경로가 없었다.

**분류 기준** (생성기 `SPECIES_GROUPS` · `SHORE_GROUP`):

- 어류 52 · 두족류 7 · 패류 9 · 갑각류 4 · 기타 수산동물류 7 = **79종**
- 두족류 = `FISH_DATABASE`의 오징어·갑오징어·한치·참문어·대문어 + 채집 낙지·문어
- 패류 = 이매패류(바지락·굴·홍합) + 복족류(소라·전복·보말·삿갓조개·오분자기·군소)

  피낭동물·연체동물이 생기면 `SHORE_GROUP` 한 줄로 확장된다

**요리 상세** — 레시피 9종마다: 한 줄 소개 · 설명 · **가치(1x 기준)**(기준 판매가·기본 회복·버프·기준 중량 800g) ·

## 6. 잔여

- **그림 없는 항목** — 수산생물 79종 중 33종(채집 13·과증식 4 등), 아이템 318종 중 89종.
  카드는 머리글자 자리표로 대신한다. 에셋이 들어오면 `gen_wiki_images.py` 재실행만으로 붙는다.
- **요리 변형 설명** — 전용 설명이 있는 어종은 매운탕 계열 3종뿐(도감과 같은 단위). 나머지 47종은
  평균 프로필로 계산되며 표에는 후보 수만 적는다.
- **제작 탭** — 사용자 지시로 이번엔 제외. `blueprints` 데이터는 실려 있으므로 실구현 시 탭 한 줄이면 된다.
- **영문** — 위키는 한국어 전용(게임 i18n과 별개).

## 7. 위험·부작용

- **게임 런타임 영향 없음** — `packages/**` 무변경(빌드·typecheck는 회귀 확인용).
- ⚠ `tools/wiki_img/`는 gitignore다. 아티팩트를 다시 구우려면 **`py tools/gen_wiki_images.py`를 먼저** 돌려야 하고,
  안 돌리면 그림 없이 조용히 굽힌다(`manifest.json` 없으면 `imgOf`가 전부 null).
- ⚠ `dump_wiki_items.mjs`는 클라 모듈 그래프를 Node에서 돌린다. `WikiCatalog` 경로에 **Phaser·DOM 의존이 새로 들어오면**
  번들이 깨진다(현재는 `import.meta.env`만 define으로 막으면 된다).
- 아티팩트 파일 수 101 / 상한 255. 그림이 더 붙으면 `used.txt` 기준 추림이 계속 필요하다.
