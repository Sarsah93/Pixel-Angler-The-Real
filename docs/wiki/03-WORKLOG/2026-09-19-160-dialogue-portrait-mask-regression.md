## 1. 배경 — 왜 했나

사용자는 “초상화 랜더링 안되고 있음. 배선 확인할 것”이라고 보고했고, 동시에
“이름없는꾼과 초상화 위치 사이에 호감도 상태 표시를 위한 공간”과 mother 창 안쪽 여백을 요구했다.
이전 수정은 프레임 위치는 개선했지만 GeometryMask가 초상화 전체를 잘라 빈 프레임처럼 보이는 회귀를 만들었다.

## 2. 원인 — 무엇이 문제였나

`ensureFacePortrait()`가 반환하는 텍스처와 이미지 배선은 정상이었다. 실제 브라우저에서 동일한
혼잣말 진입 경로를 재현한 뒤 마스크만 우회했을 때 얼굴이 즉시 렌더되었고, 마스크를 적용했을 때만
프레임 내부가 빈 상태였다. 원인은 `Graphics` 마스크를 대상 Container 안에서 숨긴 상태로 만들어
WebGL 스텐실이 유효한 화면 좌표를 얻지 못한 것이었다.

## 3. 변경 — 어디를 어떻게

| 구분 | 위치 | 내용 |
|---|---|---|
| 신설 | `packages/client-pc/src/ui/PortraitMask.ts` | 대화 초상 공통 GeometryMask. 마스크 Graphics는 대상 Container 밖의 화면 고정 객체로 만들고 부모 월드 변환을 동기화한다. |
| 신설 | `packages/client-pc/src/ui/PortraitLayout.ts` | mother 내부 여백, 프레임 폭, 이름 간격, 호감도 예약 슬롯을 공통 상수화했다. |
| 수정 | `packages/client-pc/src/ui/MonologuePanel.ts` | 초상 프레임을 mother 안쪽으로 들이고, 얼굴·목·어깨를 마스크 안에서 중앙 배치하며, 호감도 예약 영역 뒤에 이름 슬롯을 둔다. |
| 수정 | `packages/client-pc/src/ui/DialoguePanel.ts` | NPC 대화도 같은 프레임/이름 구조와 공통 마스크를 사용한다. 기존 호감도 표시와 이름 슬롯은 유지한다. |

## 4. 구조상 위치 — 어느 계층의 무엇인가

`S10 UI 프레임워크 → 대화창 공통 초상 카드 → 렌더/클리핑 및 레이아웃` 작업이다.
게임 데이터나 호감도 판정은 바꾸지 않았고, client-pc의 렌더 계층만 수정했다.

## 5. 검증 — 무엇으로 확인했나

| 대상 | 방법 | 결과 |
|---|---|---|
| TypeScript | `pnpm --filter @tra/client-pc run typecheck` | ✅ 0 오류 |
| 변경 무결성 | `git diff --check` | ✅ 공백 오류 0건(기존 줄바꿈 경고만 출력) |
| 혼잣말 초상 | dev 서버에서 새 게임 → 슬롯 → 캐릭터 생성 → 혼잣말 진입 | ✅ 초상화 렌더, 얼굴·목·어깨 프레임 내부, 이름 슬롯 분리 |
| mother 내부 여백 | 실스크린샷 육안 검수 | ✅ 좌우 경계와 겹치지 않음 |
| 호감도 예약 영역 | 혼잣말 실렌더 | ✅ 초상과 이름 사이 빈 슬롯 유지 |
| 씬 복귀 | 대화 클릭 진행 → 필드 복귀 | ✅ 필드 정상 복귀, 오류 배너 없음 |

재현 회귀 절차: `http://localhost:5174/` → `게임 시작` → `혼자 하기` → `이어하기` → 슬롯 선택 →
캐릭터 생성 → `이대로 생성하기` → 혼잣말 화면. 혼잣말 화면에서 빈 초상 프레임이 아니라 얼굴이 보여야 한다.

## 6. 잔여 — 이번에 안 한 것

NPC가 표시하는 실제 호감도 값은 기존 `DialoguePanel` 배선을 유지했다. 혼잣말은 주인공 독백이므로
호감도 문자를 표시하지 않고 슬롯만 예약한다. NPC 대화에는 같은 공통 마스크·레이아웃을 적용하고
타입검사로 컴파일을 확인했으며, 속초 이동과 NPC 상호작용의 장시간 수동 플레이는 사용자의 다음
실검증 범위로 남긴다.

## 7. 위험·부작용

GeometryMask가 화면 고정 좌표를 사용하므로 패널 드래그 시 `postupdate` 동기화가 반드시 필요하다.
두 패널 모두 이동 시 `sync()`하고 destroy 시 마스크/Graphics를 함께 정리한다. 기존 CanvasTexture 방어선과
HMR 게임 인스턴스 정리도 유지한다.
