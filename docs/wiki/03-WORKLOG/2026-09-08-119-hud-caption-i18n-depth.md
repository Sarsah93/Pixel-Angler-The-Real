## 1. 배경 — 왜 했나

118차 HUD·i18n 작업에 이어 사용자가 8건을 지시했다(원문 요지).

1. **HUD 타이틀바 여유** — "HP BAR와 확장 아이콘 + 투명화 아이콘이 겹치고 있기 때문에 겹치지 않도록".
   다른 HUD 창도 "타이틀바(혹은 캡션바)가 아래 컨텐츠와 겹치지 않도록" 전수조사하고 **향후 개발 규칙으로 지정**.
2. **지역 채널 3단계** — 큰=현행 / 중간=시각 제거 / 최소=본문 10자 초과 시 말줄임("짧은 내용은 보이도록").
3. **텍스트 밀림·오버플로 전수조사** — 월드맵 '집으로 돌아가기' 버튼이 '출조지 선택'과 겹침. **규칙 지정**.
4. **랜딩 후 수심 정보 오류** — "왜 뒤로 가는 연출이 보이며, 왜 거리가 캐릭터 아이콘에 가깝지 않은지",
   어종 정보창 상태에서 배경 좌클릭 시 릴링 진행 → BLOCK, 수평뷰 조류·바람 영향이 어획 후에도 실시간.
5. **수심 정보 물고기 아이콘** — 머리·꼬리 좌우 반전 + 챔질 성공 후 1.2배·희귀도 색
   (검붉은색 ≥2.4×는 **빨간색으로 표시**해 "더 강한 개체임을 서프라이즈로" 남긴다).
6. **영어 전수조사** — 요일·채널 태그·장비 슬롯 툴팁·맵 이름·어종명·아이템명·채비/요리 창·
   도움말 라이브러리 본문 + **캡처 화면 indication/annotation 영문판**.
7. 단축키 버튼 라벨 '단축키' → **'도움말'**.
8. 아이템 슬롯 수량 `x숫자` 우측 하단 → **우측 상단**.

## 2. 원인 — 무엇이 문제였나

### 2-1. HUD 타이틀바 (①)
상태 패널에는 타이틀바 개념이 없었다. `paintHudPanel`을 헤더 밴드 없이 그리고 컨텐츠를 패널 상단에서
바로 시작했는데, 조절 버튼(◱ ◐, 16px)은 `top = SP.y = 16`에 놓였다 → **버튼 y 16~32 vs HP 바 y 28~38 = 4px 겹침**
(전 크기 단계 공통, 116차부터 존재). 지역 채널은 밴드가 있었지만 높이가 `round(21 × k)`라
**축소 단계(k=0.5)에서 11px로 줄어** 버튼(16px)이 로그 뷰포트를 침범했다.

### 2-2. 월드맵 겹침 (③)
좌상단 홈 버튼(`bx=16, by=14, bw=150, bh=34`)은 `create()`에서 참조 없이 만들어져 **숨길 수단이 없었다**.
- 전국 지도 뷰: 타이틀 `출조지 선택`(x 20~127, y 22~48)이 버튼 사각형 안에 완전히 포함 → 가려짐.
- 지역/스팟 뷰: `← 전국 지도`(16,14,130,30)·`← 지역 지도`(16,14,120,30)가 같은 자리라
  **홈 버튼 히트렉트(depth 122)가 뒤로가기 클릭을 통째로 삼켰다.**

### 2-3. 랜딩 후 채비가 뒤로 감 (④)
`update()`가 상태와 무관하게 조류를 적용했다 — `distM = max(0.3, distM + influence.force.y * dt)`.
결과(result) 상태에서도 반탄류(+Y)가 계속 더해져 거리가 **늘어난다**. 랜딩 판정은 발앞 3m에서 나므로
거리축 마커도 그 자리(≈88%)에 멈춘 채 뒤로 밀렸다. 좌클릭은 `fpState` 가드가 없어 결과창에서도 `reeling = true`가 됐다.

### 2-4. 영어 미반영의 근본 원인 (⑥)
`translateOnce`가 규칙 치환을 `s.replace(re, rep)`로 처리해 **`$1` 캡처 안의 한국어가 재번역되지 않았다**.
게다가 규칙이 한 번 맞으면 `translateDeep`의 분해 단계(줄/태그/구분자/괄호)가 전부 건너뛰어져,
포괄 규칙 `[/^\[(\d\d:\d\d)\] (.+)$/]` 하나가 **지역 채널 로그 전체의 번역을 막고 있었다**
(사전에 `[시스템]`·`[이동]` 항목이 있는데도 발동한 적이 없었다).

## 6. 잔여 — 이번에 안 한 것

- **OSM POI 상호명은 한국어 유지**(속초마트·스끼다시천국횟집 등 74개). 실제 상호라 로마자 표기는 의미가 없고
  현장 간판과 같은 것이 자연스럽다고 판단했다. 필요해지면 `regions_config.py` 단계에서 `nameEn`을 붙여야 한다.
- **튜토리얼 삽화 18장은 한국어판 유지** — 목업 HTML(`docs/mockups/game_guide_hub.html`)에서 렌더한 SVG라
  영문판을 만들려면 목업을 영어로 다시 렌더해야 한다. 실캡처 기반인 `guide_fight_6`만 영문판을 만들었다.
- 손질/도감/아이템 상세의 **일부 동적 조립 문자열**(`미끼 krill·shrimp`, `바늘 간격 0.3m`, `평균 정확도 82%` 등)은
  정확 일치 키가 불가능해 규칙이 더 필요하다. 지금은 원문이 남는다(깨지지 않음).
- `RegionDef`/`WorldMapNode`/`RegionMapNode`에 `nameEn` 필드를 넣는 편이 사전(`places.ts`)보다 근본적이다 — 차기.

## 7. 함정 — 다음 사람이 밟을 것

1. **규칙 치환의 캡처는 재번역되지 않는다** — `s.replace(re, '$1 …')`은 `$1` 안의 한국어를 그대로 흘린다.
   이번에 `applyTemplate`로 해결했지만, **함수형 규칙은 직접 `tr(m[n])`을 호출해야 한다**.
2. **탐욕적 규칙은 반드시 맨 끝** — `[/^(.+)원$/]`이 앞에 있으면 `2부위 착용 · 280,000원`을 통째로 삼켜
   본문이 한국어로 남는다. 규칙을 추가할 때는 **더 구체적인 것이 위**.
3. **Text의 `width`는 텍스트를 넣은 뒤에야 확정된다** — 생성 시점(빈 문자열)에 `x = 앞 요소.width + n`으로 잡으면
   0 기준이 되어 겹친다(실측: 주야간 라벨이 시계 위에 겹쳤다). 흐름 배치는 **값을 채운 뒤** 다시 잡는다.
4. **Graphics/Text에 `setInteractive()`를 걸지 말 것** — 히트 영역이 없어 포인터 처리 중
   `TypeError: input.hitAreaCallback is not a function`으로 터진다. 표시/입력 토글은 **이미 인터랙티브한 오브젝트의
   `input.enabled`**만 건드린다.
5. **PIL 기본 한글 폰트에 `◱`가 없다** — 주석 이미지에서 두부(□)로 찍힌다(117차부터 있던 것). 콜아웃 라벨에는
   UI 글리프 대신 낱말을 쓴다.
6. 영어 캡처는 `localStorage['pixelAngler_settings'] = {"language":"en"}` 프리시드로 찍는다.
   캐스팅 성공 좌표는 `devTeleport(568*32, 142*32)` + 마우스 (900, 440)가 안정적이다.
