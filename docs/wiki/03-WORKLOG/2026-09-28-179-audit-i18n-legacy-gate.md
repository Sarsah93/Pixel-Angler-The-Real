# 179차 — 전체 코드베이스 전수조사: 영문 잔존 · 개발 용어 노출 · 이모지 · 구 제품명

- **날짜**: 2026-09-28
- **지시**: *"다른 모든 부분에서 전체 코드베이스 전수조사해서, 누락/새고 있는 것,
  미구현된 부분 제외한 부족한 부분들을 전체적으로 검사하고 교정해줘."*

---

## 1. 배경

178차까지의 기능은 한국어 화면 기준으로 검증돼 왔다. **"미구현"이 아니라 "구현했는데 새고 있는 것"**
을 찾는 것이 이번 과제라, 이 레포가 반복해 밟은 결함 패턴을 기준으로 훑었다 —
리스너·타이머 정리 누락 / 죽은 배선 / 세이브 갭 / **영문 잔존** / 개발 용어 노출 / 이모지 / `any` /
하위 씬의 `scene.start`.

---

## 2. 원인 — 확정된 것

### 2-1. 영문 잔존 (가장 큰 구멍)

**신규 UI 문구를 i18n 사전에 넣는 절차가 여러 차수에 걸쳐 빠져 있었다.**
178차 문구는 **사전 수록 0건**(`상호작용`·`아이템 줍기`·`내려놓기`·`모두 닫기`·`할 일 위치 안내` …).

측정 방법 2단:

1. **정적 추출** — 렌더 자리(`add.text`·`setText`·`label:`·`floatingHint`·`pushLog`)의 한국어 리터럴
   1,099건을 뽑아 실제 `t()`에 통과시킴 → **미번역 468건**.
2. **실렌더 스캔**(정본) — 설정을 영어로 두고(`pixelAngler_settings.language='en'`) 부팅해
   화면별 살아 있는 `Text`를 훑음. ⚠ 하네스에서 `import('/src/i18n/I18n.ts')` 후 `setLocale`을 부르면
   **게임과 다른 모듈 인스턴스**를 만져 0건처럼 보인다(17·120차 함정의 재현) — 반드시 **설정값으로**
   부팅해야 한다.

### 2-2. 개발 용어·레거시 경로 노출

지역 지도 하단에 **`낚시터 목록 (임시)`** 버튼이 상시 떠 있었고, 그 버튼이 심리스 필드가 아니라
**구 낚시 루프(`FieldScene` 스택)** 로 들어갔다. 그 스택은 이모지·미번역 문구가 그대로 남은
폐기 후보 경로다(§8-9 위반 + 유저 혼선).

### 2-3. 이모지 · 구 제품명

§8-8을 어긴 렌더 문자열이 현역 화면에 4곳(월드맵 자물쇠 `🔒` ×2 · 설정 `✅` · 도감 `👑`),
출조 확인 모달에 7곳. 부팅 화면에는 **구 제품명 `더 리얼 앵글러`** 가 남아 있었다.

### 2-4. 사전 분해가 만든 오역

일지 난이도 칸이 **`months 수 · Move`** 로 나왔다. 원문은 `수월 · 이동` —
`수월`이 사전에 없자 분해 경로가 `월`을 `months`로 바꿔 버린 것. **난이도 5종이 사전에 없었다.**

### 점검했으나 고치지 않은 것 (근거)

- **리스너·타이머 정리**: 패널 23종 전수 — `input.on`/`keyboard.on`/`events.on`이 전부 `destroy`에서
  해제되고 있었다(**누락 0**). `SashimiPanel`의 이중 등록처럼 보이던 것은 두족류 분기의 `return`이었다.
- **죽은 배선**: core 공개 함수 478개 중 정의 파일 밖 참조 0회가 **152개**. 다만 대부분 라이브러리
  표면(조회 헬퍼·Mock·API 파서)이고, `setVitalsCaps`는 클라가 **파생 getter로 같은 일을 하고 있다**
  (`GameState.maxHunger`가 `skillBonus('hunger_max')`를 더한다 — 죽은 보상이 아니다).
  **규칙이 선언만 되고 소비되지 않는 것**(`canUseGear`·`nuisanceCullValue`·`isFishableStandTerrain`)은
  "미구현" 쪽이라 이번 범위에서 제외하고 백로그로 넘긴다.
- `any` 7곳은 dev 전역(`globalThis as any`)·Phaser 핸들러 시그니처라 유지.
- 하위 씬의 `scene.start('RegionFieldScene')`은 전부 **최상위 씬**(메인메뉴·월드맵·캐릭터 만들기)
  이거나 자기 재시작이라 §8-7 위반 아님.

## 6. 잔여

- **레거시 `FieldScene` 스택**(Restaurant·Cook·Condo·Trap·NightHunting·CoolingBox·HUD·EnvironmentHUD)의
  이모지·미번역은 **그대로 둔다** — dev 전용으로 내렸고, 폐기 여부가 정해지기 전에 손대면 낭비다.
- `TileCatalog`(150건)·`SeamlessChunks`(69건)는 **편집기 팔레트 라벨** — dev 전용.
- 규칙 선언만 있고 소비처가 없는 core 함수 3종은 백로그(미구현 축).

## 7. 위험·부작용

- ⚠ **영어 화면의 문구가 대거 바뀐다**(한국어 화면은 불변). 번역 톤이 어색한 항목은 사전 한 줄 수정으로 교정 가능.
- ⚠ **레거시 필드는 프로덕션에서 더 이상 들어갈 수 없다.** 회귀 확인이 필요하면 dev 빌드로.
- 자물쇠는 텍스트 → `Graphics`로 바뀌었다(배치 좌표 동일, 컨테이너 소속 동일).
