## 1. 원인

1. **작업 패널 침범** — 95차 skin 섹션이 7작업이 되며 2열 그리드 4행(H 136)이 도마 프레임
   상단(164)을 10px 침범 (레이아웃 상한 미검증 — §4 검수 규칙 위반).
2. **크기 널뜀** — 회전 스케일이 "스테이지 내 최대 프레임 기준 예산 클램프"라, 사진마다 크롭
   배율이 달라 프레임 전환 때 몸통 크기가 널뛰었다 (flip 222px → peel_1 131px · peel1 사진은
   456px로 도마 이탈).
3. **연출 중 에셋 전환** — `cephFrameAt(0)`이 연출 시작에 결과 프레임을 그렸다
   (53차 "연출이 끝나기 전 다음 상태 금지" 규칙 미적용).
4. **플랩 배경색** — 목업 캡처의 플랩이 도마색 계열로 구워짐.

| 구분 | 내용 |
