## 1. 배경 — 왜 했나

사용자 원문(요지):

> "우선은 제안대로 A~F 진행해줘."
>
> "1) 실제 시간 새벽 3시에 구매해 튜토리얼 시작 — 막히는 부분이 없는지? 2) '저장하고 자기'는 어느 포지션인지?
> 저장만 하기: 피로도 회복 X / 누워 자기(휴식) … 3) 휴식 중 그냥 일으켜 세워도 되는지? 기다린 만큼 회복? 4) 집 바깥 강제 종료는?"

212차 §6 제안 A~F를 구현하고, 질문 1~4에 맞춰 침대 메뉴를 다시 짰다(「저장하고 자기」를 없애고 **자기 = 다 자면 저장**).

## 2. 원인 — 조사에서 확정한 것

| 항목 | 조사 결과 |
|---|---|
| 잠 연타 | 잘 수 있는 조건이 없어 침대를 연달아 쓰면 이야기 날짜가 계속 넘어갔다(기한 · 품삯 횟수 · 갱신일) |
| 저장 = 잠 | 저장하려면 하루를 넘겨야 했다 |
| **새벽 3시 튜토리얼** | 프롤로그의 가게(직판장)는 24시간이라 막힘 없음. **그러나 위판(선어 01~03시 · 활어 03~07시 · 일요일 쉼)이 이야기 12편의 목표**(M2-01 「첫 위판」 등 `auto('sell')`)였다 — 그 시간에 못 오는 사람은 진행 불가(R12 위반) |
| 생존 수치 오프라인 | 허기 · 수분은 노는 동안(`tickVitals(delta)`)만 닳는다 — 꺼 둔 사이엔 그대로 |

### 시간대 감사(F) — 실제 시각에 묶인 것

| 무엇 | 시간 | 막힘 여부(213차 뒤) |
|---|---|---|
| 직판장(미끼 · 채비 · 매입) · 편의점 | 24시간 | 없음 — 프롤로그 구매 · 판매가 여기라 새벽 3시 새 게임도 진행된다 |
| 마트 · 생활용품 · 약국 · 식당 · 카페 · 주점 | 10~22시 | 문 앞 혼잣말 — 이야기 목표가 이 가게에만 묶인 것은 없다 |
| 위판(선어 01~03 · 활어 03~07 · 일 쉼) | 새벽 | **맡겨 두기로 해소** — 이야기 12편이 막혀 있었다 |
| 밤 조명 · 가로등 | 20~05시 | 연출만 |
| 입질 시간대 · 피딩 · 해루질 밤 간조 | 어종 · 물때별 | 가중치(막지 않음) — 「내일」 한 줄이 언제가 좋은지 알려 준다 |

### 삭제

「저장하고 쉬기」 · 「그냥 쉬기」 메뉴 — 「저장만 하기」 + 「자기(다 자면 저장)」로 대체(사용자 질문 2 — 위치가 모호했다).

## 4. 구조상 위치

- **홈 → 잠**: 계약(core `Sleep`) · 판정(core `SleepRules`) · 데이터(`GameState.awakeMs` · 세이브) · 렌더(잠 창).
- **세이브**: 저장 지점이 「저장만 하기」와 「다 잔 잠」 둘. 오프라인 잠은 **불러오기 시점**에 판정한다(세계 시계 KST 기준 실제 경과).
- **경제 → 위판**: 판정은 기존 core 위판 엔진 그대로(현장 경매와 같은 규칙) — 맡긴 묶음을 회차 시각으로 굴린다.

## 6. 잔여 · 설계 제안 (사용자 질문 2~5)

- **농사**(질문 2): 자람은 **이야기 날짜(다 잔 잠)** 단위 — 잠 조건(A) 덕에 「연타로 수확」은 막히고, 하루 몇 시간 노는 사람은 스타듀처럼 며칠 치를 진행한다.
  계절은 실제 계절(작물이 3개월 내내 자란다) · 실제 비가 오면 물 준 것으로. 하우스(비닐)로 계절 밖 작물.
- **이야기 날짜 탭**(질문 3): 일지(J)에 「나날」 탭 — 이야기 N일째 · 기한(D-day) · 정기 지출 날짜 · 지난 하루(결산) 목록. 장부를 그대로 쓰면 된다.
- **NPC 일과**(질문 4): 인물마다 시간표(집 · 일터 · 바깥 · 24시간형). R12에 맞춰 이야기 목표는 넓은 때만 — 집에 있을 땐 **문 두드리기**로 대화.
- **실내 공간**(질문 5): 집 실내 엔진을 데이터로 일반화(`InteriorScene` + 방 템플릿) → 1단계 가게 · 보건소 · 위판장, 2단계 주요 인물 집, 3단계 아파트 공용 템플릿.
- 도움말 「집」 실캡처(침대 메뉴)가 옛 메뉴 — 다음 캡처 갱신 때.
- `TUNING.sleep` 실플레이 조율(15초 · 50% · 60분 · 4시간).

## 7. 위험 · 부작용

- 맡긴 물건은 위판장이 보관하는 동안 신선도가 멈춘다(세이브 스냅샷) — 유찰되면 맡긴 때 상태로 돌아온다.
- 오프라인 잠은 저장 시각(`lastSavedAt`) 기준 — 저장 없이 오래 놀다 끄면 그 놀이는 사라지고, 다음 불러오기에서 저장 시점 상태로 판정한다.
- 기존 세이브: 깨어 있은 시간이 없으면 60분으로 채워 바로 잘 수 있게 했다.
- 하루 경계 변경(자정 → 새벽 4시): 이미 닫힌 장은 그대로, 다음 장부터 새 경계.
