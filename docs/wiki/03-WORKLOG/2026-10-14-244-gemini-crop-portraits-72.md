# 244차 — 작물 초상 72장(Gemini 자동 생성) · 카드 초상 · 새 창 포커스 (2026-10-14)

> 시스템: 실사 도트 · 홈(농장) · UI 프레임워크 · 위키
> 계층: 에셋(초상 72) + 도구(생성 · 카드 출력) + 렌더(부팅 로드 · 창 깊이)

## 1. 배경 — 왜 했나

243차에 Gemini API 키를 네트워크 시크릿으로 붙였고, 사용자가 결제를 켰다.

- 「Gemini 결제 켰어, 딸기 변환 시험해봐.」 → 딸기 사진 1장을 Nano Banana 2 · 2.1 · Pro로 변환해 비교(243차 후속 기록).
- 남은 72종은 사진이 없어 두 방법을 냈다 — ① 사진 없이 「이름 + 생김새 설명 + 기존 변환본을 화풍 참고」로 그리기 ② 사진을 받아 변환.
- 「1번으로 진행해, 2.1 모델로」 → ①을 `gemini-nano-banana-2.1`로.

## 2. 판단 — 무엇을 어떻게 정했나

- **생성 방식**: 요청마다 화풍 참고 그림 3장(사용자 Gemini 앱 변환본 딸기 · 청치마 · 감자, 긴 변 512px)과 작물별 생김새 한 줄(`LOOKS`)을 보낸다.
  「참고 그림 속 물체는 그리지 말 것 · 순백 배경 · 한 단위만 · 그림자 · 접시 · 글자 없음」. 비율 1:1.
- **시범 4장**(곰취 · 오이 · 고구마 · 느타리)으로 화풍 · 단위 · 배경을 먼저 확인했다 — 아이콘 크기에서 기존 12장과 어울렸다.
- **검수**: 12장씩 시트(칸 아래 id)로 72장 전수. 다시 뽑은 것 2장.
  - 루꼴라 — 이름의 「한 봉」을 따라 **비닐봉지에 담아** 그렸다 → 「봉지 · 포장 없이 잎만」.
  - 대파 — 쪽파처럼 가늘었다 → 「엄지 굵기 흰 줄기가 절반, 쪽파보다 훨씬 굵다」.
- **카드 초상(메모리)**: 상세 창은 초상을 228×90 칸(높이 90px 안팎)에만 그린다. 셀 6px 원본(1,170px)을 그대로 싣으면
  장당 텍스처 약 5MB — 12장으로 59MB, 84장이면 약 440MB였다. 그래서 파이프라인이 칸 크기 카드(`<id>_card.png` · 면적 평균)를 따로 굽고
  게임은 카드와 64px 아이콘만 싣는다. 90px로 줄일 때 NEAREST 표본이 셀을 건너뛰던 깨짐도 함께 없어진다.
- **원본 보관**: `asis/`에는 긴 변 640px PNG만 넣는다. 640px 원본의 초상은 1,024px 원본의 것과 corr 0.99 · IoU 0.99~1(3종 실측) — 용량은 절반(72장 약 26MB).
- **곁가지 버그(창 포커스)**: 가방 우클릭 「상세보기」로 연 상세 창이 곧바로 가방 창 아래로 깔렸다(실측 상세 881 · 가방 882).
  기전 = 메뉴 단추의 pointerdown이 상세 창을 열어 맨 위로 올린 뒤, 같은 클릭의 씬 pointerdown에서 가방 창이 「눌린 창은 맨 위로」로 되올라왔다.
  같은 클릭으로 새로 연 창이 있으면 다른 창이 포커스를 되가져가지 않게 했다(122차 「새 팝업은 맨 위」 규칙과 정합).

## 4. 구조상 위치 — 어느 계층의 무엇인가

실사 도트 → 작물 초상 → 에셋 층(원본 `asis/` → 파이프라인 → `public/crops/`). 판정 · 데이터는 그대로다(아이템 id · 아이콘 키 `px:crop_*` 불변).

## 6. 잔여 — 이번에 안 한 것

- **중간 수확물 8 · 팩 6 초상** — 생김새(`LOOKS`)는 이미 있다. `--set extra` · `--set pack`으로 약 0.5달러.
- **어종 그림 53장도 원본을 그대로 부팅 때 싣는다**(텍스처 약 181MB) — 같은 카드 방식(상세 창 228×90)으로 줄일 수 있다. 낚시 결과 팝업 크기를 확인한 뒤 착수.
- **셀 6px 원본 84장(약 9MB)이 배포본에 실린다** — 게임은 읽지 않는다(위키 재료). `public/` 밖으로 옮기면 배포가 가벼워진다.
- 방울토마토 1개 · 청양고추 그림은 토마토 · 풋고추와 크기 차이가 안 보인다(칸을 꽉 채우는 그림이라). 필요하면 `LOOKS`로 다시.
- gh-pages 배포는 하지 않았다(사용자 요청 없음).

## 7. 위험·부작용

- **AI 생성 에셋 고지** — 작물 초상 84장이 모두 Gemini 산출물이다(사용자 앱 변환 12 + API 72). Steam 출시 때 AI 생성 콘텐츠 고지 대상이다.
  Gemini 출력에는 보이지 않는 SynthID 표식이 들어 있다.
- **재현성** — 같은 프롬프트로 다시 뽑아도 같은 그림이 나오지 않는다. 원본은 `asis/`가 정본이다(다시 뽑기는 교체 결정).
- **창 포커스 변경은 모든 팝업에 걸린다** — 「버튼 클릭으로 새 창을 연 그 클릭」에서만 클릭된 창의 포커스 가져가기를 막는다. 키보드로 연 창 · 다음 클릭은 종전과 같다.
- 모델 단종 — 요금표에 2.5 Flash Image 단종 예고가 있었다. `--model`로 바꾸면 화풍이 달라질 수 있어 시범 4장부터 다시 본다.
