## 1. 배경 — 왜 했나

117차(도움말 라이브러리·HUD·파이팅 물리)를 사용자가 실플레이로 검토한 결과 8건이 돌아왔다. 두 건은 실버그
(좌상단 상태 패널이 **아예 안 보임**, 지역 채널 크기 버튼이 **뒤에 같은 창을 겹쳐 생성**), 나머지는 입력 조건 재정의·
표기 변경·영어 지원·캡처 보강이다.

## 2. 원인 — 무엇이 문제였나

- **상태 패널 미표시**: `createStatusPanel`이 래퍼 컨테이너를 **자기 자신에 add**(`statusC.add(statusC)`)했다 —
  HUD(this)의 자식이 아니라 디스플레이 리스트 밖으로 빠져 한 번도 그려지지 않았다. 116차 하네스는 `statusAlpha`
  같은 상태값만 확인해 놓쳤다(스크린샷 육안 확인 누락).
- **채널 중복 생성**: `applyChatView → createLogPanel`이 이전 패널(`logParts`)·마스크·씬 입력 핸들러를 걷어내지
  않고 새로 만들었고, 크기 단계 `k`를 치수에 곱하지도 않았다(고정 300×148) — "축소"가 아니라 "겹침".
- **캐스팅 힌트 오발동**: 씬 `pointerdown`이 **어떤 인터랙티브 오브젝트 위 클릭인지 보지 않았다** — HUD 버튼·
  단축키 버튼·미니맵 위 클릭도 맵 클릭으로 취급돼 `tryStartCharge → "바다 가까이…"`가 떴다.
- **채비 창 오버플로**: 루어 제원 6줄을 고정 22px 행 · 2열로 찍어 "타겟 가중: …" 한 줄이 열 폭을 넘었다.
  같은 부류의 버그가 재발한 이유는 **패널 단위 마지막 방어선이 없었기** 때문.
- 튜토리얼 파이트 1·3페이지가 같은 SVG(`guide_fight_3`)를 썼고, 파이팅 실캡처는 "하네스로 입질을 강제할 수
  없다"고 플레이스홀더로 남겨 두었다 — 실제로는 씬 dev 훅 하나면 강제할 수 있었다.
- 영어: `GameSettings.language`가 있었지만 소비처가 없었다(설정 탭에 '예정' 표기).

## 3. 변경 — 어디를 어떻게

### 3-1. HUD (`ui/RegionHud.ts`)

| 항목 | 변경 |
|---|---|
| 상태 패널 | `this.add(statusC)` — 좌상단 (16,16) 고정 축소(`SP.x·(1−k)` 보정). 실측 0.5단계 위치 (8,8) |
| 지역 채널 | `destroyLogPanel()` 신설(파츠·마스크·wheel/pointermove/pointerup 핸들러 해제) 후 재생성 · **치수·폰트·헤더/입력란 높이에 k 곱** · 좌하단 (16, H−20) 고정 · 실측 300×148 → 225×111 → 150×74, `logParts` 항상 7 |
| 투명 | `HUD_ALPHAS` 최저 0.12 → **0.05**(배경이 거의 그대로 비침) · 모서리 버튼은 래퍼 밖이라 잔존 |

### 3-2. 캐스팅 힌트 입력 조건 (`scenes/RegionFieldScene.ts`)

- 씬 `pointerdown(p, over)` — **`over.length > 0`(인터랙티브 오브젝트 위) 이면 즉시 return**. 설치 확정도 같은
  가드 뒤. `isPaused`도 명시 체크. 검증: 미니맵·HUD 버튼·단축키 버튼 클릭 = 힌트 0 / 뭍 맵 클릭 = "바다 가까이".
- 단축키 버튼 라벨 `'단축키'`(12px 한 줄) — 영문 병기 제거.
- ESC 메뉴에 **[환경설정]** — `openSettingsFromPause()`: pause + `launch('SettingsScene', {returnScene})`.
  `SettingsScene.init(data)`가 `returnScene`을 받아 닫을 때 그 씬을 resume(기본 메인 메뉴).

### 3-3. 희귀도 표기

`[보통 · 평균 1.14×] 망상어 24cm…` → **`망상어 24cm / 0.37kg / 수컷 [1.14×, 평균]`**. common 라벨 '보통' → **'평균'**
(`core/simulation/FishRarity.ts`), 인벤 요약은 뒤에 `[1.14×, 평균]`, 상세보기 행 `1.14×, 평균`.

### 3-4. 채비 창 오버플로 + 마지막 방어선 (`ui/TextFit.ts` · `ui/UtilizationPanel.ts`)

- 루어 제원 = **2열 흐름 배치**(열 폭 wordWrap · 다음 줄을 실제 높이만큼 밀어냄).
- **`enforceTextBounds(container, maxRight, tag)`** 신설 — 컨테이너 트리의 모든 Text를 우측 경계 안으로 강제
  (남은 폭 wordWrap → 그래도 넘치면 말줄임) + dev `console.warn('[TextOverflow] …')`. `UtilizationPanel.renderBody`
  마지막에 호출. 검증: 루어 탭 최우측 691 ≤ 1060, 경고 0.

### 3-5. 영어 설정 (`i18n/I18n.ts` · `i18n/en.ts` — 신규)

- **원문(한국어) = 키** 사전. `Phaser.GameObjects.Text.setText`를 훅해 **모든 Text가 생성·갱신 시 사전을 통과** —
  호출부 수백 곳을 `t()`로 감싸지 않는다. 정확 일치 → 정규식 규칙(수치·이름 섞인 문장) → 줄/구분자(`›` `·` `—` `|`)
  분해 → 글리프 접두(`▾ 라벨`) 분해 → `[태그] 본문` 분해. 한글 없는 문자열은 즉시 통과. 어종명은 `FISH_DATABASE.nameEn`
  런타임 합류. 결과 캐시.
- 언어 전환 = `setLocale(l, game)` → **살아 있는 씬의 Text 전부 원문(`__i18nSrc`)으로 재-set** → 재시작 없이 즉시.
  `game.ts`가 `installI18n(loadSettings().language)`를 게임 생성 전에 호출. 설정 언어 탭 English 개방(즉시 저장·적용).
- 사전 규모: 정확 일치 ≈ 620 · 규칙 ≈ 110 (필드·HUD·메뉴·설정·다이얼로그·인벤·상점·장비·쿨러·냉장고·홈·전국 지도·
  1인칭·채비/요리/밑밥·손질 주요·도감·도움말 라벨/제목/캡션/본문 대부분·가이드 허브 전체·아이템 시드명·신선도).
- 검증(하네스): 설정 → English → 메인 메뉴/일시정지/인벤 탭/HUD/도움말 트리·본문 EN, 리로드 후 유지, pageerror 0.

### 3-6. 튜토리얼·도움말 캡처

- **dev 훅** `FirstPersonFishingScene.devForceBite()` · `devForceFight(pattern, lateralDir)` + `globalThis.__FP` —
  하네스가 입질 시퀀스와 파이팅(패턴 강제)을 즉시 만든다. 프로덕션 no-op.
- 파이트 튜토리얼 1페이지 = **`guide_fight_6`**(`tools/compose_fight_guide.py` — 실캡처 3장 여 박기/바늘털이/횡 러닝
  합성 640×300, 상황 → 대응 캡션). 3페이지와 삽화 중복 해소.
- 도움말 실캡처 8장 추가: 상점 거래(문 앞 캐릭터 + 좌 상점 + 우 인벤) · 도마 위 생선 · 손질 패널 · 밑밥 탭 · 도감 ·
  입질 3단계 · 끌어오기 화살표 · 어획 팝업. `help_fp_fight` 플레이스홀더도 실캡처로 교체. 총 21장.
- **선명도**(`tools/annotate_help_images.py`): 1280 캡처를 **패널 표시 폭 688px로 먼저 축소**(LANCZOS+언샤프)한 뒤
  그 위에 라벨(13px 볼드 + 외곽선)을 최종 픽셀로 그린다 — 게임이 1:1로 그려 텍스트가 재샘플링되지 않는다
  (116차는 1280에 그리고 960으로 줄여 흐렸다).

## 4. 구조상 위치 — 어느 계층의 무엇인가

- i18n은 client 전용 계층(`client-pc/src/i18n/`) — core는 한국어 원문 데이터를 그대로 두고, 표시 시점에 사전을 탄다.
  데이터에 `nameEn`이 있는 것(어종)은 그것을 쓴다.
- `enforceTextBounds`는 `TextFit.ts`의 세 번째 방어 수단 — 배치 규칙(§ui-panel)을 어겨도 창 밖으로는 못 나간다.

## 6. 잔여 — 이번에 안 한 것

- **사전 미수록 문장은 한국어로 남는다** — 손질 스테이지 안내(ButcheryPanel 190건 중 주요만), 도감 설명문, 아이템 상세
  설명 일부, 상점 카탈로그 아이템명(시드명은 수록), 회썰기 패널, 편집기/dev 콘솔(dev 전용). 다음 회차에 파일 단위로
  이어 채운다(키 = 원문이라 코드 수정 없이 `en.ts`에 추가만).
- 영어 문장이 더 길어 고정 폭 버튼·라벨에서 잘릴 수 있다 — `enforceTextBounds`가 있는 패널(활용)은 안전, 나머지는
  실플레이 관찰 대상.
- 채널 채팅 EN은 예시 문구만 번역(멀티플레이 전).

## 7. 위험·부작용

- `Text.setText` 프로토타입 훅은 게임 전역 — Text 원문을 코드에서 `t.text`로 읽어 **한국어와 비교**하는 로직이 있으면
  EN에서 어긋난다(현재 검색상 없음). 새 코드에서 `text === '한글'` 비교 금지.
- 캐스팅 힌트 가드는 "인터랙티브 오브젝트 위"를 전부 막는다 — 맵 위에 인터랙티브 오브젝트가 생기면(설치물 등) 그 위
  클릭은 캐스팅이 아니게 된다(의도).

## 8. 후속 (같은 날) — 상태 패널 3단계 가독성 + 단축키 버튼 토글·커서

사용자 재검토 2건.

### ⓐ 상태 패널 = "정보량 축소"로 재설계 (`ui/RegionHud.ts`)

구 구현은 컨테이너 `scale`(1/0.75/0.5)이라 **글씨까지 같이 줄어 최소 단계에서 읽을 수 없었다**.
단계마다 **실치수 레이아웃으로 재생성**하고 폰트 크기는 어느 단계에서나 동일하게 둔다(clock 18px 고정 실측).

| 단계 | 패널 | 내용 | 호버 |
|---|---|---|---|
| 0 전체 | 320×176 | 기존 그대로(배지 2열×2행 + 캡션) | 없음 |
| 1 중간 | 236×132 | HP·피로도·날짜·시각 + **배지 아이콘 1행 4개**(캡션 제거) | **아이콘별** 1줄 툴팁 |
| 2 최소 | 196×84 | **HP·피로도·시각만**(날짜·날씨 제거) | **패널 어디든** 날씨 4종 전체 툴팁 |

- 툴팁은 **커서 우측 하단**(+14,+16)에 붙고 화면 밖이면 반대편으로 접힌다. 아이콘 원 + 텍스트를 함께 그린다.
- 배지 내용은 단계와 무관하게 `badgeData`에 항상 기록 — 최소 단계에서도 툴팁이 실시간 값을 쓴다.
- `destroyStatusPanel()`(파츠·툴팁 정리) 후 재생성 — 지역 채널과 같은 규칙.

### ⓑ 단축키 버튼 — 재클릭 시 닫기 + 커서 (`RegionFieldScene` · `DraggablePanel`)

- **원인 실측**: Phaser `InputManager.resetCursor`는 **`useHandCursor` 객체가 파괴되기만 하면**(포인터 아래였는지와
  무관) 캔버스 커서를 기본값으로 되돌린다. 버튼 클릭 → 팝업이 열리며 `showTopic()`이 인터랙티브 자식을 파괴 →
  커서가 풀리는데 포인터는 버튼 위 그대로라 `pointerover`가 다시 오지 않아 복구되지 않았다.
  하네스 실측: 1클릭 `pointer` → **2클릭 `''`(기본값)**. HUD ◱/◐ 버튼도 자기 재생성 때문에 같은 증상.
- **수정**: `DraggablePanel.restoreHandCursor(scene)` 신설 — 인터랙티브 자식을 파괴하는 동작 직후 호출.
  단축키 버튼과 HUD 조절 버튼에 적용. 단축키 버튼은 **재클릭 = 닫기(토글)** 로 변경.
- 검증: 1클릭 열림·`pointer` / 2클릭 닫힘·`pointer` / 3클릭 재열림·`pointer` · HUD ◱ 클릭 후 `pointer` · pageerror 0.
