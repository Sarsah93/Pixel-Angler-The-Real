## 3. 변경

| 구분 | 위치 | 내용 |
|---|---|---|
| 재설계 | `ui/ButcheryPanel.ts` | **도마 = 항상 가로 고정** — `boardX/Y/W/H` getter 신설(상수 rect), `boardCy` 고정(295), `ROT_CY` 삭제, `ROT_SCALE` 0.50→**0.45**(560×0.45=252 ≤ 도마 외곽 높이 262 — 생선이 도마 안에 들어옴), `drawFish` 도마 배경을 고정 rect로 분리 |

## 6-b. 후속 (같은 날) — 생선 확대: 도마 밖 허용 + 패널 확장

사용자: *"도마 위로 조금 튀어나오는 건 괜찮지 않을까? 도마를 가두는 마더 창 밖으로만 나가지 않도록. (안 되면) 활용창을 조금 키우고 도마 창을 아래로 늘려서."* — 채택:

| 값 | 변경 | 근거 |
|---|---|---|
| `PANEL_H` | 620 → **656** | 화면(720) 안 32~688 — 하단 여유 +36px. 하단 요소는 전부 PANEL_H 상대라 자동 이동 |
| `ROT_SCALE` | 0.45 → **0.55** | 세로 생선 308px(141~449) — 도마 외곽(164~426)을 위·아래 ~23px 자연스럽게 넘고, 상단 작업 패널(하단 ≈130)·하단 상태줄(상단 ≈455) 안 |
| flash | board+44 → **+66**(466) | 생선 하단 449와 6px 간격 |
| F9 편집박스 / dev 목록 | +62/+58 → **+84/+80** | 상태줄 아래로 연쇄 이동 |

재검증: fish {278,141,116,308} · 유도선 세로(스팬 x37/y146) · 드래그 cov 통과 · 실사(fin_score) 도마 걸침 렌더 스크린샷 · pageerror 0.
⚠ 잔여 관찰: `flat_gut_scoop`(회전 90·scoop)에서 채움 게이지 바(boardY-40 = 150~162)가 생선 상단(141~)과 최대 ~21px 겹칠 수 있음 — 바가 위에 그려져 판독은 되나, 실플레이에서 거슬리면 위치 재조정.

## 7. 위험·부작용

- **새 함정**: 생선 위에 그리는 것은 **반드시 `toPanelPx` 경유** — 정규화 좌표를 `fishX + x·fishW`로 직접 매핑하면 회전 시 어긋난다(이번 ②의 기전). 반대로 **오버레이/버튼/목록은 board rect** — fish rect에 앵커하면 회전 시 밀린다(③의 기전).
- `jumpTo` 방향 스냅이 항상 발동 — 재장착 재개(`resumeAtSection`)도 시작 스테이지 방향으로 자동 정렬된다(의도 동작. 수동 정렬을 기대하는 코드가 생기면 충돌).
- 세로 배치 생선이 구(280px)보다 소폭 작아짐(252px) — 판정은 정규화 공간이라 난이도 불변, 시각 체감만.
