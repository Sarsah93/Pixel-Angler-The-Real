# 322(2)차 — 새 어종 9종 그림(어종 · 필렛) · 손질 열림 · 전어 가닥 정리 · 다금바리 다시 그리기

- 날짜: 2026-11-12
- 시스템: 손질 · 도감 · 에셋 파이프라인 · 위키

## 1. 배경

322차에 새 어종 9종을 등록했지만 Gemini 선불 크레딧이 떨어져(402) 그림을 못 그렸다 — 도감 칸은 「이미지 없음」, 손질은 닫혀 있었다.

사용자 지시(원문):

- 「Gemini API 크레딧 만원 충전해서 … 현재 크레딧 6천원 정도로 충전되었어. 신규 어종들 기본 이미지, 손질 과정에 필요한 필렛 이미지 생성 및 적용 작업 시작하면 될 것 같아.」
- 「전어 … 빨간색 네모 박스로 표시한 부분이 머리카락처럼 길게 뻗어있는 데, 저거는 실제로 없어. 저 부분을 정리하라고 말한 거야.」
- 「위 쪽에 있는 생선이 표준명 '다금바리'야. 근데 너가 생성한 gemini 이미지는 농어에 가까워.
  입 부분(주둥이)가 좀 더 뾰족하고, 배와 등쪽은 머리쪽보다 더 폭이 넓어서 빵이 좀 있는 느낌의 생선이야. 수정해줘.」

## 2. 원인

- 전어 가닥: 생김새 설명(`LOOKS.gizzard_shad`)에 「등지느러미 맨 뒤 줄기가 실처럼 길게 뻗는다 · 긴 실이 있어야 한다」고 적었다.
  모델이 그 줄기를 몸에서 떨어져 구불거리는 한 칸 굵기 선으로 그려, 어두운 창에서 머리카락처럼 보였다.
- 다금바리: 설명에 「농어처럼 길쭉하고 날씬한 방추형 몸(몸높이가 몸길이의 4분의 1쯤)」이라고 적었다 — 그대로 농어 같은 그림이 나왔다.
  실물(사용자 첨부 사진)은 주둥이가 창끝처럼 뾰족하고 아래턱이 나왔으며, 몸통이 머리보다 훨씬 높다.
