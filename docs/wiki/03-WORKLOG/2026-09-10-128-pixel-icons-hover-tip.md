## 1. 배경

126차에서 상태이상 표시를 이모지에서 **색 칩 + 텍스트 약어**(`식`/`FP`)로 바꿨는데,
사용자가 규칙의 본뜻을 정정했다(원문):

> 이모지 금지 규칙은 UI 디자인 시, 클로드 특유의 '[아이콘] [타이틀]' 혹은
> '[강조 특수문자] [타이틀] 혹은 [설명]' 느낌을 금지한 것임.

> 뱃지를 생성할 때, 디자인을 통일감있게 만든 것이 가장 칭찬할 부분임. 다만 …
> **요약된 혹은 함축된 의미의 텍스트 약어를 유저가 시각으로 확인하는 것은 동의할 수 없음.**
> 특수문자를 사용하지 않고, **2D 픽셀 고급 디자인(조잡한 도형들로 만들지 말 것)** 으로 보여줄 것.

> 바뀔 상태이상 뱃지 위에 마우스를 호버링 할 때, **실시간으로** 설명 팝업창 HUD가
> **공간이 여유있는 쪽으로 확장**되어 보여지는 형태로 구현해야 함.

> '허기'와 '수분'을 각각 **'빵' 모양 아이콘과 '물방울' 모양 아이콘**으로 …
> BAR 게이지에 마우스 호버링 시, **'"숫자"%(현재 상태) / 100%(최대 상태)'** 이런 식으로 표기.

즉 **금지 대상은 이모지와 텍스트 장식이지 시각적 아이콘이 아니다.**
통일된 칩 프레임은 유지하고 내용물만 그림으로 바꾸는 것이 정답이었다.

## 2. 원인 (설계 오독)

- 126차는 AGENTS §4를 "아이콘 = 짧은 라벨 + 색"으로 읽고 `StatusBadge { ko, en, color }`를 만들었다.
- 실제 제약은 **① 이모지(OS 컬러 벡터 — 도트 톤과 불화) ② Claude식 텍스트 장식** 두 가지였고,
  픽셀아트 아이콘은 오히려 권장 수단이다.
- 부수 문제: 약어는 **로케일마다 다른 문자**(`식` ↔ `FP`)라 폭이 흔들리고 사전을 타야 했다.
  아이콘은 로케일 무관이라 이 문제 자체가 사라진다.

### 아이콘 13종

허기(빵) · 수분(물방울) · 식중독(생선 가시 + 악취) · 생물중독(해파리) · 설사(변기) ·
출혈(핏방울) · 골절(두 동강 난 뼈) · 오한(눈송이) · 감기(마스크) · 독감(바이러스) ·
이상고열(체온계) · 탈진(방전된 번개) · 기절(X자 눈 얼굴).

### 팝업 동작

- **앵커 확장** — `anchorTip(c, rect)`: 좌우는 남는 폭이 큰 쪽, 상하는 남는 높이가 큰 쪽으로 펼치고
  화면 안으로 클램프. 커서를 따라다니지 않으므로 칩 위에서 마우스를 움직여도 흔들리지 않는다.
- **상태이상 앵커 = 스트립 전체 박스** — 칩 하나에 붙이면 팝업이 **형제 칩을 덮어**
  다른 상태이상으로 커서를 옮길 수 없었다(실렌더에서 발견).
- **매초 갱신** — `tipRefresh` 훅을 `updateStatus` 1초 루프가 호출한다. 남은 시간이 실시간으로 줄고,
  상태가 풀리면 팝업이 스스로 닫힌다.
- **표기 분리** — 허기·수분은 100 만점이라 `62% / 100%`, 체력·피로도·경험치는 `현재 / 최대 (비율)` 유지.

## 6. 잔여

- 날씨 배지 글리프(`☀ ⛅ ☁ ☂ ❄ ≋`)는 그대로다 — 같은 원칙이면 픽셀 아이콘으로 갈 대상이지만
  이번 지시 범위 밖이라 손대지 않았다(백로그).
- `InventoryStore` 시드·`ShopCatalog`의 레거시 `icon` 이모지도 미정리(기존 백로그 항목).
- 골절 아이콘은 16px에서 "부러진 뼈"로 읽히긴 하나 형태 여유가 적다 — 더 좋은 안이 있으면 교체 가능.

## 7. 위험·부작용

- **세이브 무관** — `StatusBadge`는 정적 정의표라 저장 데이터에 들어가지 않는다.
- `moveTip` 제거는 날씨 툴팁에 영향 없음(별도 `moveWeatherTip` 사용) — typecheck로 확인.
- 아이콘 텍스처는 게임 레벨 TextureManager에 남는다(씬 재시작 시 재사용 — 누수 아님, 13종 고정).
- ⚠ 하네스 함정(신규): **헤드리스에서 `scene.time` 타이머 이벤트가 발화하지 않는다**
  (새로 등록한 프로브 이벤트도 0회 — 씬 status 5·`time.paused` false인데도).
  HUD 1초 루프를 검증할 때는 `hud.updateStatus()`를 직접 호출할 것.
- ⚠ 하네스 함정(신규): `GameState.vitals`는 **게터가 새 객체를 만든다** —
  `GS.vitals.hunger = 62`는 버려진다. `GS.commitVitals({ ...GS.vitals, hunger: 62 })`를 쓸 것.
