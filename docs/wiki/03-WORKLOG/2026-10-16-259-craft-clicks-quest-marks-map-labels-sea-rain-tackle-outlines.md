## 2. 원인 — 확정된 기전

### 2.1 제작 창이 눌리지 않는다 — 다시 그린 자식의 scrollFactor

- 제작 보드(`ui/CraftBoard.ts`)는 고를 때 · 칩을 바꿀 때 · 제작 상태가 바뀔 때 **자기 컨테이너를 비우고 다시 그린다**(`redraw`).
  새로 만든 글 · 단추 · 히트 사각형은 scrollFactor 1로 태어난다. 창(`UtilizationPanel`)은 처음 그릴 때만 `applyFix()`로 0을 맞춘다.
- Phaser는 컨테이너 자식의 입력 판정에 **자식 자신의 scrollFactor**를 쓴다 — 카메라가 움직인 필드에서는 히트가 카메라 이동량만큼 어긋난다.
- 재현(필드 · 카메라 가로 16,240 · 세로 3,752px): 첫 클릭(목록 둘째 행)은 들어가 선택이 바뀌고 다시 그린다 → 그 뒤 셋째 · 다섯째 행 · 「미끼」 칩 클릭은
  **선택이 그대로**(`bp_rig_blackfish`) · 다시 그린 자식 scrollFactor = 1.
- 사용자가 「아무것도 안 눌린다」고 본 까닭(추정): 처음 선택된 행(감성돔 바늘 묶음 채비)을 먼저 누르면 겉보기에 바뀐 것이 없는데 다시 그리기는 일어나,
  그 뒤 모든 클릭이 어긋난다.

### 2.2 물음표가 잘려 보인다

- `tools/gen_pixel_icons.py`의 `mk_ready`(16×16)는 아래 점이 두 줄만 그려지고 닫는 줄이 칸 밖이었다(점의 아래 절반이 잘림).
  고리 획 굵기도 1 · 2 · 3칸이 섞여 고르지 않았다. 미니맵 `mm_ready`(10×10)는 줄기와 점이 붙어 점이 어두운 덩어리로 보였다.

### 2.3 수면이 비에 반응하지 않는다

- 1인칭 화면의 비는 화면 전체에 빗줄기 사각형(70 · 110개)만 내렸다(`spawnFpRain`). 수면(수평선 아래)에는 아무것도 그리지 않았다.

### 2.4 감성돔 바늘이 제작 창에서 안 보인다

- 가방 칸 바탕(#0e1d2e)과 색 거리 60 안인 물건 픽셀 비율 — 게 통발 둘 0.96 · 어류 그물 통발 0.95 · 필드백 0.95 · 감성돔 바늘 0.94 · 뜰채 0.92 ·
  장어 통발(대형 연결식) 0.89 · (원통형) 0.84. 256차에 새 그물 · 육묘 트레이만 테를 두르고 이것들은 사용자 결정으로 남겨 두었다(백로그 CD ①).
- 제작 창 재료 그림은 20px — 64px 아이콘을 ⅓ 아래로 줄이며(NEAREST) 어두운 바늘이 배경에 녹았다.

## 4. 구조상 위치

- **UI → 창 공통(`DraggablePanel`) → 입력 판정** — 계약 변화 없음. 패널 트리의 자식이 언제 생기든 다음 프레임 안에 화면 고정이 된다.
  같은 구조(자기 컨테이너를 비우고 다시 그리는 보드)가 30곳 있다 — 패널 안이면 이제 전부 안전망을 탄다.
- **스토리 → 의뢰 표시 → 그림(16px 손그림 아이콘)** — 렌더만.
- **UI → 필드 글자 규칙(R14)** — 지도 표시 이름이 적용 대상에 들어갔다(규칙 문구 갱신).
- **낚시 → 1인칭 배경 → 날씨 연출** — 렌더 + 튜닝 두 값(판정 무관).
- **에셋 → 장비 카드 · 아이콘 굽기** — 출력 그림만(원본 · 표 · 로드 경로 그대로).

## 6. 잔여

- **아주 작은 칸(20px 안팎)의 흰 테는 점선으로 보인다** — 64px 아이콘(테 2px)을 ⅓ 아래로 줄여 그리면 테 픽셀이 듬성듬성 빠진다.
  제작 재료는 24px로 키워 읽히게 했다. 더 깔끔하게 하려면 작은 칸 전용 아이콘(32px · 테 1px)을 한 벌 더 구워야 한다 — 요청 시.
- **수면 빗방울 조율**(초당 48 · 고리 16px)은 실플레이 의견 뒤(F8 슬라이더 둘). 눈 · 우박은 수면 표현 없음.
- 위키 그림(밝은 바탕)에는 테를 두르지 않는다 — 256과 같다.

## 7. 위험 · 부작용

- 안전망은 열린 패널마다 매 프레임 트리를 훑는다(읽기만 — 0이 아닐 때만 고친다). 가방(칸 수백)도 수백 번 읽기라 무시할 만하다.
  패널 안에 일부러 세상 좌표(scrollFactor 1)로 둔 자식이 있다면 0으로 바뀐다 — 지금은 없다(패널은 전부 화면 고정 UI).
- 제작 사유 줄의 해라체 안내 8개가 합니다체로 바뀌었다(같은 자리에 섞이지 않게) — 가방 「가방에 자리가 없다」 등 다른 곳 문구는 그대로다.
- 수면 빗방울은 그래픽 한 장(상한 220)이라 그리기 비용이 작다. 비가 아닌 날은 만들지 않는다.
