# 150차 — 실검증 피드백 12건: 표현형 전면 손질 + 스포일러 차단 + 표현 규칙 상시화

> 2026-09-17 · 빌드 3/3 · typecheck 0 · 실렌더 47/47 · pageerror 0

## 1. 배경

사용자 실검증(캡처 5장 + 지시 12건). 개별 버그도 있었지만 관통하는 지적은 하나였다 —

> "요구 사항 자체는 잘 반영했으나, 표현형이 너무 **AI가 함축된 의미의 텍스트만으로 direct하게
> 표시하고자 하는 느낌**이 강함. UI/UX적으로 구현이 미흡함."

그리고 일지에 대해서는 더 강하게:

> "유저가 미리 전체 퀘스트를 보게 되는 **매우 안 좋은 효과**가 나타나고 있음.
> 현재처럼 구현된 모습은 **유저들의 재미를 다 떨어트리는 행위적 구현**임."

작업 중 사용자가 타르코프 위키 PDF와 인게임 캡처 2장을 추가로 주며 표현형을 지정했고,
마지막에 **"내가 지정한 부분들은 규칙으로 정해놔"** 라고 했다.
그래서 이번 차수의 산출물은 코드 + **상시 규칙(AGENTS §4 R1~R10)** 이다.

## 6. 잔여

- **StoryNarrative 186편 영문 미번역** — 141차에 이미 "영문은 후속"으로 미룬 항목. UI 라벨은 잔존 0.
- **퀘스트 아티팩트 위키형 재구성** — 타르코프 위키 골격(인포박스·대화·요구사항·목표·보상·안내·참고·여담)
  으로 재발행. 레퍼런스 원문은 scratchpad에 보관.
- **거래 NPC** — `shopId` 계약만 세우고 데이터는 비어 있다(지금은 건물이 거래를 맡는다).
- 일지 「조행록」·「사람들」 탭 — 이번에 목록에서 뺐다. 되살릴 때 **가 본 지역/만난 사람만** 여는 규칙으로.
- 장비창 페이퍼돌이 착용 아이템을 반영하지 않는다(`refreshCharacterLook` 호출측 0 — 138차부터).

## 7. 위험·부작용

- **일지 구조가 통째로 바뀌었다.** 세이브는 건드리지 않지만(`StoryStore`만 읽는다) 구 뷰(`journal`/`ladder`/
  `people`/`arc`)를 참조하던 코드가 있으면 깨진다 — 전수 확인 결과 `JournalPanel` 내부뿐이었다.
- **i18n 키가 바뀌었다**(도움말 6문장·패널 3라벨). 한국어 원문이 키이므로 옛 EN 항목은 고아가 된다 — 제거·교체 완료.
- 차량 배율은 **밴드 상단(×1.4)** 이라 52.78 vs 52로 여유가 0.8px뿐이다. 더 키우려면 사용자 재확인 필요.
- `nudgeOffRoad`는 **문 좌표**를 민다 — 스프라이트·거래 판정·NPC·미니맵 핀이 같이 따라간다.
  199곳이 움직였으므로 육안 검수 권장.
