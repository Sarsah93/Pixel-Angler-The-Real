### B2. 회귀 위험 (과거 실제로 깨진 곳)
| 지점 | 무엇이 깨졌었나 | 재발 방지 |
|---|---|---|
| 부산물 지급 경로 | 종료 경로 3개 중 하나만 빠져도 아이템 증발 (59·61·62·63차 4연속) | 새 종료 경로 추가 시 정산/회수 필수 |
| 씬 전환 페이드 | `camerafadeoutcomplete` 미발화 → 검은 화면 (46·52·71·73차) | `SceneFade.fadeOutThen` 경유 |
| 재진입 가드 | 씬 재사용이라 필드 초기값이 재진입에 미적용(73차 먹통·이중 차감) | `create()`에서 리셋 |
| 구운 스프라이트 | PNG만 바꾸고 생성기 미실행 → 반영 안 됨(74·76차) | `asset-pipeline` 스킬 체크리스트 |
| 세이브 스키마 | 구세이브에 신규 정적 필드 없음(53차) | `deserialize` 시드 백필 |
| 매칭 테이블 순서 | 부분일치 선착순 오매칭(`한치`·`잿방어`·`말쥐치`…) | 긴 이름 먼저 |
| 마스크 팬텀 히트 | 스크롤아웃 셀이 클릭됨 | 인터랙티브 목록 = 윈도우드 렌더 |

### B3. 데이터·환경 위험
- **프로덕션엔 vite 프록시가 없다** — HTTP 전용 API(MAFRA·NMPNT)는 배포 시 Mock 폴백. 서버 프록시 필요.
- **API 키가 번들에 인라인**된다(사용자 승인 상태). 공개 배포 시 재검토 대상.
- **NMPNT 데이터 공백**: 파고 0개소 · 수온 11/76개소 · 강수/운량 필드 없음 → 날씨 판정은 기상청 API 의존.
- **MAFRA는 2023년으로 날짜 매핑** — "실시간 시세"가 아니다. 밸런스 판단 시 유의.
