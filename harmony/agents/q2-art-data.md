# ② 그림·데이터·문구 정합

## 목적

플레이어가 **보는 것**(그림 · 이름 · 설명 · 숫자)이 **실제 물건 · 실제 규칙**과 같게 한다.

## 왜 이 갈래가 있나 (사용자 예시)

- 255차: 「갯바위 단화」 · 「기모 장갑」 그림에 세 켤레가 그려져 있었다(아이템은 한 켤레).
- 256차: 같은 물건이 두 id · 두 이름으로 따로 쌓였다(뜰채 5m · 구멍찌 1.0호 · 카본 목줄 3호 · 지그헤드 3g).
- 280 · 281차: 줄 세기가 낚시 물리(호수 × 1.8kg)와 상세 창(제원 lb)에서 달랐다.

## 보는 것 (질문)

1. 그림 속 **개수 · 종류 · 상태**가 이름 · 수량 단위와 같은가? (한 켤레 · 한 갑 · 10개입 · 1kg · 반 마리)
2. 같은 물건이 **두 id · 두 그림 · 두 이름**으로 나오는가? 반대로 다른 물건이 같은 그림을 쓰는가?
3. 상세 창 · 설명문의 **숫자**가 데이터 · 판정 값과 같은가?
4. 도감 · 위키 · 도움말 · 상점 · 가방의 **이름**이 서로 같은가?
5. 영어로 바꾸면 **한글이 남거나** 원문이 바뀌어 번역이 끊긴 곳이 있는가?
6. 그림이 **없거나**(빈 아이콘 · 이모지 폴백) 표시 크기에서 **안 읽히는가**?

## 방법

- **모아 보기 그림**: 카드 · 아이콘을 이름표와 함께 격자로 모아(Pillow — `pip install --target <스크래치>/py pillow`) 직접 본다.
  표시 크기(가방 칸 64px · 상세 창 카드)로 줄인 판도 본다. 결과 그림은 상태 브랜치 `harmony/visual/<날짜>/`(실행당 2 MB 이하).
- **순수 함수 돌리기**: 하네스 안에서 `ItemDetailPanel.buildItemDetail`을 전 아이템에 돌려 행 값과 데이터 필드를 대조한다.
- **번역 스캔**: 하네스에서 `setLocale('en', game)` 뒤 창을 열고 화면 Text의 한글 잔존을 센다(스킬 verify-render 함정 참고).
- 참고 노트: `knowledge/v1/04-design-media.md`(아이템 · 맵 그림 품질 기준표 — v1 상시 과제 A · B는 이 갈래의 S2-06 · S2-07로 옮겼다).

## 이 프로젝트 전용

- 그림 경로: 원본 `food assets/{items,tackle,fish,forage,dishes}` → 생성기 `tools/*_cards.cjs` → 소비본 `public/{items,tackle,fish,…}`.
  매핑은 `data/ItemArtManifest.ts` · `data/ItemImages.ts` · `ui/ItemIcon.ts`. 구운 스냅샷과 직접 로드 구분은 스킬 `asset-pipeline` ⓪.
- 이름 · 설명: `data/ShopCatalog.ts` · `data/WikiCatalog.ts` · `data/HelpContent.ts` · `i18n/*.ts`.
- 수치 정본: core `db-schema/*` · `rules/*`(줄 세기 = `rules/LineStrength.ts` — 281차).
