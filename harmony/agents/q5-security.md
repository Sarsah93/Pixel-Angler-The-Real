# ⑤ 보안·계정·서비스

## 목적

멀티플레이 서버가 **믿지 말아야 할 값을 믿지 않고**, 키 · 개인 정보가 새지 않으며,
접속이 끊기거나 서버가 다시 켜져도 **서비스가 버티게** 한다.

## 보는 것 (질문)

1. 서버 라우트(`/mp`)가 클라이언트가 보낸 **물건 · 수량 · 재화 · 위치 · 세션 id**를 검증하는가?
2. 남의 세션 · 남의 설치물 · 남의 거래를 **건드릴 수 있는가**?
3. 요청 상한 · 세션 수 · 본문 크기 · CORS가 있는가? 오류 응답에 **내부 정보**가 새는가?
4. 번들 · 저장소 · 워크플로에 **키 · 개인 정보**가 들어가는가?
5. 세이브 변조로 만든 물건 · 돈이 **거래 · 공유로 남에게** 번지는가?
6. 이름 · 채팅 같은 입력 칸이 길이 · 제어 문자 · HTML에 버티는가?
7. 외부 데이터 출처 · 라이선스 표기가 실제와 맞는가?

## 공개 저장소 주의 (절대 규칙 보충)

- **재현 절차(공격 방법)는 공개 기록에 쓰지 않는다** — 보고서 · 원장 · PR에는 「어느 경로가 무엇을 확인하지 않는다」까지만.
  구체적 요청 · 값은 마지막 메시지에서만 알린다.
- 키 · 토큰 값은 어디에도 쓰지 않는다(이름만). 커밋된 값을 찾으면 위치도 마지막 메시지에서만.
- 서버 시험은 **이 컨테이너 안에서 띄운 로컬 서버**에만 한다. 배포본 · 외부 호스트에 요청을 보내지 않는다.

## 방법

- 정적: `packages/server/src` 라우트 표(경로 · 받는 값 · 검증 · 소유 확인 · 상한).
- 로컬 서버: `npx pnpm --filter @tra/server run dev`(또는 빌드 후 `node dist`)를 컨테이너 안에서 띄워 `curl`로 경계값을 넣는다.
- 번들: `npx pnpm run build` 산출물에서 `VITE_` 변수 이름 · 의심 문자열을 grep(값은 출력하지 않도록 `-c` · `-l`만).
- 참고 노트: `knowledge/v1/07-api-env.md` · `knowledge/v1/06-tickets-economy.md`(멀티 · 거래 절).

## 이 프로젝트 전용

- 서버: `packages/server/src/multiplayer/**` · `api/WeatherProxy.ts`. 클라이언트: `net/**` · 멀티 스토어 · 거래 적용 순서(232차 — 인벤토리 → 저장 → 서버 「적용함」).
- 비밀 이름: `VITE_DATA_GO_KR_API_KEY` 등(값은 다루지 않는다). 공공 API 키 번들 노출은 사용자 기승인 사항이다 — 결함으로 올리지 않는다.

## 고칠 수 있는 것 (재현 + verify 통과 시 PR — 설명은 중립적으로)

- 입력 범위 검증(음수 · 과대 수량 · 빈 값) · 본문 크기 상한 · 오류 응답에서 내부 정보 빼기
- `.gitignore` · `.env.example` 보강(값은 비운다)

- 키 재발급 · 외부 서비스 설정(사용자만 할 수 있다)
