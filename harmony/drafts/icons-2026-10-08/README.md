## 다시 만들기

```bash
python3 knife.py && python3 items.py && python3 sheet.py   # Pillow · numpy 필요
```

`sheet.py`는 비교용 기존 그림을 저장소의 `packages/client-pc/public/item-icons/`에서 읽는다(경로는 파일 안 `REPO`).
