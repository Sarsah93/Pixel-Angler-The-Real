## 0. 배경 (사용자 원문 요약)

- 해루질로 잡는 생물은 대개 **바닷물 안**에 있거나 **자갈 · 흙 · 진흙 깊숙이** 숨어 있다(청갯지렁이 · 참갯지렁이 · 조개).
- 조개는 **숨구멍**을 모래 위에 내고, 그 구멍으로 물과 공기를 먹고 뱉는다.
- 갯강구 · 쫄장게 일부는 걸어서 닿는 곳을 **돌아다닌다**(쫄장게도 85% 이상은 물속 바위틈).
- 맨손으로 잡는 건 손재주와 경험이 많아야 쉽다. 아니면 **집게 · 도구**를 써야 다치지 않는다. 다치는 것도 상태이상으로.
- 지금은 생물이 **정지**해 있고, 탑다운에서 다가가 [F]를 누르기만 하면 된다 — 순발력 · 도구 사용이 없다.

## 1. 지금 구조 (바꿀 지점)

| 단계 | 지금 | 문제 |
|---|---|---|
| 배치 | 지형 후보 타일 → 시간 시드로 스팟 ≤220개 | 모든 생물이 같은 「점」이다 — 묻힌 것 · 붙은 것 · 걷는 것의 구분이 없다 |

| 다침 | 맨손 부상 확률(`hand_injury`) | 결과가 숫자뿐 — 어디를 어떻게 다쳤는지 없다 |

## 2. 생물을 사는 방식으로 네 갈래로 나눈다

### A. 묻혀 사는 것 — 「단서를 읽고 판다」

- 대상: 바지락 · (신규) 맛조개 · 동죽, 청갯지렁이 · 참갯지렁이(미끼).
- 보이는 것은 생물이 아니라 **단서**다.
  - 조개: 모래 위 **숨구멍 두 개**(입수관 · 출수관). 가까이 걸으면 **물을 찍 뿜고** 구멍이 닫힌다(진동에 반응 — 실제 행동).
  - 갯지렁이: 자갈 · 펄 위 **배설 둔덕(똥 무더기)과 구멍**.
- 잡기 = **파기**: 호미(신규 도구)로 파 들어가는 깊이 게이지. 생물은 그 사이 **아래로 내려간다**.
  - 맛조개는 빨리 내려간다 → **소금을 구멍에 넣으면 스스로 튀어 올라온다**(실제 기법 — 소금 1 소모).
  - 너무 세게 파면 껍데기가 깨진다(품질 하락) — 힘 조절.
- 장소: 모래 · 펄이 있는 곳만(속초는 해수욕장 · 청초호 기수역 가장자리 · 사석 사이 자갈).

### B. 붙어 사는 것 — 「떼어 낸다」

- 대상: 홍합 · 굴 · 거북손 · 삿갓조개(배말) · 전복 · 오분자기.
- 바위에 고착 — 도망은 없지만 **떼는 기술**이 있다.
  - 삿갓조개 · 전복: 한 번에 못 떼면 **꽉 달라붙어** 다음 시도가 더 어렵다(실제 행동). 첫 시도의 타이밍이 중요.
  - 굴 · 거북손: 껍데기가 날카롭다 — 맨손이면 **베임(출혈)** 확률.
- 잡기 = 칼 · 집게를 틈에 넣고 **한 번에 비트는 타이밍** 미니게임(게이지가 초록 칸일 때 놓기).

### C. 느리게 기어 다니는 것 — 「물속에서 찾는다」

- 대상: 소라 · 보말 · 군소 · 해삼 · 성게.
- 대부분 **물 타일 안**(얕은 물 · 간조 웅덩이)에 있고 아주 느리게 움직인다(분 단위로 위치가 조금 바뀐다).
- 잡기는 쉽지만 **물에 들어가야** 한다 → §3 접근 조건. 성게는 맨손이면 **가시 박힘(출혈 경미)**.

### D. 걸어 다니고 도망치는 것 — 「몰아서 잡는다」

- 대상: 쫄장게 · 민꽃게(돌게) · 꽃게 · (신규) 갯강구 · 돌문어.
- **실시간으로 배회**한다(탑다운 스프라이트가 걷는다). 대부분은 물속 바위틈에 있고, **뭍에 나와 있는 것은 소수**(쫄장게 기준 15% 이하).
- 플레이어가 다가오면 **감지 반경**에서 바위틈 · 물로 **도망친다**. 달리면 더 멀리서 알아챈다(발소리).
  밤 + 랜턴을 아래로 비추면 잠시 굳는다(실제 해루질 기법 — 랜턴 밝기 · 각도).
- 잡기 = **반응 미니게임**: 게가 좌우로 튀는 순간 집게 · 손을 내린다. 판정 창 크기 = 도구 + 손재주.
  - 맨손 + 손재주 낮음 → **집게발 물림(출혈 경미)** · 놓침.
  - 문어는 바위틈에 숨으면 **갈고리로 끌어내기**(당기기 줄다리기 — 너무 세면 다리가 끊겨 품질 하락).

## 3. 물 · 조석 · 접근

- 접근 3단계: `shore`(뭍) · `wade`(얕은 물 — **장화 · 가슴장화** 필요, 수심 ≤ 0.6m) · `dive`(스노클 — 나중).
- 간조에 드러나는 타일이 늘어난다(이미 `tideLevel01`이 있다) — C · D의 상당수가 **물이 빠질 때만** 닿는다.
- 물에 오래 있으면 **체온 저하(오한)** — 이미 있는 상태이상 `chill`. 가슴장화가 늦춘다.
- R12 준수: 「물이 빠질 때」 · 「밤에」처럼 넓은 때만 조건으로 쓴다.

## 4. 도구 (신규 = ★)

| 도구 | 쓰는 곳 | 비고 |
|---|---|---|
| 맨손 | 전부 | 손재주가 판정 창을 키운다 · 다칠 확률 최고 |
| 집게(채집 집게) | B · C · D | 222차 작업대 도면 있음 — 다침 거의 없음 · 판정 창 보통 |
| 갈고리 | B(전복) · D(문어) | 222차 작업대 도면 있음 |
| 뜰채 | D(게) | 있음 |
| ★ 호미 | A(파기) | 작업대 도면으로 추가 |
| ★ 소금통 | A(맛조개) | 식자재마트 굵은소금 재사용 |
| 목장갑 | 맨손 보조 | 222차 맨손 도면 있음 — **장갑을 끼면 맨손 다침 확률 절반** |
| ★ 장화 · 가슴장화 | `wade` 접근 | 생활용품점 · 체온 저하 늦춤 |
| 헤드랜턴 | 밤 | 있음 — D를 잠시 굳히는 효과 추가 |

## 5. 다침 = 상태이상으로

- **출혈(bleed)** 은 원인을 남긴다: 「굴 껍데기에 베였다」 · 「성게 가시가 박혔다」 · 「게에게 물렸다」.
- **골절(fracture)**: 젖은 갯바위 미끄러짐(이미 있음) — 달리거나 짐이 무거우면 확률 상승.
- **오한(chill)**: 물속에 오래 있으면.
- 다치면 222차 제작의 **손 상태 벌점(다친 손)** 이 그대로 이어진다 — 시스템끼리 맞물린다.

## 6. 손재주 · 숙련 연결

- 222차 **손재주**(분야 숙련 합 + 제작 기술 + 레벨 몫)를 맨손 판정에 쓴다 — 새 스탯을 만들지 않는다.
- 채집에도 분야 숙련을 둔다(파기 · 떼기 · 잡기 3갈래) — 하면 할수록 판정 창이 넓어진다.
- 스킬 연결: 단단한 손(맨손 다침 ↓) · 채집 손놀림 · 문어 붙잡기는 위 미니게임의 수치로 옮긴다.

## 8. 정해 주셔야 할 것

1. **미니게임 강도**: 매번 손이 가는 미니게임(P2 · P3)으로 갈지, 숙련이 오르면 「자동으로 잡기」(홀드만)로 줄여 줄지?
   제안: 숙련 레벨이 일정 이상이면 쉬운 대상(C 갈래)은 홀드로 끝내고, A · B · D는 끝까지 손이 가게.
2. **도망친 생물**: 놓친 게 · 문어는 그 자리에서 사라지고 **다음 시간대에 다시** 나오게 할지, 근처 바위틈에 숨어 **다시 찾을 수 있게** 할지?
3. **물에 들어가기(`wade`)**: 장화 없이도 무릎 깊이까지는 들어가게 하되 오한이 빨리 오게 할지, 장화가 없으면 아예 못 들어가게 할지?
4. **신규 종**: 맛조개 · 동죽 · 갯강구 · 청갯지렁이 · 참갯지렁이 5종을 넣을지(속초 실제 서식 여부를 같이 확인 — 동해안은 갯벌이 적어 맛조개 · 동죽은 드물다).
5. **갯지렁이 = 미끼 자급**: 직접 캔 갯지렁이를 낚시 미끼로 쓰게 할지(상점 미끼 수요가 줄어든다 — 상점 재고와의 균형).
6. **에셋**: 배회하는 게 · 갯강구 · 문어는 걷는 동작이 필요하다 — 절차 도트로 먼저 갈지, 스프라이트 시트를 받을지?
