# 작업 기록 — docs/wiki 4층 체계

## 0. 언제 쓰나

**작업을 끝낼 때마다(예외 없음).** 코드 변경이 0줄인 조사·검증 작업도 기록한다("무엇을 확인했고 왜 안 고쳤는가"가 다음 사람의 시간을 아낀다).
착수 시점에도 한 번 쓴다 — 대상 시스템 페이지 §4·§5를 읽어 **중복 구현·이미 알려진 함정**을 피한다.

## 1. 문서 역할 (중복 기록 금지)

| 문서 | 무엇을 | 길이 |
|---|---|---|
| `docs/wiki/03-WORKLOG/<날짜>-<차수>-<슬러그>.md` | **본문 기록**(8절) | 제한 없음 |
| `docs/wiki/02-SYSTEMS/<시스템>.md` | 그 시스템의 **현재 상태**(과제 표·잔여·함정) | 누적하지 말고 **갱신** |
| `docs/wiki/04-BACKLOG.md` | 잔여·위험·최적화 **전역 뷰** | 갱신 |
| `.agents/AGENTS.md` §9 | 차수 원장 — **요약 3~5줄 + 워크로그 링크** | 짧게 |
| `.agents/IMPLEMENTATION_PLAN.md` | 다음 착수·직전 완료 | 짧게 |
| `.agents/AGENTS.md` §1~§8 | **불변 규칙** — 규칙이 바뀔 때만 | — |

> 같은 내용을 세 군데에 길게 쓰지 않는다. **긴 설명은 워크로그 1곳**, 나머지는 링크.

## 2. 절차

1. **워크로그 신설** — `docs/wiki/03-WORKLOG/_TEMPLATE.md`를 복사해 8절을 채운다.
   파일명 `YYYY-MM-DD-NNN-슬러그.md` (NNN = 차수 3자리).
2. **인덱스 추가** — `03-WORKLOG/README.md` §3.1 표 맨 위에 한 줄.
3. **시스템 페이지 갱신** — 해당 `02-SYSTEMS/*.md`의
   §4 세부과제 현황(상태·차수) · §5 잔여 · **§6 함정(새로 발견한 것만)**.
   해당 시스템 페이지가 없으면 **6절 구조로 신설**하고 `02-SYSTEMS/README.md`·루트 `README.md` 대시보드에 등록.
4. **백로그 갱신** — `04-BACKLOG.md` A(잔여)·B(위험)·C(최적화)·D(미해결 질문).
5. **AGENTS §9 + PLAN** — 요약 3~5줄 + 워크로그 링크. 규칙이 바뀌었으면 §4·§8도.
6. **대시보드** — 시스템 상태(🟢🔶🚧⬜)가 바뀌었으면 `docs/wiki/README.md` §2·§3.

## 3. 8절 양식 — 각 절이 답해야 하는 것

| 절 | 반드시 담을 것 |
|---|---|
| 1 배경 | 왜 했나. **사용자 리포트는 원문 인용**(회귀 판정 기준) |
| 2 원인 | 버그면 **확정된 기전 + 확정 근거**(실측값·로그·스크린샷). 틀렸던 초기 진단도 남긴다 |
| 3 변경 | **신설/수정/삭제** 구분 표 + 파일 링크. 삭제는 이유 필수 |
| 4 구조상 위치 | `시스템 → 세부과제 → 이 작업`, **계약/데이터/판정/렌더 중 어느 층**인지(파급 판단) |
| 5 검증 | 대상·방법·결과 표. 재현 절차가 있으면 그대로(다음 회귀 테스트가 된다) |
| 6 잔여 | 왜 안 했나 + **착수 조건** |
| 7 위험·부작용 | 회귀 지점·충돌 여지·성능. 없으면 "없음"이라고 쓴다 |
| 8 후속 반영 | 위 §2 체크리스트 |

## 4. 쓰는 규칙

- **가독성(빈 줄·줄 길이·블록인용 제한)은 스킬 `doc-readability`를 함께 로드해 따른다** — 특히 PLAN/AGENTS 요약을 쓸 때.
- **한국어**, 사실 위주. 추정과 확정을 섞지 않는다(추정이면 "추정"이라 쓴다).
- **수치를 남긴다** — "겹쳤다"가 아니라 "하단 180 > 프레임 176(11px 침범)". 다음 회귀를 이 숫자로 잡는다.
- **파일은 링크**(`path/file.ts:line`), 심볼은 백틱.
- 상태 배지 통일: ✅완결 🟢운영 🔶부분 🚧진행 ⬜미착수 ⚠위험.
- 시스템 페이지 §4 표는 **줄을 늘리지 말고 상태를 바꾼다**(누적 금지 — 히스토리는 워크로그가 갖는다).
- 스크린샷·긴 로그는 붙이지 말고 **결론과 수치**만. 필요하면 scratchpad 경로를 적는다.

## 5. 함정

- **워크로그를 안 쓰고 AGENTS §9에만 길게 쓰면** 예전 상태로 돌아간다(§9는 375 KB까지 커져 세션 컨텍스트를 먹는다).
- 시스템 페이지에 **차수별 나열을 복사해 넣지 말 것** — 그 페이지는 "지금 상태"를 답하는 문서다.
- 새 함정을 발견하면 워크로그 §7뿐 아니라 **시스템 페이지 §6**에도 올린다. 워크로그는 아무도 다시 안 읽는다는 전제로 쓴다.
- 반복 절차성 지식(생성기 재실행·검증 하네스 등)은 워크로그가 아니라 **해당 스킬**에 반영한다.
