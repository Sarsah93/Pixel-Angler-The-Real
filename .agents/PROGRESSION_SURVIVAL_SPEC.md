## 1. 레벨·경험치

### 1-1. 구조

- **core 신설 `types/Progression.ts`** (순수 TS — index.ts export):
  `MAX_LEVEL = 200` · `xpToNext(n) = Math.round(25 * Math.pow(n, 1.5)) + 75` ·
  `xpForActivity(kind, params)`(§1-3 표 구현) · 마일스톤 검증용 `cumulativeXp(level)`.
- **저장 구조는 현행 유지** — `GameState.player.level / experience`(레벨 내 잔여 XP 방식).
  `GameState.ts:423`의 임계 `level × 100`을 `xpToNext(level)`로 교체, `MAX_LEVEL`에서 정지.
- 스킬 포인트 = 현행 유지 — `skillPointsForLevel(level) = level × 1` → **Lv200 = 200SP = 트리 총 비용**(§2).
- 구세이브 마이그레이션: level 그대로, experience는 새 임계와 그대로 비교(초과분은 연쇄 레벨업 허용 —
  기존 로직이 이미 while 루프).

## 2. 스킬 트리 — 7카테고리 83노드 200pt

### 2-0. 공통 규칙

1. **아키텍처는 122차 그대로** — 노드 = `SKILL_DATABASE`의 `SkillDef`, 효과 소비 =
   `GameState.skillMult(key)/skillBonus(key)`만. 노드별 tuning 키를 만들지 않는다(S21 함정 #1).
2. **중간 랭크 = 수치, 최종 랭크 = 행동 해금**(해금 없는 노드는 수치 유지). 해금은 `add` 모드
   effect 키를 대상 시스템이 게이트로 소비 — 시스템 미구현이면 `wired: false` + 패널 '예정' 배지(현행).
3. **숙련도 정합**: `GameState.skills.filleting`(사용 기반 숙련)은 별도 축 유지.
   최종 배율 = 숙련도 배율 × 트리 보정(곱연산). 추후 요리 숙련도 같은 원칙.
4. 리스펙: **'스킬 초기화권'**(상점 ₩50,000) — 전체 환급만, 부분 환급 없음.
   `skillPointsForLevel` 곡선을 바꾸는 마이그레이션이 생기면 1회 무상 전체 환급(S21 함정 #3 대비).
5. 스킬 상세창 실측 통계 연동("내 성공률 62% → 3랭크 시 71%")은 **P8**(일지 자동 기록) 이후.
6. 잠금 카테고리 = 열람만(현행 농사 방식): **제작** 탭은 제작 시스템(U '제작' 탭 — P7) 구현 시 활성
   (⚖ 기본 제작이 무조건 개방이므로 퀘스트 게이트 없음), **농사** 탭은
   농지 이용권(면허 `farmland_use`) 취득으로 활성. 채집 탭의 통발 하위 노드는 통발 기본 면허 취득 시 투자 가능.

### 2-5. 제작(crafting) 시스템 개요 (P7 — ⚖ 사용자 확정 2026-09-10)

**2단 구조** — 기본은 어디서나, 고급은 설치물 앞에서:

1. **기본 제작 = `UtilizationPanel`(U)에 '제작' 탭 신설** — 핸드크래프팅 보드. **조건 없음.**
   - 도움말 라이브러리 구조처럼 **좌측 도면 목록 › 우측 상세**. 도면은 항상 열람 가능하고,
     **인벤토리에 재료를 보유하면 활성화**(부족분은 붉게 — `재료 2/3` 표기).
   - **수량 조절**(−/+/최대 — 보유 재료로 만들 수 있는 최대치 자동 산출) 후 [제작].
   - 대상 = `station: 'hand'` 도면: 바늘묶음 채비 3종(craft_knot) · 봉돌 2종(craft_sinker) ·
     **붕대·부목·상비약**(§5 — craft_medic) · 밑밥 배합(기존 chum 입력 — craft_chum).
2. **고급 제작 = 설치형 '고급 제작대' 아이템 + [F] 상호작용 → 팝업 패널**
   - `InvItem.placeKey` 설치 시스템(44차 홈타운 배치) 재사용 — 직판장/마트 판매 + 홈타운 설치.
   - 설치된 제작대에 근접 [F] → `AdvancedCraftPanel` 팝업(기본 탭과 같은 목록 구조).
   - 대상 = `station: 'workbench'` 도면: 커스텀 루어(craft_paint) · 에기 튜닝(craft_egi) ·
     통발 기본/개량(craft_trap — 개량은 최종랭크 해금) · 로드 빌딩(craft_rod) · 릴 커스텀(craft_reel).
- 재료: 채집물·손질 부산물(`ceph_*` 포함) + 상점 자재. 성공률·품질에 제작 스킬 반영.
- **`CraftingDatabase.ts` 신설**(`RecipeDatabase`와 분리 — 요리와 도면 제작을 섞지 않는다).
  도면 항목은 `station` 필드 + nameKo/nameEn·descKo/descEn 필수(§10).
- 제작 1건 = 생존 소모(§4 표) + XP(§1-3). AGENTS §6 예약표의 CraftScene(U) 항목은 본 구조로 대체.

## 3. 캐스팅 연출·정확도 (원안 유지 — 스킬 배선 명시)

### 3-1. 카메라 팔로우 (심리스 대응)

- 예상 착수점이 뷰포트 밖이면 캐스팅 순간 카메라가 채비를 lerp(0.15) 추적.
  착수 후 0.4초 홀드 → FP 씬 인계, 취소 시 0.3초 캐릭터 복귀. 카메라 클램프는 심리스 규칙(100차~) 준수.

### 3-2. 조준 홀드 가이드 (`fish_scatter` 1랭크 해금)

- 커서 지점 클릭 유지 0.4초 → 거리로 필요 파워 역산 → **차지 게이지 위 가이드 눈금**.
  역산은 기존 캐스팅 물리 공식 재사용. 사거리 밖 = "초과" 표시.

### 3-3. 착수 산포 모델 (tuning: `cast.scatter.*`)

- 실제 착수점 = 목표점 + 오차벡터. `r = d × baseScatter × (1−windComp)`,
  `baseScatter = 0.12 × 0.7^(fish_scatter 랭크)` (0랭크 12% → 3랭크 4.1%), 무작위 타원 분포.
- 바람 편향 벡터 + `fish_wind` 랭크당 40% 보정·1랭크부터 화살표 UI.
- `fish_cast`(비거리)·`fish_surf`와 곱연산. 산포 계수만 tuning, 스킬 랭크 효과는 effect.key(§0-1).

## 6. 기절·사망 (FSM + 연출)

### 6-1. 기절 (원안 유지)

1. 피로도 최대치 도달 → 즉시 기절. 옆으로 누운 눈 감은 스프라이트(신규 2프레임 — man/girl 각각).
2. 캐릭터 주변 원형 제외 화면 디밍(비네트 암전 0.5초).
3. 2초 후 팝업 "기절했습니다!" + **[일으키기]** → 기상.
4. 페널티: `exhaust` 부여 + **피로도 80%에서 회복 재개**(연속 기절 루프 방지 안전거리 20%).

### 6-2. 사망

1. HP 0 또는 치명 상태이상 → 눕기+디밍 연출 → 2초 후 "사망했습니다!" + **[집에서 부활하기]**.

### 11-b. P5·P6 실행 중 확정 (127차)

⚖ **바람 보정 스킬은 원안보다 훨씬 약하게** — `fish_wind`를 랭크당 +0.40 → **+0.10**(상한
`TUNING.castWeather.windCompCap 0.30`)으로 낮췄다. 사용자 지시 "아주 미비한 정도" 반영 —
만렙에서도 바람 손실의 **20%만** 회복한다(9m/s 맞바람 ×0.73 → ×0.78).

⚖ **`skillMult`는 선형 합산이다** — 스펙에 `0.7^rank`로 적힌 값은 그대로 못 쓴다.
`fish_scatter`는 랭크당 **−0.22 선형**으로 재표현했다(3랭크 = 0.34 ≈ 원안 0.343).

⚖ **비거리 배율은 완력이 아니라 수평 속도 전체에 곱한다** — `CastLaunchParams.speedMult` 신설.
완력은 초기 속도의 15%뿐이라 완력에만 곱하면 배율 0.73이 실제로는 −7%에 그친다(실측).

**착수 순서 확정(사용자 2026-09-10)**: 본 스펙 P1~ 을 **선행**으로 진행 → 이후 통발 D2 → 불요리 → 농장.
농사는 타입 정의·행위 지정이 별도 품이라 **농장 단계로 이연**(스킬 카테고리는 잠금 열람만 유지) —
P Farm 관련 항목(농사 노드 배선·카테고리 해제)은 농장 경영(S8 E1~) 착수 시 함께 구현한다.
P1 = 124차 착수. **P1~P6 완료(127차) — 다음 = P7 제작.**
