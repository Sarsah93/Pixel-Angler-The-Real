## 1. 원칙

1. **어디서 만드나가 곧 난이도다** — 맨손(어디서나) → 작업대(집 · 공방) → 고급 작업대(장인 공방). 위로 갈수록 시간 · 재료 · 조건이 무겁다.
2. **사는 것과 경쟁하되 이기지 않는다** — 만든 물건은 시판품의 70~90% 원가 + 시간. 덤 옵션은 작게(아래 §6).
3. **시간이 흐른다** — 만들기는 실시간으로 진행되고, 창을 닫거나 필드로 나가도 이어진다. 직접 「중지」 · 「취소」를 눌러야만 멈춘다.
4. **R11** — 창에 조작 안내 글자를 쓰지 않는다. 처음 열 때 체험 가이드(직접 하나 만들어 보기).

## 3. 창 구성 (사용자 지정안)

```
┌ 제작 ─────────────────────────────────────────────── ✕ ┐
│ [전체][채비][봉돌·찌][미끼][루어][통발][장비][구급]   ← 종류 탭   │
├───────────────┬──────────────────────────────────────┤
│ ● 감성돔 묶음 채비 │ [그림 64]  감성돔 바늘 묶음 채비        │
│ ● 벵에돔 목줄 채비 │           채비 · 맨손                  │
│ ◐ 원투 3단       │ 설명(줄바꿈)                           │
│ ○ 개량 통발      │ 조건: Lv 12 · 매듭 숙련 2 · 도면 있음   │
│   …  (스크롤)    │ 재료: [아이콘] 카본 목줄 3호  2 / 1     │
│               │       [아이콘] 감성돔 바늘   5 / 2     │
│ □ 만들 수 있는 것만 │ 수량  [−] [ 3 ] [+] [최대]              │
│               │ 성공 92% · 실패 시 재료 잃을 확률 50%    │
│               │ 걸리는 시간 개당 20초 · 모두 1분        │
│               │ 얻는 것  경험치 36 · 매듭 숙련 +12      │
│               │ [■■■■■□□□□ 2/3 · 남은 18초]           │
│               │ [ 제작하기 ]  [ 중지 ]  [ 취소 ]         │
└───────────────┴──────────────────────────────────────┘
```

- **목록 칸 상태**: 초록 = 지금 만들 수 있음 / 노랑 = 재료 부족 / 회색 = 조건 미달(레벨 · 스킬 · 작업대). R2(스포일러) 때문에 **아직 모르는 도면은 목록에 없다**.
- **수량**: −/+ · 숫자 칸 클릭 → `TextInput`(숫자만) · 「최대」 = 재료 · 가방 칸 · 피로가 허락하는 최대.
- **중지** = 지금 개는 마저 만들고 멈춘다. **취소** = 지금 개도 멈추고, 그 개의 재료는 절반만 돌려준다(이미 손댄 재료).
- **가방 칸 미리 확인**: 시작 전에 결과가 들어갈 자리를 계산해 모자라면 「가방에 n칸이 모자라다」로 막는다. 진행 중 가방이 차면 **작업대 보관함**에 쌓는다(사라지지 않는다).
- **결과 창**: 끝나면 작은 창 — 「만든 것 n · 실패 m(잃은 재료 목록) · 덤이 붙은 것(§6) · 얻은 경험치」. 창이 닫혀 있었다면 필드 로그 + 다음에 창을 열 때 한 번.

## 4. 시간 · 이어 하기

| 항목 | 제안 |
|---|---|
| 개당 시간 | 맨손 10~40초 · 작업대 30초~3분 · 고급 3~20분(로드 빌딩 20분) |
| 진행 저장 | `CraftQueueStore`(세이브) — 벽시계 기준(요리 `CookingStore`와 같은 방식). 창을 닫아도, 필드로 나가도 진행 |
| 맨손 제작 중 행동 | 걷기 · 자전거는 된다. **낚시 · 손질 · 요리 · 채집 중에는 멈췄다가 끝나면 이어진다**(손이 하나다) |
| 작업대 제작 | 그 자리에서 계속 돈다(멀리 가도). 접속을 끊으면 **작업대만** 오프라인 동안 진행(최대 8시간) |
| HUD 표시 | 상태 아이콘 줄 옆에 작은 진행 칩(그림 + 막대). 호버 = 「감성돔 채비 2/3 · 남은 18초」. 누르면 제작 창 |
| 동시 진행 | 맨손 1줄 + 작업대마다 1줄. `craft_batch`(인내심) = 줄마다 예약 +2개 |

## 5. 성공률 · 실패

- 성공률 = 기본(도면) × (1 + 스킬 보정) × 숙련 보정 × **레벨 차 보정**(요구 레벨보다 10 높을 때마다 +3%, 최대 +9%).
- 실패하면 재료마다 따로 「잃을 확률」(기본 50%, `craft_tools` −6%/랭크) — 창에 확률을 그대로 보여 준다.
- 피로가 80% 넘으면 성공률 −10%(손이 떨린다). 술 · 오한이면 −15%.

## 6. 덤 옵션 (작게)

- 만든 물건마다 품질 굴림: **보통 75% / 좋음 22% / 훌륭함 3%**(스킬 · 숙련으로 좋음 이상 최대 +10%p).
- 좋음 = 한 가지 수치 +3~5%, 훌륭함 = +6~10% 또는 두 가지 +3%. 상한을 넘지 않는다.
  - 채비: 강도(끊김 −) · 루어: 어필 · 통발: 내구 · 구급품: 지속 시간 · 거치대 · 뜰채: 내구.
- 상점 판매가는 품질과 무관(시세 교란 방지). 상세보기에 「손으로 만든 것 · 좋음」 표기.

## 8. 구현 단계 (제안)

1. **C1 core** — `CraftBlueprint`에 `timeSec` · `minLevel` · `category`(탭) · `lossChance` · `quality`(덤 표) · `learn`(도면 얻는 길) · `station: 'hand' | 'workbench' | 'advanced'`. 판정 순수 함수.
2. **C2 큐 · 세이브** — `CraftQueueStore`(벽시계 · 오프라인 진행 · 보관함) + `save-migration` 백필.
3. **C3 창 재작성** — 위 §3 배치. 종류 탭 · 윈도우드 목록 · 재료 그림 · 숫자 입력 · 진행 막대 · 중지/취소 · 결과 창 · 체험 가이드.
4. **C4 HUD 칩 · 이어 하기** — 필드 진행 칩 · 낚시 중 멈춤 · 완료 알림.
5. **C5 도면 확장** — 15 → 약 40(§2-1) · 상점 도면 · 고급 작업대(공방).
   → **223차 구현**: 도면 40종 · 상점 도면 종이 10 · 분해 깨침 3 · 분해 · 레벨 차 보정. 남음 = 퀘스트/우호도 도면 보상 · 공방 개량.
6. **C6 도움말 · 위키 · 영어**.
