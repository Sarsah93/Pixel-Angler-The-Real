### 2-1. XP 밸런싱 원칙 (138차 확정)

- **기존 퀘스트 보상은 줄이지 않는다.** 퀘를 더할 때는 **우변(총량)을 늘린다**
  — 스킬 트리 Σ 215 재정의(130차)와 같은 원리다. 이미 진행한 세이브의 보상이 소급 변동하면 안 된다.
- 신규 서브 퀘 XP는 **그 챕터 서브 평균의 0.8~1.2배** 안에서 준다(챕터 안 난이도 정합).
- **만렙 200에서도 XP는 계속 쌓인다** (`GameState.grantXp` — 레벨만 200에서 멈춘다).
  퀘 총량이 Lv200 누적(5,636,469)을 넘겨도 보상이 증발하지 않는다.
  `xpDisplay()`가 만렙이면 `max: null`을 돌려주고 UI는 누적치만 표시한다.

### 2-2. 무결성 검사 항목

`validateStoryQuests()`가 보는 것:

1. id 중복 0
2. `prereq`가 가리키는 id 실재
3. 챕터별 메인/서브 개수·XP 합계 = `contract`
4. 조행록 17장이 참조하는 아크 실재
5. 아크 id가 실재 (`STORY_ARCS`)

⚠ **id 번호는 발행 순서, 배열은 챕터 순서다.** 기존 id를 다시 매기면 세이브(`story.quests`)가
진행을 통째로 잃는다. 삽입은 **번호를 새로 따서 배열의 알맞은 자리에** 넣는다.

⚠ 메인 삽입은 **각 챕터의 마지막(해금) 퀘스트 앞**에. `mainRows`가 배열 순서로 체이닝한다.

## 5. 법 규칙 5조 — 판정과 강제

`[CORE] rules/FisheryLaw.ts` — 전부 순수 함수, 거부 Verdict는 **항상 합법 대안 ≥ 1개**.

| 규칙 id | 내용 |
|---|---|
| `LAW_SELL_ROD` | 낚싯대·릴로 잡은 것은 팔 수 없다 |
| `LAW_NONFISHER_GEAR` | 비어업인 금지 어구 |
| `LAW_ILLEGAL_CATCH` | 불법 어획물 유통 |
| `LAW_SIZE_SEASON` | 금지체장 · 금어기 |
| `LAW_VILLAGE_FISHERY` | 마을어업권 대상종 무단 채취 |

- 어획 시점에 `CatchProvenance`(방법·자가어획·지역·일차·체장·`legalFlags`)가 확정되고 **이후 불변**.
- `InvItem.catchMethod` — 낚시(rod)/통발(trap) 생성 지점에서 기록, 쿨러 → 인벤 이송 시 승계.
  없는 구세이브 어획물은 `rod`로 본다.
- 테스트 T1~T7 (`FisheryLaw.test.ts`).

### 5-1. 강제 3단계 (135차)

`TUNING.law.enforceRodSell` — **기본 2**.

| 값 | 동작 |
|---|---|
| 0 | 끔 (전부 판매 가능) |
| 1 | 항상 강제 |
| **2** | **M1-06(법을 배우는 퀘) 완료 후부터 강제** |

2를 기본으로 둔 이유: **규칙을 가르치기 전에 벌하지 않는다.**
스토리를 진행하지 않은 구세이브는 회귀 0이다.

⚠ M1-06 → M1-11 구간은 어획물 판매가 전면 막힌다(낚싯대 영구 · 통발도 비어업인은 자가소비).
그 사이 현금은 **품삯뿐**(일당 상한 73,000원) — `reported_fishery`는 M1-11 총회에서 나온다.

## 9. 회귀 고리 (137차)

**해결한 맹점**: 챕터 = 지역 1:1이라 다음 지역이 열리면 **이전 맵을 다시 갈 이유가 없었다.**
실측 — 120퀘 중 챕터 무대 밖 편이 20, 그중 2~5챕터의 속초 복귀는 **0편**.
Ch1에서 세운 인물 7명이 Lv20 이후 사라졌다.

**장치**: 새 자격·새 배를 들고 옛 항구로 돌아가는 편을 각 챕터에 심었다.

| 퀘 | 내용 |
|---|---|
| M2-11 되돌아온 상자 | 부산에서 배운 상자 규격을 속초 좌판으로 |
| M4-11 속초의 손님 | 낚시어선업 배로 강두철·탁만수를 태운다 |
| M6-09 고래마루의 마지막 손님 | Ch3의 배가 팔린다 |

- 챕터 무대 밖 편 20 → **33**.
- 학습 태그 `returnTrip` 4편(M2-11 · M4-11 · M6-09 · N20-3).
- 일지 서브 트랙은 **윈도우드 렌더 + 휠 스크롤** — Ch5가 12아크 15편으로 늘어
  필요 573px > 예산 470px이 됐다(간격 압축으로는 못 담는다).

## 10. 생활 계통 (138차)

### 10-1. 과증식 해양생물 — `[CORE] db-schema/MarineNuisanceDatabase.ts`

**어종 DB와 분리한 이유**: ① 낚시 스폰 후보가 아니고 ② 가치가 판매가가 아니라 **구제 수매가**이며
③ 시간 축이 계절이 아니라 **과증식(bloom)** 이다.

| id | 이름 | 종류 | 크기 | 무게 | 과증식 월 | 정점 | 독성 | 수거 | 수매가 |
|---|---|---|---|---|---|---|---|---|---|
| `moon_jelly` | 보름달물해파리 | 해파리 | 15~40cm | 0.2~2.5kg | 5~10 | 7·8 | 1 | 훌치기 | 300원/kg |
| `nomura_jelly` | 노무라입깃해파리 | 해파리 | 60~200cm | 15~150kg | 7~10 | 8·9 | 3 | 훌치기 | 1,200원/kg |
| `blue_bat_star` | 별불가사리 | 불가사리 | 6~14cm | — | 연중 | — | 0 | 채집 | **0 (구제 대상 아님)** |
| `amur_star` | 아무르불가사리 | 불가사리 | 20~40cm | — | 3~6 | 4·5 | 0 | 채집 | 700원/kg |

- **노무라는 희소하다** (`abundance 0.18`) — 값이 아니라 **출현 빈도와 난이도**로 희소하게 했다.
- **별불가사리는 구제 대상이 아니다.** 사체·부착생물을 먹는 청소부라 무차별 구제가 오히려 해롭다.
  게임의 교육 포인트 — **무엇을 줄이고 무엇을 두는지 눈으로 가려야 한다**(`markKo` 구별 포인트).
- 상세보기는 어종 스펙과 같은 밀도로 표기: 학명 · 크기 · 무게 · 과증식 시기 · 독성 · 서식 · 피해 · 구별 포인트.

**필드 규칙** (`[CLIENT] ui/NuisanceField.ts`):

- 해파리는 **해안선에서 최소 6타일**(노무라 8) 바깥 수면에만 뜨고, **5분에 한 칸**(노무라 7분) 표류한다.
- 렌더는 타일 위에 얹지 않는다 — **수면 아래 픽셀을 바다색으로 눌러** 빙산의 일각처럼 걸친다
  (`[CORE] art/NuisanceArt.ts` `submerge()` — 텍스처 자체가 그렇게 구워진다. 런타임 합성 없음).
- 불가사리는 바닥 서식 + **해안으로 밀려온 개체는 [F] 채집**.

**훌치기(snag)** — 기존 낚시와 다른 계통:

- **씬 전환이 없다.** 착수 지점에 걸고, 좌클릭 유지로 릴링해 플레이어 **바로 앞 한 칸**에서 종료.
- 속도는 무게에 반비례(`3.2 / (1 + kg·0.18)`) — 노무라 100kg은 눈에 띄게 느리다.
- 슬랙 0.4초 → 되밀림, 26타일 초과 → 원줄 파단.
- 회수물은 **인벤토리 '식품' 카테고리**(`subCategory: '해파리' | '불가사리'`).

### 10-2. 신규 아크 4종

| 아크 | 주제 | 목표 종류 |
|---|---|---|
| N20 유하랑 | 낚시 버튜버 — 응원·합방·콘텐츠 제작 | `talk` · `catch` · `returnTrip` · `streaming` |
| N21 오세찬 | 과증식 대응 — 해파리·불가사리 구제 | **`cull`** · `bloom` · `aquaculture` |
| N22 하늬 | 손으로 짓는 것 — 제작·리빙 | `craft` · **`furnish`** · `living` |
| N23 채수림 | 세는 사람 — 어종 관리·개체 수 조절 | `cull` · `release` · `catch` · **`farm`** · **`mine`** |

**설계 판단(사용자 확인)**: 제작·농사·광질·리빙은 **시스템보다 퀘스트를 먼저 깐다.**
구조(목표 종류 + 학습 태그 + 아크)를 지금 박아 두고 목표는 `manual`로 둔다 —
시스템이 도착하면 **플래그만 빼면** 그대로 살아난다. 퀘스트 수가 느는 것은 감수한다.

## 14. 잔여 · 결정 대기

### 14-1. 구조 부채

- **manual 목표 과다** — 챕터당 2편 규칙 대비 크게 초과(§4-2 표).
  배 출조·좌판·총회가 들어오면 한 번에 내려간다. 그 전까지는 신규 퀘에서 manual을 늘리지 않는다.
- **`onMiss` 벌칙 미배선** — 기한 초과 시 `'cost'`/`'delaySeason'`이 실제로 무엇을 하는지 미정(사용자 결정).
- **평판 소비처 미배선** — 값은 움직이는데 아무 데도 쓰이지 않는다.

### 14-2. 데이터

- 추가 권장 어종 7종이 등록되면 조행록 대체분(1·4·7·10번)을 원안으로 되돌린다.
- 하위 권역 id(거제·태안·제주)는 OSM 확장 시 실체화.

### 14-3. 사용자 결정 대기

- 캐릭터 아트 비율·얼굴 표현(머리 크기 · 눈 · 입) — **139차 보류**, 사용자 검토 중.
