## 지시 요지
- 곁가지(서브)는 개시를 선택적으로 안 할 수도 있다 → 거절 = 실패(거절) 가능
- 우호도 · 보상은 알아서 재배치(+0.25 · 담배 한 갑은 사용자가 지정)
- 대화하듯 주고받기 — 혼자 다 대답하고 정보 한 번에 쏟기 금지. 이 흐름을 모든 스토리 · 퀘스트에 적용
- 대화 내용을 요약해 일지(J)에 적는다
- 퀘스트 목표 첫 단계 = 「딸에게 말 걸기」(새 인물 — 해녀 어머니 · 딸 필요)
