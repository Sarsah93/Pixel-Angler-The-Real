## 0. 한 눈에

- **주인공** 한여름(22, 이름·성별 변경 가능). 부모를 잃고 2년을 흘려보낸 뒤, 아버지의 낡은 릴대 하나와
  네 살 때 영금정에서 찍은 가족사진을 들고 속초에 온다.
- **적은 사람이 아니라 제도와 계절이다.** 낚시로 잡은 물고기는 법으로 팔 수 없다. 팔려면 어업인이 되어야 하고,
  어업인이 되려면 시간·거주·공동체 승인이 필요하다. 그 절차가 그대로 챕터가 된다.
- **스파인**: 실습생(D-180) → 어촌계원 → 선장 → 가이드 → 기록자.
  챕터마다 **기한 걸린 자격** 하나가 있고, 그것이 다음 지역을 연다. 실패 엔딩은 없다(비용·한 시즌 지연만).
- **장기 엔진**: 고진태 선장이 남긴 「동명 조행록」 빈 17장 = 17개 지역. 한 장 = **제철 지표 어종 자가어획 + 그 지역 서브 아크 완주**.
- **정서선**: 혼자 → 신세 짐 → 쓸모 → 소속 → 물려받음 → 물려줌. 마지막 장면은 첫 장면의 반복.

## 2. 플레이 흐름 — 5부 7챕터

### 제1부 「실습생」 · Ch1 속초 (Lv1~20 · 메인 11 · 서브 5)

**"아무 자격도 없이 도착한 항구에서, 무엇부터 배워야 하나."** 튜토리얼 전담 — 퀘 1개 = 시스템 1~2개.

1. **막차** — 영금정에 선다. 이동·인벤·상태 패널·월드맵. ✅
2. **얼음 나르기** — 정옥선: "울 거면 얼음부터 나르고 울어." 첫 품삯 30,000원 · 상점 UI. ✅(품삯 = 대화로 완료)
3. **열쇠 두 개** — 옛 어촌계 숙소 = 홈타운. 침대에서 자야 저장된다. **실습생 증 = D-180 시작.** ✅
4. **사이소 영수증** — 도현수: "그 대는 아까우니까 여기다 쓰지 마." 저가 장비 + 테트라포드 구멍치기. 🔶(구멍치기·사이소 ⬜ → 방파제 어획 1마리로 대체)
5. **첫 캐스팅** — 아버지 릴대를 편다. 캐스팅→입질→챔질→파이팅→랜딩. ✅
6. **팔 수 없는 물고기** — "네가 잡은 건 네가 먹어라. 계원이 돼도 낚싯대로 잡은 건 못 판다." 준법 방생 1회 + 대화. ✅
7. **부엌의 순서** — 손질 1 + 회뜨기 1. 2년 만에 제대로 된 밥. ✅
8. **간이 백팩** — 탁만수: "짐부터 어떻게 좀 해라." 제작 1회. 🔶(가방 착용 ⬜)
9. **밤바다** — 물때표를 스스로 읽는다. 해루질 2개체. ✅
10. **공동작업** — "실습생"으로 불린다. 공동작업(대화) + 자전거 탑승. 🔶
11. **총회** — Lv18 + 총회 대화 → **신고어업 + 어촌계원** 자동 취득 → 위판·부산 개방. ✅(위판 UI ⬜)

서브: N04-1 입부 권유 · N03-1 선생님 · N01-1 리어카 · N02-1 부러진 대 · **N04-2 부원을 낚아라 → 조행록 1장(도루묵·겨울)**.

### 제2부 「위판」 · Ch2 부산 (Lv20~45 · 메인 10 · 서브 8)

**"잡는 것과 파는 것은 완전히 다른 일이다."** 기한 = 분기 총회.

첫 위판(통발 어획물) → 유찰(얼음을 아낀 대가) → **감성돔 40cm+ = 2장** → 횟집 납품 → 품질관리 교육(루어 개방) →
**전갱이 야간 루어 = 3장** → 통제선(몰래 넘는 선택지 없음 — 합법 우회 3종) → **볼락 3마리 = 4장** → 총회(도현수 반대표, 그래도 통과) →
면허 학원(울산·포항 개방). 🔶 위판·납품·교육·통제선은 대화로 완료 / 어획 목표 ✅.

서브: N06 씨바스터즈(태클 베스트) · N05 하린·기범 · N07 짐 강 유작 루어 · N01-2 · N03-2 조합장님.

### 제3부 「겨울 배」 · Ch3 울산·포항 (Lv45~70 · 메인 9 · 서브 8)

**"사라진 것들 앞에서 무엇을 할 수 있나."** 기한 = 조종면허 실기 회차.

방어진 입항(배 출조 첫 체험 ⬜) → **방어 40cm+ 지깅 = 5장** → 실기 시험(한 번 떨어져도 된다 → `boat_operator`) → 덕장(청어가 안 든다 ⬜ 불요리) →
해무(돌아오는 것도 실력) → **명태를 본 적 있어요?**(구술 채록 ⬜) → 종묘방류(바다 평판 +3) → **겨울 참돔 = 6장 · 유품 릴대가 부러진다** → 배를 보러 가자(거제·여수·태안 개방).

서브: N08 고래마루 부녀 · N09 수연·봄(거울 아크 — 부모 이야기를 꺼낸다) · N10 남궁현 · N07-2 · N01-3.

### 제3부 「내 배」 · Ch4 거제·여수·태안 (Lv70~100 · 메인 10 · 서브 10)

**"손님을 태운다는 건 목숨을 맡는다는 뜻이다."** 기한 = 성어기 전 선박 등록·낚시어선업 신고.

조선소(돈이 모자라 절반만) → 첫 배(이름 직접 ⬜) → **광어 = 7장** → 안전 검사 → **갈치 야간 = 9장** → 첫 손님(`angling_boat_biz`) →

서브: N11 동백마루(거절하는 법 · 드라이백) · N12 가윤·우미(**조과 0이어도 완료되는 유일한 퀘**) · N13 송노인·마작가 · N02-2 왕대 · N01-4 절벽(**8장**) · N07-3.

### 제4부 「손님」 · Ch5 제주 (Lv100~130 · 메인 9 · 서브 10)

**"항구를 지키는 방법이 하나가 아니라면 나는 어느 쪽에 서나."** 기한 = 대회 전 해양관광업 등록.

운진항 → 불턱(마을어업권 실전) → **한치 3마리 = 12장** → 해양관광업 등록(`marine_tourism`) → 낚시공원 설명회(찬반 취재) →
대회 예선 → **무늬오징어 에깅 = 14장** → **결선 방어 80cm+ = 13장 · 정옥선이 쓰러졌다는 전화** → **총회 표결**(도현수가 처음 같은 편 · 울릉·인천 개방).

### 제5부 「먼 항로」 · Ch6 울릉·인천 (Lv130~160 · 메인 8 · 서브 8)

막배(결항의 밤) → **부시리 = 16장** → 등대(석대양 노인이 고진태 선장을 기억한다) → **연안부두 우럭 30cm+ = 15장** →

서브: N16 석독구(낡은 사이소 릴을 물려준다) · N15 오세라(혼자와 외로움) · N17 단철호·하민지 · N01-6(마운틴 백팩) · N05-4 · N16-2.

### 제5부 「조행록」 · Ch7 독도 (Lv160~200 · 메인 8 · 서브 6)

## 5. 규칙 세 가지

**법 (5조)** — 낚싯대로 잡은 것은 **누구도** 팔 수 없다. 어업인이 되어도 마찬가지. 어업인 자격이 여는 것은 통발·투망·맨손 어획물의 위판.
금지체장·금어기는 랜딩 시 판정 → 방생만. 마을어업권 구역 안 전복·해삼은 어촌계 허락 필요.
✅ core 판정 5함수 + 판매 UI 배선 / ⚠ **강제는 `TUNING.law.enforceRodSell` 플래그(현재 OFF)** — 켜는 시점은 사용자 결정(§0.5-6).

**평판 2종** — 항구 신뢰(지역별 0~100: 공동작업·무상 납품 ↑) · 바다 평판(−10~+10: 준법 방생 ↑ / 위반 ↓).
둘 다 진행을 잠그지 않는다. ✅ 상태·퀘 보상 변동 / ⬜ 소비처(수수료·표결·시험 가산).

**기한** — 실패 없음. 비용과 한 시즌 지연만.
