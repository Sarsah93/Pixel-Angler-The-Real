## 0. 한 장 요약

- **주인공**: 22세. 고졸 직후 부모를 사고로 잃고 2년을 흘려보냈다. 남은 것은 산골 빈집, 아버지의 낡은 릴대, 잔고 ₩312,000, 그리고 네 살 때 영금정에서 찍은 가족사진 한 장.
- **적대자는 사람이 아니라 제도와 계절이다.** 낚시로 잡은 물고기는 법으로 팔 수 없다(§3). 팔려면 어업인이 되어야 하고, 어업인이 되려면 시간·거주·공동체 승인이 필요하다. 이 절차가 그대로 챕터가 된다.
- **스파인**: 실습생(D-180) → 어촌계원 → 선장 → 가이드 → 기록자. 챕터마다 기한 걸린 자격이 하나씩 있고, 그것이 다음 지역을 연다.
- **장기 엔진**: 「동명 조행록」 빈 17장 = 17개 지역. 한 장을 채우려면 **제철 지표 어종 자가어획 + 그 지역 서브 아크 완주**가 둘 다 필요하다.
- **정서선**: 혼자 → 신세 짐 → 쓸모 → 소속 → 물려받음 → 물려줌. 마지막 장면은 1-2의 반복이다.
- **29편 공통 주제**: "한 마리가 사람 사이를 잇는다." 주인공의 결핍과 NPC 17아크의 결핍이 같은 방식으로 풀린다.
- **실패 엔딩 없음.** 기한을 놓쳐도 비용과 한 시즌 지연만 발생한다(스타듀식 관대함).

## 1. 설계 원칙

1. **음모 없음, 악당 없음.** 대립은 제도·계절·자원 감소·세대 교체·상권 변화로만.
2. **준법이 게임 규칙 그 자체.** 위법은 숨은 지름길로 보상되지 않는다. 막힌 길에는 항상 합법 대안을 병기한다.
3. **튜토리얼은 전부 스토리 안에서.** 조작·재화·지급품·제작·생존·인벤토리를 Ch1 11퀘가 NPC 대화로 전담(§9).
4. **가난에서 시작한다.** 시작 인벤은 탭당 2×5칸이고, 장비는 생활용품점 저가품이다(§8·§11-3). 성장 체감의 절반이 여기서 나온다.
5. **원작 비복제.** 29편에서 가져온 것은 관계 원형뿐. 인물명·고유 설정·명대사·장면은 옮기지 않는다.
6. **실명 회피.** 기관·기업·학교·점포·상표는 전부 가상. 지명과 법령만 실재를 따른다.
7. **연령등급 보호.** 술·도박·유혈 연출 배제. 대회는 참가비·순위 상금만.

## 2. 세계관 (2026년, 속초)

### 2-1. 톤
동명항의 새벽은 늘 같다. 얼음 깨는 소리, 경매 종, 좌판 천막. 그 위에 변화가 스민다 — 오징어와 명태가 사라진 바다, 평균 연령 60대의 어촌계, 관광객은 늘고 어선은 주는 항구, 안전 문제로 잠기는 방파제. 주인공은 그 한복판에 아무 자격도 없이 도착한다.

### 2-2. 지도와 계절
- 시작 지역은 `sokcho_v2` 하나. 나머지 16개 지역은 자격·기한·계절로 열린다(§6).
- 인게임 1년 = 4계절. Ch1의 D-180이 첫 계절 사이클(가을→겨울→봄)을 강제로 체험시킨다.
- 계절은 어종·물때·체감온도·공동작업 종류를 바꾸며 퀘스트 조건에 직접 들어간다.

### 2-3. 상권 변화 (악역 아님)
**속초해양레저협동조합**이 방파제 일부를 유료 낚시공원으로 전환하자고 제안한다. 안전관리·수익·관광에는 유리하지만 공동작업장과 좌판 구역이 줄어든다. 찬반 모두 타당하게 쓰고, **Ch5 총회 표결**에서 플레이어의 누적 평판·공동작업 참여율이 반영된다. 어느 쪽이 이겨도 게임은 계속되며 항구 풍경·상점 구성·낚시 요금만 달라진다.

## 3. `[CORE]` 법 규칙 — 코어 승격 구현 계약

> **이 절은 서사가 아니라 구현 스펙이다.** Claude Code 작업 시 이 절을 단독 참조 가능하도록 자족적으로 작성했다.
> 배치: `packages/core/src/rules/fishery-law.ts` (신규) + `index.ts` export. **Phaser·DOM 금지**(레포 규칙).

### 3-1. 규칙 5조 (실제 법령 근거)

| ID | 규칙 | 근거 | 판정 대상 |
|---|---|---|---|
| `LAW_SELL_ROD` | 낚시로 포획한 수산동물은 **누구도** 판매·판매목적 저장·운반·진열 불가 | 낚시 관리 및 육성법 §7조의2 | 판매/위판/납품(유상) |
| `LAW_NONFISHER_GEAR` | 비어업인은 정해진 어구·방법으로만 포획·채취 (투망 / 반두·쪽대 / 외줄낚시 / 가리·외통발 / 집게·갈고리·호미 / 손) | 수산자원관리법 §18 | 어구 사용 시점 |
| `LAW_ILLEGAL_CATCH` | 불법 포획물의 소지·유통·가공·보관·판매 금지 | 수산자원관리법 §17 | 인벤 보관·조리·이동 |
| `LAW_SIZE_SEASON` | 금지체장 미만·금어기 개체 포획 금지 | 수산자원관리법 고시 | 랜딩 직후 |
| `LAW_VILLAGE_FISHERY` | 마을어업권 구역의 정착성 수산동식물(전복·해삼 등) 무단 채취 금지 | 수산업법 / 마을어업권 | 해루질·잠수 채집 |

### 3-2. `[CORE]` 타입 계약

```ts
/** 어획 경로 — 판매 가능 여부의 1차 결정자 */
export type CatchMethod =
  | 'rod'        // 낚싯대·릴 (LAW_SELL_ROD 대상)
  | 'handline'   // 외줄낚시·손줄
  | 'trap'       // 가리·외통발
  | 'net'        // 투망·반두·쪽대
  | 'gather'     // 집게·갈고리·호미·손 (해루질 포함)
  | 'commercial' // 어업인 자격으로 행한 조업
  | 'bought'     // 상점·경매 구매
  | 'gift';      // 무상 수령

export type LicenseId =
  | 'reported_fishery'   // 신고어업(맨손어업)
  | 'coop_member'        // 어촌계원
  | 'boat_operator'      // 소형선박조종사
  | 'angling_boat_biz'   // 낚시어선업 신고
  | 'marine_tourism';    // 해양관광업 등록

export interface CatchProvenance {
  method: CatchMethod;
  caughtByPlayer: boolean;
  regionId: string;
  gameDayCaught: number;
  lengthCm?: number;
  /** 랜딩 시점에 확정. 이후 불변 */
  legalFlags: LegalFlag[];
}

export type LegalFlag =
  | 'undersize'          // LAW_SIZE_SEASON
  | 'closed_season'      // LAW_SIZE_SEASON
  | 'restricted_gear'    // LAW_NONFISHER_GEAR
  | 'village_fishery';   // LAW_VILLAGE_FISHERY

export interface LawVerdict {
  allowed: boolean;
  ruleId?: string;       // 'LAW_SELL_ROD' 등
  reasonKo: string;      // UI 툴팁에 그대로 노출
  alternatives: string[];// 합법 대안 (원칙 6-7: 항상 1개 이상)
}
```

### 3-3. `[CORE]` 판정 함수 (전부 순수 함수)

```ts
canSell(item, provenance, licenses): LawVerdict
canKeep(item, provenance): LawVerdict          // 소지·보관·조리 (LAW_ILLEGAL_CATCH)
canUseGear(gearId, licenses, regionId): LawVerdict
canGather(targetId, regionId, licenses): LawVerdict
requiredLicenseFor(action): LicenseId | null
```

**`canSell` 결정 순서** (첫 매치에서 반환):
1. `legalFlags`에 하나라도 있으면 → `LAW_ILLEGAL_CATCH`, 불가. 대안: 즉시 방생(이미 랜딩 시 유도).
2. `method === 'rod' || 'handline'` → `LAW_SELL_ROD`, **면허 보유와 무관하게 불가**. 대안: 자가소비 / 요리 / 도감 등록 / 무상 납품 / 방생.
3. `method === 'bought'` → 되팔기 허용(시세 차익).
4. `method === 'commercial'` → `licenses`에 `reported_fishery` 없으면 불가. 있으면 위판 허용.
5. `method === 'trap' | 'net' | 'gather'` → 비어업인이면 **자가소비만**(판매 불가). `reported_fishery` 보유 시 판매 허용.

> **핵심**: 어업인이 되어도 **낚싯대로 잡은 것은 여전히 못 판다.** 이것이 게임 전체의 가장 중요한 오해 방지 포인트이며,
> 1-6 퀘스트에서 정옥선이 명시적으로 설명한다. 어업인 자격이 여는 것은 **통발·투망·맨손어업 어획물의 위판**이다.

### 3-4. 강제 지점 (Enforcement Points)

| 시점 | 호출 | 실패 시 동작 |
|---|---|---|
| 랜딩 직후 `[CORE]` | 체장·금어기 판정 → `legalFlags` 확정 | `undersize`/`closed_season`이면 **보관 버튼 비활성**, 방생만 가능. 준법 방생 XP 지급 |
| 인벤 이동·조리 `[CORE]` | `canKeep` | 차단 + 사유 툴팁 |
| 판매/위판/유상납품 UI `[CLIENT]` | `canSell` | **버튼 회색 + 사유 툴팁 + 대안 목록**. 숨기지 말 것(교육 목적) |
| 어구 장착 `[CORE]` | `canUseGear` | 미허용 어구는 상점에서 "어업인 전용" 배지, 구매는 되지만 사용 차단 |
| 해루질 채집 `[CORE]` | `canGather` | 마을어업권 구역 대상종은 채집 불가 + 경고 팝업 1회 |
| 퀘스트 납품 `[CORE]` | `quest.selfCaughtRequired` | 구매품·선물품으로 대체 불가 |

### 3-5. 수용 기준 (테스트 케이스)

```
T1 낚싯대로 잡은 감성돔 45cm + 신고어업 보유 → canSell.allowed === false, ruleId === 'LAW_SELL_ROD'
T2 통발로 잡은 문어 + 신고어업 보유    → canSell.allowed === true
T3 통발로 잡은 문어 + 면허 없음        → false, 대안에 '자가소비' 포함
T4 금지체장 미만 개체                  → canKeep.allowed === false (보관 자체 불가)
T5 상점 구매 생선                      → canSell.allowed === true (되팔기)
T6 마을어업권 구역 전복 채집           → canGather.allowed === false, ruleId === 'LAW_VILLAGE_FISHERY'
T7 모든 거부 Verdict                   → alternatives.length >= 1 (원칙 위반 방지 회귀 테스트)
```

### 3-6. 인게임 노출
- 일지 도움말 ⑬ 「팔 수 있는 물고기와 팔 수 없는 물고기」에 규칙 5조를 평문으로.
- 판매 UI 회색 처리 시 툴팁: `reasonKo` + 대안 2개까지.
- `[VERIFY]` 금지체장·금어기 수치는 고시 개정이 잦다. `[DATA]` `fishery-limits.json`으로 분리해 코드와 분리하고, 배포 전 현행 고시 대조.

## 4. 어촌계 설정 — 고증 수정본

### 4-1. 무엇을 바꿨나
v2의 "6개월 실습 → **어촌계 준회원**"은 두 가지 문제가 있었다.
1. **전국 공통의 '6개월 거주' 요건은 없다.** 어촌계 가입 요건은 각 어촌계 정관·규약에 따라 다르며, 실제 조사에서는 1년·2년·3년·5년, 심지어 훨씬 긴 사례까지 폭이 넓다. 기본 골격은 *지구별수협 조합원 자격 → 해당 어촌계 구역 거주 → 가입 신청 → 총회 심사·승낙*이다.
2. **'준회원'은 법령 용어 '준어촌계원'과 혼동된다.** 준어촌계원은 "아직 정회원이 아닌 실습생"이 아니라, 계원 자격은 없지만 마을어업권 어장에 입어하는 어업인 등이 총회 의결로 되는 별개 지위다.

### 4-2. v3 확정 설정

```
외지인(자격 없음)
   ↓ 정옥선 추천
실습생            ← 동명항 어촌계가 자체 규약으로 두는 6개월 실습기간 (게임 내 가상 설정)
   ↓ 6개월간: 공동작업 참여 · 지역 거주 · 신고어업 등록 · 서류 준비
예비계원          ← 게임 내 가상 명칭. 총회 상정 자격을 갖춘 상태
   ↓ 어촌계 총회 심사·승낙
어촌계원
```

- **'준회원' 용어 전면 폐기** → `실습생 / 예비계원 / 어촌계원` 3단계. `[DATA]` 기존 문자열 키 `coop_associate` → `coop_candidate`로 교체.
- **6개월의 출처를 바꿨다**: "제도가 그렇다"가 아니라 **"동명항 어촌계가 그렇게 정해 놨다."** 정옥선 대사로 직접 못박는다.
  > "여긴 처음 온 사람이 바로 계원 되는 곳이 아니야. 우리 계는 육 개월이야. 딴 데는 삼 년도 받아. 일부터 배워."
- 이 한 줄이 ① 게임 D-180을 살리고 ② 어촌계마다 다르다는 실제를 알려주고 ③ 6개월을 대표 기준으로 오인하지 않게 만든다.

### 4-3. 면책 문구 `[CLIENT]`
일지 → 자격 탭 하단, 그리고 1-3 실습생 증 수령 시 1회 팝업 하단에 작게:

> ※ 본 게임의 '6개월 실습기간'은 게임 진행을 위한 설정입니다. 실제 어촌계의 가입 자격·거주기간·가입 절차 등은 각 어촌계의 정관 및 관련 법령에 따라 다를 수 있습니다.

### 4-4. 로딩 팁 `[CLIENT]` — '바다 이야기' 시리즈에 추가
> 어촌계마다 가입 조건은 조금씩 다릅니다. 어떤 곳은 거주기간을 두고, 어떤 곳은 가입금이나 별도 조건을 요구하기도 합니다.
> 이 게임에서는 주인공의 이야기를 위해 6개월의 실습기간을 두었습니다.

### 4-5. 퀘스트 영향
문구 교체 외 흐름 변경 없음. 1-3(실습생 증) · 1-10(공동작업) · 1-11(총회) 구조 그대로.
2-9 「총회」의 정회원 승급도 `예비계원 → 어촌계원` 표기만 조정하면 된다.

## 5. 인물 — 메인 3인

### 5-1. 주인공 (기본명 **한여름**, 이름·성별 변경 가능)
- 22세. 부모는 2년 전 빙판길 사고로 함께 세상을 떠났다. 친척 왕래 없음. 장례 후 산골집에서 아무것도 하지 않았다.
- **시작 지급품 (고정)** — 전부 §9 튜토리얼에서 쓰임:

| 아이템 | 수 | 최초 사용처 |
|---|---|---|
| 아버지 유품 릴대 (내구 40%) | 1 | 1-5 첫 캐스팅 → 3-8에서 부러짐 → N02-4에서 부활 |
| 기본 찌채비 | 3 | 1-5 |
| 청갯지렁이 (반 통) | 1 | 1-4 구멍치기 / 1-5 |
| 주먹밥 | 2 | 1-1 허기 |
| 생수 | 1 | 1-1 수분 |
| 반창고 | 1 | 1-9 응급처치 |
| 낡은 자전거 (펑크) | 1 | 1-10에서 수리 후 탑승 |
| 가족사진 | 1 | 1-1 영금정 / 7-4 회상 |
| 현금 | ₩312,000 | §11-3 예산 설계의 기준값 |

- 대사 선택지는 항상 **무뚝뚝 / 솔직 / 너스레** 3톤. 결과는 동일하고 호감도만 미세 차이.

### 5-2. 정옥선 (71) — 동명동 직판장 좌판 '만복상회'
- 40년째 같은 자리. 남편 **고진태**는 10년 전 세상을 떠난 선장이었고 「동명 조행록」 세 권을 남겼다. 마지막 권은 절반이 비어 있다.
- 동정하지 않고 일을 준다. "울 거면 얼음부터 나르고 울어."
- 줄 수 있는 것: 좌판 품삯 / 실습생 추천서 / 빈 어촌계 숙소 6개월 무상 사용(= 홈타운) / 조행록.
- **줄 수 없는 것: 판매권.** 이 선이 Ch1 전체의 동력이다.
- **결말 확정**: 5-8에서 쓰러지고 6-5에서 조행록을 넘긴다. **사망하지 않는다.** 요양 후 7-6 재개관식에 휠체어로 참석해 테이프를 자른다. 이후 좌판에 가끔 앉는 NPC로 상시 존재하며 반복 의뢰를 준다.

### 5-3. 도현수 (24) — 어촌계장 손자, 라이벌
- 수산대 휴학. 실력은 항구에서 손꼽히는데 배를 물려받기를 거부한다. 주인공을 "굴러들어온 애"로 본다.
- **있는데 버리려는 자 vs 없는데 가지려는 자.** 적대가 아니라 거울.
- 주기적 조과 대결(주간 의뢰 프레임), 2-9 총회에서 반대표, 4-10에서 처음 배를 타러 오고, 5-9 총회에서 처음 같은 편에 선다.

## 7. 「동명 조행록」 17장 — 어종 데이터 대조본

### 7-1. 규칙
- 고진태 선장의 세 번째 권. **빈 17장 = 17개 지역 1:1.**
- 한 장을 채우는 조건은 **둘을 동시에**:
  1. 그 지역의 **지표 어종을 제철에 자가어획** (`caughtByPlayer: true`, 계측 후 방생 가능)
  2. 그 지역 **서브 아크 1개 완주**
- 어획만으로도, 대화만으로도 안 된다. "한 마리가 사람 사이를 잇는다"가 시스템이 된다.
- 채운 장은 홈타운 벽 액자에 걸리고, 해당 지역 물때·어종 정보 열람이 영구 개방된다.

### 7-2. v2 대비 변경 사유
v2의 지표 어종 중 **청어·망둥어·살오징어**는 현 `FISH_DATABASE` 계열 문서(`jigging-fish-species.md`, `fishing-spots-busan-sokcho.md`)에서 확인되지 않는다.
DB에 없는 어종을 조행록 필수 조건으로 걸면 진행 불가 버그가 된다. 그래서 **전 항목을 문서로 확인 가능한 어종으로 교체**하고, 확인 안 되는 어종은 대체안·추가 권장으로 내렸다.
또 v2에서는 방어가 2개 지역에 중복됐다 — v3에서는 **tier로 분리**해 중복을 의도적 설계로 바꿨다.

## 8. `[CORE]`+`[CLIENT]` 인벤토리·가방 사다리 (신규)

### 8-1. 설계 의도
dev 모드 용량을 처음부터 주면 **가난의 체감·제작의 동기·확장의 보상감**이 전부 사라진다.
v3에서는 가방을 **장비 슬롯(단축키 E)에 착용해야만 용량이 늘어나는 아이템**으로 만든다.

### 8-2. 용량 모델

`D` = 현재 dev 모드에서 쓰는 탭당 슬롯 수 (`inventory.devSlotsPerTab`, 기존 값 그대로 상수화).

| 단계 | 가방 | 탭당 용량 | 획득 | 비고 |
|---|---|---|---|---|
| 0 | **없음** (주머니) | **2열 × 5행 = 10칸** | 게임 시작 | 1-2에서 즉시 부족을 체감 |
| 1 | **간이 백팩** (improvised backpack) | `round(D × 0.5)` | **1-8 제작** (메인) | 재료: 방수천 조각·폐로프·버클·바늘실 |
| 2 | **태클 베스트** | `round(D × 0.75)` | **N06-3 보상** (Ch2) | 소형 슬롯 다수 = 채비·루어 탭 가중 |
| 3 | **드라이백** | `round(D × 0.9)` | **N11-2 보상** (Ch4) | 침수 방지 — 배 침수·비 이벤트에서 손실 0 |
| 4 | **마운틴 백팩** | `D` (= dev 전체) | **N01-6 보상** (Ch6) | 떠돌이 바람이 쓰던 것 |

- **탭 구조는 유지**하고 탭마다 위 용량이 적용된다(`slotsPerTab`). 탭 종류는 기존 구현을 따른다.
- 별도 축: **리어카** (N01-1, Ch1) — 자전거에 연결하는 **이동 창고**. 인벤과 분리된 별도 보관함이며 자전거 탑승 중에만 접근 가능. 가방 사다리와 곱연산되지 않는다.

### 8-3. `[CORE]` 규칙

```ts
export interface BackpackSpec {
  id: 'improvised' | 'tackle_vest' | 'dry_bag' | 'mountain';
  slotsPerTabRatio: number;   // 0.5 / 0.75 / 0.9 / 1.0
  equipSlot: 'back';
  traits?: ('waterproof' | 'quickAccess')[];
}

/** 가방 미착용 시 기본값 */
export const BASE_SLOTS_PER_TAB = { cols: 2, rows: 5 } as const;

resolveSlotsPerTab(equippedBag: BackpackSpec | null, devSlots: number): number
canUnequipBag(inventory, targetCapacity): { ok: boolean; overflow: number }
```

**해제 규칙**: 소지량이 낮은 용량을 초과하면 해제 차단. 사유 팝업 + "집 창고로 보내기" 버튼 제공(홈타운 안에서만).
아이템을 바닥에 흘리는 처리는 하지 않는다(분실 스트레스 회피 — 스타듀 톤).

**사망 페널티와의 관계**: `progression-survival-spec.md` §6-2의 인벤토리 상실 규칙은 그대로. **착용 중인 가방 자체는 상실 대상에서 제외**(재제작 반복 강요 방지). `[VERIFY]` 기존 페널티 스펙과 충돌 없는지 확인.

### 8-4. `[CLIENT]` UI
- 장비 슬롯 단축키 **E**. 등(back) 슬롯에 가방 아이콘.
- 용량 증감 시 탭 그리드가 애니메이션으로 확장/축소하고, 새로 열린 칸은 1회 하이라이트.
- 0단계에서 인벤이 꽉 차면 툴팁: "가방이 필요하다. 방수천이라도 있으면 만들 수 있을 텐데." → 1-8 힌트.

#### B. `[CORE]` 출조 파이프라인 (8단계 상태기계)
```
BOOK → MUSTER → SAFETY_CHECK → DEPART → RUN → FISHING → RETURN → SETTLE
```
| 단계 | 내용 | 실패/이탈 |
|---|---|---|
| **BOOK** 예약 | 날짜·시간대(새벽/오전/밤)·대상어·선비 결제. 정원 제한 | 기상 예보 악화 시 전날 알림 |
| **MUSTER** 집결 | 집결 시각 전 부두 도착. **늦으면 출항해 버린다**(선비 환불 없음) | 지각 = 하루 손실 |
| **SAFETY_CHECK** 점검 | 구명조끼 착용·승선 명부 서명·음주 확인 | 미착용 시 승선 거부 |
| **DEPART** 출항 | 실시간 기상 롤 → 결항 확률 | 결항 시 선비 환불 + 항구 신뢰 소폭 ↑(선장 판단 존중) |
| **RUN** 항주 | 이동 시간 동안 **멀미 게이지** 상승. 채비 준비·수면으로 상쇄 | 멀미 만땅 = 조과 페널티·조기 귀항 요청 |
| **FISHING** 조업 | 사관(자리) 배치 → 포인트 이동 2~4회 → 어탐·보일링 이벤트 | 라인 엉킴·밑걸림·채비 유실 |
| **RETURN** 귀항 | 귀항 시각 고정. 기상 악화 시 조기 귀항 | 미준수 선택지 없음 |
| **SETTLE** 정산 | 조과 분배·쿨러 보관·선장 평점 | 어획물 `CatchMethod: 'rod'` → §3에 따라 **판매 불가** |

#### C. `[CORE]` 선상 고유 룰
- **사관(자리) 시스템**: 이물/고물/현측. 대상어·조류 방향에 따라 유불리가 바뀐다. 추첨이 기본이고, 항구 신뢰가 높으면 선장이 좋은 자리를 준다.
- **라인 엉킴**: 옆자리와 캐스팅 각도·투입 타이밍이 겹치면 확률 발생. 해결 미니게임 또는 채비 절단(손실). 선상 매너 스킬로 확률 감소.
- **밑밥 순번**: 여러 명이 동시에 뿌리면 효과 분산. `chum-sync-overlap-spec`과 연동.

- **어탐·보일링**: 선장이 포인트를 찍으면 해당 구역 `feedingActivity` 보너스. `boiling-schooling-feedingtime` 이벤트를 선상에서 그대로 재사용.

## 13. 세계관 ↔ 퀘스트 결합 장치

1. **자격이 지역을 연다** — 레벨만으로는 어디도 못 간다(§6).
2. **기한이 서사를 민다** — 챕터마다 D-day 하나. 실패는 없고 비용과 계절 지연만.
3. **평판이 절차 속도를 바꾼다** — 표결·수수료·시험 가산(§6-1).
4. **법이 경제를 규정한다** — 낚싯대 어획물은 영원히 판매 불가. 수입은 통발·맨손어업·품삯·사업에서 나온다(§3).
5. **서브가 메인의 재료다** — 조행록 17장은 지역 서브 아크 없이는 못 채운다(§7).
6. **가방이 행동 반경을 규정한다** — 초반 10칸은 "한 번에 많이 못 가져간다"를 통해 출조 계획을 강제한다(§8).
7. **막힌 길엔 항상 합법 대안** — 2-7이 교본. `LawVerdict.alternatives.length >= 1`은 회귀 테스트 항목이다(§3-5 T7).

### 14-6. 남은 판단 사항
1. **부 경계 연출 유지 여부** — v2에서 제안한 "부 마지막 퀘 후 취침 시 타이틀 카드 + 증거 보드(→ v3에서는 **조행록 액자 벽**)" 연출을 살릴지.
2. **플라이(털바늘)** — N09·N15가 쓰는 털바늘을 기존 캐스팅 물리 안의 채비 변형으로 둘지, 독립 스타일로 확장할지.
3. **좌판 운영(6-6)** 의 깊이 — 간단 정산 루프인지, 본격 경영 서브시스템인지.
4. **구술 채록(3-6)** 을 도감 확장으로 볼지 별도 컬렉션으로 볼지.
5. **§8-1 챕터표 지역 보정 반영** — Ch4에 태안 2권역, Ch6에 인천 명시(17개 지역 1:1: 1/3/2/5/3/2/1). 퀘 수·XP 변경 없음.
